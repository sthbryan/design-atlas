# Outline Kit

## What it is

A fictional outline icon set on a 24px grid, published as SVG files and a React package.

## When to open it

When a product needs one consistent outline set under a permissive licence.

## Most useful

- A React package with a provider for shared stroke and size

## Using it with agents

`npm i outline-kit-react@2.1.0`, then import named components. There is no MCP server.

## Watch out for

- Solid variants cover only part of the set

## Reusable ideas

- Set icon defaults once in a provider instead of on every icon
