# Goodest

## What it is

Goodest is a curated design inspiration gallery: 1,097 items at review across apps, websites, agent-related visuals, motion, 3D, logos, brands, typography and launch videos. Interface is the largest category (495 items at review), followed by motion.

## When to open it

Open it for a quick, broad sweep of current design inspiration by category, especially interface and motion work.

## Most useful

- **Category breadth**: apps, websites, motion, 3D, logo and brand in one library.
- **Visual-first browsing**: the gallery leads with the work, with category counts up front.
- **Curated, not scraped volume**: the library is small enough to browse, unlike raw screenshot dumps.

## Using it with agents

No MCP, API or agent guide is published; an agent can browse the gallery in a browser.

## Watch out for

- The shown work is referenced, not licensed; use it as inspiration only.
- The library is curated, so it reflects the curator's taste and coverage.

## Reusable ideas

- Lead with category counts so a visitor can judge the library before diving in.
- Keep a small, curated set browsable instead of growing an unfiltered dump.
