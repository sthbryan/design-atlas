# Lafys

## What it is

Lafys sells long, design-heavy prompts for rebuilding whole websites with AI builders. It was started by Bogdan Falin and the designers behind the QClay studio, and the company is registered in Singapore. Each entry shows a video of the finished site, the number of sections it builds (from a 2-section hero up to 14-section landing pages), the tools it was tested with (Claude, Lovable, v0, Antigravity, Kimi, ChatGPT, Codex, Grok) and tags such as scroll animation, WebGL, Three.js or liquid glass. The sitemap listed 42 prompt pages at review, in seven categories: UI Components, Ecommerce, Portfolio, Hero Pages, Landing Pages, AI Websites and Fintech. A separate library of 100+ static and animated backgrounds comes with the top tiers.

## When to open it

Open it when you want to see what a carefully written website prompt looks like and what it produces, especially for cinematic, scroll-driven or WebGL landing pages. The free prompts and the video previews are worth studying even if you never subscribe.

## Most useful

- **Video of the result** on every entry, so you judge the output before copying the prompt
- **Section counts and tool tags**, which show how much of a site one prompt is meant to build and which builders it was tested on
- **Tag pages** (about 410 at review) for motion and visual effects such as scroll animation, 3D, glass effect and cinematic
- **Backgrounds** for hero sections, in static and animated versions

## Using it with agents

The prompts are plain text built for pasting into Claude, Lovable, v0 and similar tools, so any agent can use them once copied. There is no MCP server, API or CLI. The site publishes a short `llms.txt`, but at review it listed only the main pages and no blog articles, and the prompt text is loaded by script rather than served in the page, with premium prompts locked to members. To use a prompt with a coding agent, save it as a file in your repo and pair it with your own design tokens, so the output isn't only the Lafys look.

## Watch out for

- The licence terms conflict: the pricing page offers personal-only and client licences by plan, while the terms of use limit all site content to personal, non-commercial use. Get written confirmation before client work
- The pricing FAQ refers to a $299 price that matches no plan listed on the page, and the crossed-out prices suggest a standing promotion
- Payments, including lifetime purchases, are non-refundable
- The catalogue is small and mostly by one author, so the style is fairly uniform
- A long prompt doesn't guarantee the same result: output varies with the builder and model used

## Reusable ideas

- Pair every prompt with a recording of what it produced, so readers can judge it before copying
- Label prompts with section count and tested tools, so readers know the scope before they paste
- Split a site prompt into named sections, so parts can be reused on their own
