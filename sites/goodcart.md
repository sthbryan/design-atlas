# GoodCart

## What it is

GoodCart is a gallery of real ecommerce websites, captured as full-page desktop and mobile screenshots. At review it described more than 1,160 captures across 396 selected stores, covering home, collection and product pages. The Resore entry links its three page captures to the live shop. The gallery interface uses a pale gray canvas, a left-aligned sans-serif heading, page tabs, a desktop/mobile switch and a three-column capture grid; that interface is separate from the visual styles of the stores it indexes.

## When to open it

- When laying out a storefront homepage, product detail page or collection listing and you want to compare shipped examples across brands.
- When checking how a specific ecommerce category handles responsive composition, product grids or add-to-cart actions.
- When exploring visual directions for a store, then following a capture to the live site to check the original context.

## Most useful

- **Page tabs**: compare Home, Collection and Product captures for the same store. Resore's entry shows three pages side by side and links each capture to the corresponding live page.
- **Device switch**: inspect desktop and mobile versions to compare navigation, hero composition and product hierarchy across widths.
- **Industry and style filters**: browse 13 ecommerce industries and styles such as editorial, luxury, minimal, organic, playful and retro.
- **UX pattern filters**: find examples of patterns such as sticky add-to-cart, quick add, variant swatches, filtering and sorting.
- **Sort order**: change the gallery ordering from Latest when looking for different examples.

## Using it with agents

There is no published MCP, API, CLI, registry or agent guide. The public gallery is readable without an account, so an agent can use its categories, filters and linked live examples as research starting points. Treat screenshots as reference material only: the terms forbid copying or distributing GoodCart content without permission, and the captured store assets belong to their respective owners.

## Watch out for

- These are visual captures, so verify current behavior, responsive states and content on the linked store before relying on them.
- The gallery focuses on home, collection and product pages; it does not document a complete checkout journey.
- At review, GoodCart described its catalogue as 1,160+ captures from 396 stores; these counts can change.
- A visual pattern in a live store is an example to study, not evidence that it improves conversion.

## Reusable ideas

- Keep page type and device as separate controls so visitors can compare like with like.
- Group several page captures under one store entry and link them to the source pages; this makes it easier to trace repeated brand choices across a storefront.
- Pair broad industry and style filters with narrower UX-pattern tags to support both mood exploration and task-focused research.
