# Dark Design

## What it is

A curated gallery of dark-themed websites with a feed of site cards, category filters and new or popular sorting. Each card links both to a gallery detail page and to the live site. A separate section lists free templates.

## When to open it

Use it when the project calls for a dark interface and you want to compare current examples by industry. It adds useful filtering and direct-outbound links to the simpler, paginated list in [Dark Mode Design](dark-mode-design.md).

## Most useful

- The [homepage](https://www.dark.design/) groups a large grid under categories such as Agency, AI, Culture, Education, Hardware, Personal, Software and Web3.
- [Basement's live site](https://basement.studio/) uses a compact top navigation, a short studio introduction and a featured-project sequence; the [gallery record](https://www.dark.design/site/basement) keeps the recommendation tied to its source.
- The visible sponsored card is labelled, which helps distinguish paid placement from the handpicked entries.

## Using it with agents

There is no published agent integration. Use a browser to filter by industry, open a gallery detail page, then inspect the linked live site before making a design decision. Gallery previews are snapshots and may no longer match the current design.

## Watch out for

The gallery is intentionally restricted to dark-themed sites, so it will not help compare light and dark treatments of the same product. Sponsored placements appear in the feed. The site provides free templates, but no licence for gallery captures or other content was found; treat them as look-only.

## Reusable ideas

- Pair a persistent style constraint with industry filters, then let visitors switch between recency and popularity.
- Label sponsorship on the card itself, close to the recommendation.
- Keep a gallery detail page between the preview and original site so a source remains identifiable after the outbound visit.
