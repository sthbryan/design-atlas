# Aiverse

## What it is

Aiverse is a framework of AI UX patterns organised by interaction phase: Discovering, Instructing, Observing, Refining and Adapting. At review it holds 40 patterns backed by 300+ curated examples from real products, from prompt assistance and MCP connectors to agent observability and memory. Some patterns are free, others are Pro exclusive.

## When to open it

- When designing an AI interaction beyond chat and you want a phase-by-phase vocabulary for it.
- When a pattern needs product evidence: each entry links examples from shipping products.
- When trust, correction and control decisions (pause, stop, disambiguate) need a principled reference.

## Most useful

- Phase structure: patterns attach to a stage of the journey, so a team can find the ones relevant to their flow.
- Real examples per pattern (for example 15 inside prompting assistance, 12 inside parallel processing), not just prose descriptions.
- Refinement thinking: local editing of a passage instead of restarting the whole interaction.
- Adapting phase: feedback, memory and personalisation patterns as first-class design concerns.

## Using it with agents

- MCP access exists on Pro; the free tier is browsable patterns and examples.
- No public API details, llms.txt or CLI were verified at review, so the patterns site itself is the reading path.
- Terms restrict reuse to limited subscriber use; treat the framework as a reference to describe in your own words.

## Watch out for

- Pricing at review: Pro at $8/month billed annually, Teams at $32/month billed annually. Check the pricing page for current figures.
- Pro-exclusive patterns (MCP connectors, knowledge bases, multi-modal output, confidence) are gated; the free set alone is partial.
- The framework is under active rework (v2 latest at review), so phase names and counts shift.

## Reusable ideas

- Organise AI patterns by journey phase, so teams find the relevant ones for their flow instead of a flat list.
- Pair every pattern with concrete product examples and counts, so the guidance is checkable.
- Make refinement local to the output: edit the passage, keep the rest of the interaction intact.
