# Framio

## What it is

Framio is a curated gallery of live websites. It presents long page captures and links back to each original site. Its own interface has a cream editorial surface, oversized black serif headings, and a dense row of filters for industries and visual tags such as Brutalism. At review, the gallery listed 162 sites, 324 captures and 61 style tags.

Open an entry to compare desktop and mobile captures side by side, inspect its extracted palette and visit the live source. In the [Eduardo Duccigne entry](https://www.framio.site/sites/eduardoduccigne-co-en), the linked [portfolio](https://eduardoduccigne.co/en/) opens with a narrow serif introduction on the left, black pill links, and a two-column project grid with thumbnails on the right. That original composition is useful to study separately from Framio's own editorial layout.

## When to open it

Use it to compare full-page compositions across industries or to find a visual direction by style, colour or typeface. The desktop and mobile captures make it easier to see how a page's hierarchy and imagery change between screen sizes before opening the original.

## Most useful

- Filter by industry, then narrow by a visual tag such as Brutalism, Big Type, Grid or Typographic.
- Use the long captures to follow hierarchy, image rhythm and footer treatment through an entire page rather than judging only the hero.
- Compare the desktop and mobile captures in an entry, then open its live-site link to check the current layout and interaction.
- Use the extracted palette as a starting point for studying colour relationships; it is a reference, not a reusable asset licence.

## Using it with agents

No MCP, API, CLI, `llms.txt` or agent-specific access channel was visible at review. An agent can still use the public gallery in a browser: choose a tag, inspect a few captures, and follow the source links. Keep observations about Framio's captures separate from observations about each original site.

## Watch out for

- The homepage described the picks as daily, while its latest-add notice was 39 days old at review. Check the displayed date if recency matters.
- A capture records one visit and may not show later redesigns, responsive states beyond the supplied mobile view, or interactions. Open the original before relying on those details.
- The screenshots belong to their makers. No general permission to copy or redistribute them was stated; use them for visual reference and check the original site's terms before reusing code or assets.

## Reusable ideas

- Pair a full-page capture with an extracted palette, device variants and a direct source link so a reference can be evaluated in context.
- Combine industry filters with concrete visual tags to narrow a broad gallery without losing the ability to compare different page structures.
- In the Eduardo Duccigne portfolio, the fixed two-column composition balances a concise introduction with a browsable project grid; the black pills give navigation a compact, high-contrast treatment.
