# Super

## What it is

Super hosts a website whose content lives in a Notion page, and the design problem it solves is the interesting one: Notion gives you a document, not a page layout, so Super layers themes, custom fonts, an icon set, illustrations and components over the document. The home page is unusually literal about this — its top navigation is a flat list of its own internal pages (Landing, Notion Icons, Icons — All, Illustrations, Components, Themes, Templates, Showcase, Case Studies, Changelog), which reads like a site map left in the header and does say how much of the product is a themed catalogue rather than a builder.

## When to open it

Open it when a content-heavy site — docs, changelog, handbook, resource list — has to look designed without a CMS build, and you want to see how far a themed layer can take a plain document. It is also a reference for a three-step explainer that fits above the fold.

## Most useful

- **Themed layer over content**: themes, custom fonts, icons and illustrations are the design surface; the page structure stays Notion's.
- **Three-step explainer** (choose a page, paste the link, publish) with the steps numbered and laid out as a sequence.
- **An icon and illustration set of its own**, visible in the nav, which is what a themed host needs to stop its sites looking identical.
- **Components and templates pages** that show the layer as a catalogue rather than a feature list.
- **MCP server** advertised in the header, so an assistant can build a page from Notion content.

## Using it with agents

Super advertises MCP and an AI assistant that builds a site from Notion content, which makes it one of the few site hosts whose own page states an agent channel. The MCP route is the one to try in a code agent; the free tier is enough to see what the themed output looks like before paying.

## Watch out for

- The creator counts disagree: the home page says over 100,000, the pricing page says over 30,000.
- Publishing controls, custom code and multi-language are paid; the free site carries the badge and lives on a subdomain.
- A document-based site inherits Notion's limits: block types, width and table behaviour, which the themed layer can style but not restructure.
- The header nav is a dump of internal page titles, which is a usability problem as much as a design choice.
- Testimonials and "trusted by" logos are repeated across pages with little variation.

## Reusable ideas

- Sell the layer, not the editor: themes, fonts, icons and illustrations are what a plain document cannot give itself.
- Explain a three-step product with numbered steps and one verb each.
- Ship your own icon and illustration set so customer sites do not all look the same.
- State the agent channel (here MCP) in the header, where a developer will see it.
