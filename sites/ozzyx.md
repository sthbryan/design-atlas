# ozzyx

## What it is

Ozzy's portfolio introduces his design-engineering work through a single oversized text composition, with links to projects, inspiration, writing and contact.

## When to open it

Open it when a portfolio needs to make its introduction the visual centerpiece instead of leading with a conventional hero card.

## Most useful

The first view lays a large, lowercase paragraph across the left side while tilted project images float down the right. Gray text recedes behind darker phrases, and selected links receive soft pastel highlights. The images vary between pale mockups and dark screens, so the column feels like a loose visual counterweight rather than a uniform card grid.

## Using it with agents

No agent-facing integration was found. The portfolio links to an inspiration page and writing, which can be opened separately as authored references.

## Watch out for

The floating image placement depends on a wide viewport. Recheck the composition at narrow widths before adapting it.

## Reusable ideas

- Let long-form display copy provide the main layout structure.
- Use weight and muted color to separate supporting clauses from key phrases.
- Float a few tilted product captures beside the text to add visual rhythm without turning every project into a card.
