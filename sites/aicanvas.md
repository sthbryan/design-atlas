# AI Canvas

## What it is

AI Canvas is the design layer for AI coding agents: complete React design systems your agent builds with and you reshape to your project, plus 98 standalone React components and blocks that fit any of them. Every open component installs with one command; Premium adds the Andromeda Pro system, its templates and the AI Brain.

## When to open it

Open it when you want an agent-native design system, where the agent and the human work from the same components.

## Most useful

- **Systems plus standalones**: full systems for a product, and standalone pieces that fit any of them.
- **One-command install**: open components install free with an account.
- **Agent-shaped**: the systems are designed for Claude, ChatGPT, Cursor and similar agents to build with.

## Using it with agents

An MCP server and an `llms.txt` are published; the one-command install is the path both humans and agents use.

## Watch out for

- The premium systems sit behind a paid tier; confirm the licence before shipping them.
- A system your agent builds with still needs your brand applied on top.

## Reusable ideas

- Ship standalone components that fit any system, so buyers are not locked to one theme.
- Make installation a single command so the agent can assemble without friction.
