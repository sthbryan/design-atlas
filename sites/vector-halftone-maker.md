# Vector Halftone Maker

## What it is

Vector Halftone Maker is the earlier browser editor by Xoihazard, now explicitly linked to Halftone Maker as its new version. It converts a local image into dot patterns and can export PNG or SVG. Its compact toolbar and parameter panel make it a useful reference for a small, single-purpose graphics editor.

## When to open it

- When you want a quick halftone without an account or a large setup screen.
- When you want to compare square, hexagonal or radial grids and round, triangular, square or hexagonal marks.
- When a lightweight reference for a parameter-heavy image effect is more useful than a full graphics suite.

## Most useful

- **Grid choices**: square, hexagonal and radial layouts with spacing, rotation and radius controls.
- **Dot choices**: circles, triangles, squares, hexagons and related shapes with scale, strength and outline settings.
- **Sampling and colour**: tune blur, gamma, clipping, channels, foreground/background colours, transparency and channel decomposition.
- **Local processing**: the site states that images stay in the browser and are not uploaded.
- **Visual direction**: a thin top toolbar sits over an open white canvas, while dense black settings panels with blue sliders stay docked on the right. A large monochrome dot illustration demonstrates the result.

## Using it with agents

There is no published MCP, API, CLI, `llms.txt` or agent guide. Export a PNG or SVG from the browser and give the file to an agent.

## Watch out for

- The page announces Halftone Maker as the newer version, with mobile support, more export options and other added features.
- The creator grants broad commercial use of generated content, but restricts copying the tool's code or design. This does not grant rights to the sample illustration, which is credited to Sevnzel.
- The page shows a build timestamp from December 2025; the older editor remains live but may not receive the newer version's features.

## Reusable ideas

- Keep common actions in a fixed toolbar while placing detailed controls beside, not over, the canvas.
- Offer visible sample presets for quick visual exploration, then expose the full parameter set for precise tuning.
- Separate the image's sampled channels from the shape grid and output colour controls.
