# SVG Shapes

## What it is

A one-page gallery of over seventy hand-drawn shapes as SVG, made by Monika Michalczyk, where the primary action is copying rather than downloading: click a shape and it is on your clipboard. There is a download-all link for the impatient, and nothing else — no account, no filters, no categories, no search.

The value is the drawing rather than the tooling. These are deliberately irregular shapes, the kind you would otherwise trace, and they arrive as clean SVG rather than as a sprite sheet or a Figma file. In a landing page that needs an organic blob, a hand-drawn arrow or a torn edge, one click beats opening a vector editor.

## When to open it

Open it when a layout needs one non-geometric form and you do not want to draw it, or when you are assembling a small illustration set and need shapes that look drawn by the same hand.

## Most useful

- **Copy to clipboard as the primary action**, which removes the download-unzip-import loop.
- **Hand-drawn irregularity**, the specific thing a CSS shape cannot give you.
- **Consistent authorship**, so two shapes from the page sit together without a style clash.
- **A single page with everything on it**, fast to scan and fast to finish.
- **Download all**, for a project that wants the whole set.

## Using it with agents

No `llms.txt`, no API, no JSON, and copying is a clipboard interaction an agent cannot perform. An agent can read the page and the shape count, but the assets need to be downloaded or inlined by a person.

## Watch out for

- No licence is stated: "free copy-paste" describes the interaction, not the rights. Ask before shipping in a commercial product, or draw your own.
- There is no search or categorisation, so finding a specific shape means scrolling.
- No dark-mode variants, no stroke-weight options, no favicon or icon sizes.
- The set is small and personal; it will not cover a whole icon system.
- SVG copied from a page may carry inline fill colours you will need to strip.

## Reusable ideas

- Make copy the primary action on an asset page; it is faster than any download flow.
- Keep one hand behind a small set so the shapes belong together.
- Put everything on one page when the set is under a hundred items.
- If the assets are genuinely free, say so in a licence line, not in the tagline.
