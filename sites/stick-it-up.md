# Stick It Up

## What it is

Stick It Up is a free UI sticker component library for React and Next.js: 65+ interactive vector, metallic chrome and retro pixel-art stickers with a realistic 3D vinyl hover-peel effect.

## When to open it

Open it when a UI needs sticker-style accents (badges, callouts, playful markers) with a tactile hover interaction.

## Most useful

- **Vinyl hover-peel**: the 3D peel on hover is the interaction that makes stickers feel physical.
- **Three sticker styles**: vector, metallic chrome and retro pixel art in one library.
- **React and Next.js**: components, not images, so stickers theme and animate with the app.

## Using it with agents

An `llms.txt` describes the library; the npm package is the working path for an agent.

## Watch out for

- No named licence was found at review despite the open-source claim.
- Stickers are accents; a page built from them will look playful, not enterprise.

## Reusable ideas

- Give stickers a physical hover so they feel like objects on the page.
- Keep several sticker styles in one library so the accent family stays coherent.
