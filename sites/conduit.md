# Conduit

## What it is

Conduit provides AI agents for hospitality teams, including a shared inbox for guest messages and calls. The marketing page demonstrates that interface inside the landing page rather than relying only on decorative mockups.

## When to open it

When a service page must show the actual shape of an operations interface, especially a multi-channel inbox with triage and escalation states.

## Most useful

- [Home](https://www.conduit.ai/) — inspect the centered serif hero, inbox preview, selected task tabs and operator side panel.
- [Pricing](https://www.conduit.ai/pricing) — compare plan cards, unit-based rates and feature grouping.
- [MCP overview](https://docs.conduit.ai/mcp/overview) and [API reference](https://docs.conduit.ai/api-reference/introduction) — follow the product's published agent and developer interfaces.

## Using it with agents

The footer links to [llms.txt](https://www.conduit.ai/llms.txt), an [MCP server](https://www.conduit.ai/mcp) and an [API reference](https://docs.conduit.ai/api-reference/introduction). MCP and API are public integration channels; the live docs remain the source for current setup details.

## Watch out for

- The page includes a cookie prompt and an embedded chat widget that can cover parts of the screen; dismiss or account for them when studying the layout.
- The inbox preview is a product demonstration, not a public guest-operations account.
- Published prices start at $18 per unit per month at review and scale by package and portfolio size.

## Reusable ideas

- Show a believable operational interface directly below a concise product promise, so visitors can see the product's information hierarchy immediately.
- Put selected and unselected work states in the preview to make triage behavior legible without a long explanation.
- Use numbered section labels to help people track a long product story while preserving a quiet editorial layout.
