# Lusion

## What it is

Lusion is a creative studio portfolio for 3D visual storytelling and interactive web projects. Its homepage combines a short studio introduction, a large rendered 3D scene and a featured-work section, presenting the site itself as a sample of the studio's art direction.

## When to open it

Open it when you need a reference for a high-impact 3D hero or a studio portfolio that lets a rendered scene carry most of the first impression.

## Most useful

- **Homepage hero**: a pale lavender-gray page places the Lusion wordmark at the upper left and a large, three-line statement near the center. A wide, rounded dark canvas beneath it contains glossy interlocking tubular forms in white, black and vivid blue.
- **Framing**: small pill-shaped controls sit beside the headline, while sparse plus marks and a centered scroll prompt frame the 3D scene without adding a conventional card layout.
- **Featured work**: further down, the homepage links to projects and labels their roles, including web, design, development, 3D and animation. The provided `/work` address returned to the homepage during this review; use the homepage's project links to continue exploring.

## Using it with agents

There is no published agent interface. Give an agent the homepage and ask it to describe a specific compositional choice—such as how the pale page surface contrasts with the dark scene, or how the headline and canvas share the first screen—and make a new design from that observation.

## Watch out for

- The work depends on a large 3D canvas and motion. Check loading behavior, performance, keyboard access and reduced-motion fallbacks before using similar effects in a product interface.
- No reuse licence for the portfolio's code, imagery or featured projects is stated. Treat the site as a visual reference rather than a source of reusable assets.

## Reusable ideas

- Make a single, distinctive 3D scene the main visual anchor and keep the surrounding page controls sparse.
- Set a dark scene inside a contrasting light page surface so the rendered object reads as a deliberate stage.
- Let a short studio statement lead directly into the work instead of separating the introduction from the visual proof.
