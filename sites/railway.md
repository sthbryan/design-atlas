# Railway

## What it is

Railway is a cloud deployment platform. Its rendered site is a useful reference for a software product landing page: the homepage uses a custom illustrated night-sky background and large product canvas, while the free VM page turns a terminal command into the central interaction.

## When to open it

- When a technical product needs a distinctive visual identity without burying the product interface.
- When designing a focused campaign page around one user action or command.

## Most useful

- **Homepage**: the [hero](https://railway.com/) places a serif headline and two calls to action above a dark project canvas, all against a hand-drawn cloud and star field. Feature sections continue with product UI, then explain build, networking, scale and monitoring.
- **Free VM campaign**: [Get a VM for free](https://railway.com/free-vm) centers a large serif title over a dotted violet field, then presents a copyable `ssh railway.new` command in a terminal-like control.
- **Page sequence**: the campaign moves from command to a three-step connect/build/claim flow, then a short FAQ, keeping the main action visible throughout.
- **Visual system**: compare the homepage's violet buttons and illustrated clouds with the campaign's denser dot field and monospace command to see how one brand shifts emphasis between page types.

## Using it with agents

No MCP, CLI, registry or agent guide for accessing Railway's design references is listed. The pages are ordinary browser content; Railway's deployment CLI is for its hosting product.

## Watch out for

- Railway is a paid cloud service, with usage-based billing; the free VM campaign is a specific no-account trial path rather than a general free hosting tier.
- The site and its illustrations are proprietary, with no asset reuse licence stated. Use the page as visual reference only.
- The campaign page's claim and command depend on current service behavior; verify before repeating any product facts.

## Reusable ideas

- Put one copyable command in a visually distinct terminal block when the action is the whole point of a campaign.
- Let a custom background carry the product's mood, while keeping interface imagery large and readable.
- Follow a hero with a short numbered explanation, then answer edge cases in a compact FAQ.
