# Dark Mode Design

## What it is

Dark Mode Design is a long-running showcase of websites designed dark by default, hand-picked by designer Cai Cardenas. It is a simple Webflow site: a paginated grid of thumbnails, each linking straight to the live site, with one sponsor card (Mobbin at review time).

## When to open it

- When you're designing a dark-first site and want to see how real studios handle contrast, accent colour and imagery on near-black.
- When you need proof that a dark palette can work for a portfolio, agency, developer tool or product site.
- When you want a short, calm set of references rather than a huge filtered database.

## Most useful

- About 380 site entries in the sitemap, with records going back to 2020 and additions as recent as September 2026.
- A mix of personal portfolios, studios and product sites (Oxide, GitHub, frame.io and Lazy appeared on the first page).
- Every thumbnail opens the real site, so you can check how the dark theme holds up across a full page.
- Updates are posted on Threads, Instagram, Bluesky and X, and sites are submitted by email.

## Using it with agents

No MCP, llms.txt, API or export. Pick a few sites, measure what they do (background shade, text colour and contrast, how many accents, how images and borders are treated) and give the agent those values as a dark palette spec. Ask it to check contrast against WCAG, since a reference site passing by eye isn't proof.

## Watch out for

- There is no search, tagging or filter by industry, colour or layout; browsing is page by page.
- It shows sites that are dark by default, so it won't teach you how to design a light/dark toggle or theme tokens.
- The catalogue is small and grows slowly; some older entries may have been redesigned since.

## Reusable ideas

- A single strict rule (dark by default) is enough to make a gallery useful without any filters.
- Linking thumbnails straight to the live site keeps the gallery light and avoids hosting full captures.
- One clearly labelled sponsor card in the grid is an unobtrusive way to fund a niche showcase.
