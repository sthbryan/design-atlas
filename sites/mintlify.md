# Mintlify

## What it is

Mintlify is a hosted documentation platform positioned for the agent era: docs in Git as markdown or MDX, served to people and agents alike. The Free plan at review costs nothing for up to five editors and includes hosting, search, a custom domain, the web editor, authentication, an MCP server and the API playground. Pro was listed at $540/month billed monthly, or $450/month billed annually.

## When to open it

- When a small team wants polished docs without assembling a generator, hosting and search themselves.
- When docs must be readable by agents: MCP server, llms.txt and markdown output are built in.
- When API reference pages need an interactive playground beside guides and tutorials.

## Most useful

- Agent surfaces from the docs page itself: copy page as markdown, open or connect with an AI tool, MCP server and llms.txt, not just setup docs.
- OpenAPI to interactive reference pages with a playable request console, included even on the Free plan.
- Docs stay in Git, so content ownership survives leaving the platform.
- AI assistant on paid plans helps readers answer questions, and agents can propose doc updates through pull requests.

## Using it with agents

- MCP server connects your Mintlify content to AI tools; llms.txt is published at review.
- API playground gives agents and humans a live reference for the same endpoints.
- Setup guidance exists for connecting an AI agent to a Mintlify site from the docs.

## Watch out for

- Pro pricing is steep at review figures; confirm current prices on the pricing page before budgeting.
- The hosted platform's own reuse terms were not found stated at review, so check the terms for anything you publish through it.
- Custom third-party npm libraries need setup; components run in a sandboxed MDX environment with named exports.

## Reusable ideas

- Put agent access (copy as markdown, connect AI tool, MCP) on the documentation page itself, not buried in setup guides.
- Keep docs content in Git as markdown so the platform stays replaceable.
- Pair every API reference with a playable console, so readers learn the workflow and try endpoints in one place.
