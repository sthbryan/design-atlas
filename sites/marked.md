# marked.dev

## What it is

marked.dev is a reference library for coding agents: you save interfaces, interactions and motion from X, Pinterest and the web into private collections, and your agent reads what you saved over MCP. The point is that the agent sees the references you actually chose instead of guessing what good looks like.

## When to open it

Open it when you want to hand an agent a curated set of interaction references, for example "scroll animations like these", rather than describing them in prose.

## Most useful

- **Search by interaction**: type what moves (hover, scroll, drag) and find saved references that match.
- **Private collections**: keep your own taste library separate from the public curated library.
- **MCP access**: the saved references are served to the agent, so the session starts from your choices.

## Using it with agents

An MCP server exposes the library to the agent; the site also offers a public library to browse without an account. There is no `llms.txt` at review.

## Watch out for

- Saved references are other people's work; treat what the agent produces as inspired, not copied.
- The public library is curated by the team, so private collections are where your taste lives.

## Reusable ideas

- Search references by the interaction they demonstrate, not only by the product they come from.
- Let a user build a private taste library and serve it to the agent as context.
