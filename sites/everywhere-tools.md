# everywhere.tools

## What it is

everywhere.tools is a small, hand-picked collection of experimental tools for designers and other creatives, made by the designer Danil Vladimirov. Its About page describes it as a place for side projects and experiments that would otherwise sit unnoticed in personal repositories, and says the site runs on a customised version of the portfolio builder Collected. Each entry has a short card, a one-paragraph page and a link out. The footer carried a "last updated" date of 21 July 2026 at review.

## When to open it

- When you want offbeat type and image tools (grid-based letter builders, type filters, datamoshing, glitch, dithering) for a poster, identity or zine-style web piece.
- When you are looking for open-source type foundries and collectives to take free display faces from.
- When you want a lightweight, open-source way to build an exhibition or portfolio site.

## Most useful

- 20 entries at review in three groups: Generative art (12), Typefaces (6) and Website builders (2).
- **Typefaces** mixes foundries ([Velvetyne](velvetyne.md), Collletttivo, a type-filter foundry) with browser type generators and a grid type tool.
- **Generative art** covers drawing and gradient toys, halftone and dither makers, video datamoshing, glitch effects and experimental tool collections from studios.
- **Website builders**: Swarm, an open-source exhibition site builder on Kirby, and Collected.

## Using it with agents

No llms.txt, MCP or API. The list is short enough to read yourself. Make type or image assets in the linked tools, check each project's own licence (above all for fonts), and hand the agent the exported files.

## Watch out for

- It's very small, and the date in the footer suggests it isn't updated often.
- "Open source" in the tagline isn't true of every entry; for example, [Tooooools](tooooools.md) is free but doesn't publish its source. Check each project yourself.
- Font entries lead to foundries with their own licences, often the SIL Open Font License but not always.
- Contributions go through a Google Form, and the site loads Google Analytics.

## Reusable ideas

- A short, strongly themed list with its own taste can be more useful than a large general directory.
- Building the directory on one of the tools it lists shows the curator uses what they recommend.
