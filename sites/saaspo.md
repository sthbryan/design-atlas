# Saaspo

## What it is

Saaspo is a hand-curated gallery of SaaS website pages, built on Webflow and run by Andy Hooke, who also promotes a SaaS web design studio from the site. It goes beyond the home page: entries are tagged by page type (landing, pricing, product, about, careers, integrations, changelog, media kit and about 20 more), so you can study a whole marketing site. Alongside the page grid it has a Sections view (716 at review), OG image examples (384) and a small templates list (46).

## When to open it

Open it when you are designing a particular SaaS page and want to see how many products handle it, for example a pricing or integrations page. It also works for a quick visual survey of a vertical such as AI, fintech or developer tools before you start a landing page.

## Most useful

- **Page-type filter**: at review, depending on the view, it showed about 790 to 1,370 landing pages, around 390 to 500 pricing pages, and smaller sets for pages like "why us", compare, demo booking and media kit
- **Industry filter** with roughly 80 verticals, including Agents (36) and AI (222) at review
- **Style tags** such as scroll animations, dark mode, bento, boxed, unique footer and ultra-detailed
- **Asset tags** that group pages by the kind of imagery they use: feature abstracts, animated, UI, mascot, 3D, hand-drawn, ASCII
- **Stack filter** (Webflow, Next.js, Framer, Gatsby, WordPress, Nuxt, Astro), plus a random-page shortcut on the R key

## Using it with agents

There is no API, MCP or `llms.txt`; the `/llms.txt` path returns a not-found page. The robots file allows GPTBot but blocks CCBot. Cloudflare challenges plain HTTP clients and entry pages, so agents usually can't fetch it. Browse it yourself, pick a few pages, and give your agent the live URLs or your own notes on their structure.

## Watch out for

- Automated access is blocked, and entry pages can show a bot check even in a normal browser
- Sponsored cards (Framer, Mobbin and others) sit inside the grid, and many outbound links carry referral tags
- Counts differ between menus, so treat the numbers as rough
- There are screenshots only: no code, fonts or palette data per entry

## Reusable ideas

- Tag every reference by page type, not only by industry, so a pricing or careers page is as easy to find as a hero
- Tag the kind of imagery a page uses (abstract, product UI, mascot, 3D) as its own filter
- A one-key random jump is a cheap way to make a large gallery worth browsing
