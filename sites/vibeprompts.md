# VibePrompts

## What it is

A curated library of prompts you paste into an AI agent to get clean Tailwind CSS markup back. Instead of distributing code components, the site distributes the text description (the prompt) that produces the component.

## When to open it

When you don't have a specific component in mind but do have a clear section (hero, pricing, auth, FAQ...) and would rather have the agent generate it to spec than adapt an already-built component from another library.

## Most useful

The site organizes content into 15 categories: authentication forms, pricing, hero, features/bento, navbars, footers, dashboards, testimonials, FAQs, onboarding and contact, among others, plus a "Bonus" section with utility components (toasts, loaders, dialogs). Each prompt has a "View" button with the full text ready to copy.

## Using it with agents

The whole flow is built around agents: pick a section → copy the prompt → paste it into whichever AI assistant you use (Claude, Cursor, v0, etc.) → get production-ready Tailwind CSS back. There's no API or SDK: the interaction with the agent is manual, via copy-paste.

## Watch out for

Since these are prompts rather than pre-audited code, output depends on the model and can vary between runs; review accessibility and visual consistency of the result the same way you would with any generated code. No licence is stated for the prompts or the resulting code.

## Reusable ideas

- Keep your own library of reusable "section prompts" by block type (hero, pricing, cta...) instead of just code snippets
- Organize a catalog by page section, useful as a checklist of what sections a site typically needs
- Use the prompt as a versionable spec layer, shorter and more editable than the final component
