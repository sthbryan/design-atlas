# GreatStuff

## What it is

GreatStuff.fyi is a link archive for designers and makers, built in Framer. The home page is a long grid of cards, each with a name and a one-line note, that you can filter by type (AI, Tools, Resources, Assets, Dev, Curations, Insights, Fun) or shuffle. Each entry has its own page with the link, its type and an "updated on" date. It says it is curated by designers for designers, but it doesn't name the curator. A newsletter sign-up claims more than 2,000 designers and says mailing starts soon.

## When to open it

- When you want to browse recent small launches in the design-tool world (ASCII and dither toys, hand-drawn UI controls, animated icon sets, colour and easing token tools) without a goal in mind.
- When you want other galleries and directories to follow; the Curations type points to many of them.

## Most useful

- About 599 published entries at review, most with an "updated on" date between late June and mid-August 2026.
- By type: Tools about 376, Resources 53, AI 47, Assets 44, Curations 31, Dev 17, Insights 16, Fun 8.
- The entries at the top of the grid at review included several made for coding agents, such as colour ramps, easing tokens and UI sounds an agent can read.
- A shuffle button for random browsing.

## Using it with agents

No llms.txt, MCP or API. Framer does publish a JSON search index for the site, but it's an internal build file, not an interface. Use the archive to find a tool yourself, then give the agent that tool's own docs or package.

## Watch out for

- Much of it is general software: Mac utilities, note apps, planners, invoicing and a layoffs tracker sit next to design resources.
- About 550 more entry pages show "This Page is Not Ready Yet", and the 244 collection pages sit under a `/wip/` path, many of them empty. The site is still being built.
- There are no pricing or licence labels on entries, so check each link.
- A sponsor enquiry link is on every page, but there's no stated policy on how sponsored items are marked.

## Reusable ideas

- A shuffle button suits a site that is meant for browsing, not searching.
- Giving each link its own page with a date lets you see what's new even though the home page has no sort options.
