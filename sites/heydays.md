# Heydays

## What it is

Heydays is a historical Oslo design studio portfolio. The site currently announces that Heydays is now part of Kurppa Hosk and still exposes its earlier work and project pages as an archive.

## When to open it

Open it as a historical reference for brand studio presentation and case-study structure, keeping the merger in mind when following contact or studio information.

## Most useful

- **Home page**: a black merger notice sits above a pale butter-yellow canvas. The struck-through Heydays wordmark, live clock, work links and large muted introduction make a distinctive editorial frame for the portfolio.
- **Huddly**: [the case page](https://heydays.no/projects/huddly) uses a two-column opening with the project name at left and its rationale and deliverables at right. It describes an expanded identity and a warmer palette.

## Using it with agents

No MCP, API, CLI, `llms.txt` or agent guide was found. Use the archived project pages as visual references, and identify them as Heydays-era work rather than current independent studio output.

## Watch out for

- Heydays has merged into Kurppa Hosk, so this is a historical portfolio archive rather than an independent current studio.
- The Huddly case's visual media did not render during this review; only its page layout and case text were available to inspect.
- No reuse licence was stated on the pages checked. Treat case studies and client assets as look-only.

## Reusable ideas

- Put a status change in a high-contrast notice above the old identity so visitors understand the site's context immediately.
- Use a broad, softly colored canvas and a large introduction to establish a calm rhythm before the project list.
- Align a concise project title separately from a fuller rationale and deliverable list.
