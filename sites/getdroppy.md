# Droppy (getdroppy.app)

## What it is

Droppy is a Mac utility sold through a product site that presents the app with animated demonstrations and a catalogue of optional extensions. This entry is about the product landing page at `getdroppy.app`, not the coding-agent app documented at `getdroppycode.app`.

## When to open it

Open it to study a feature-heavy software landing page that needs to explain many small tools without turning every feature into a paragraph. It is especially useful for product showcases, sticky navigation, bento-style feature grids and short demonstration clips.

## Most useful

- **[Home page](https://getdroppy.app/)**: the hero uses a saturated cobalt field, a grainy monochrome illustration and a large centered headline. The top navigation sits in a white capsule, with the purchase action called out in blue.
- **Feature grid**: pale lavender surfaces and oversized rounded cards stage screenshots and motion art; different card sizes establish hierarchy while keeping each feature attached to a short label.
- **[Droplet Store](https://getdroppy.app/droplets)**: a long catalogue turns optional tools into individually named, switchable units instead of one undifferentiated feature list.
- **[Live feature highlights](https://getdroppy.app/#showcase-highlights-title)**: autoplaying product clips show the app's store, shelf editor and file handling in context. A visible control starts the hero film with audio; the highlight rail also has next/previous controls.

## Using it with agents

No `/llms.txt`, MCP or site API was verified in this review. The site has product documentation and a DroppyKit SDK for developers, but those are product documentation rather than a design catalogue. Share a specific section URL and describe the layout or motion to reproduce; don't reuse its product imagery or code under the site terms.

## Watch out for

- The page is a Mac product campaign, not a generic template. The notch, macOS interface screenshots and app-specific blue palette are part of its identity.
- Motion clips autoplay as you scroll; check them with sound muted and avoid reproducing the same density of movement in an interface that needs quiet reading.
- The terms reserve the site's visual and written materials. Use it as a visual reference only unless separate permission covers an asset.
- This is the consumer utility Droppy at `getdroppy.app`; it has no relationship to Droppy Code at `getdroppycode.app`.

## Reusable ideas

- Give the hero one strong graphic and one product claim, then let feature cards carry the detail.
- Use a mixed-size card grid to let a few central features dominate while keeping supporting capabilities findable.
- Give animated demonstrations a clear audio control and pair them with concise labels so the product remains understandable when motion is off.
