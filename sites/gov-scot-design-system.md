# Scottish Government Design System

## What it is

The Scottish Government Design System's charts guidance explains how to present numerical data in an accessible way on public pages. It matches each kind of data to a chart form (time series, rankings, distributions, comparisons) with worked examples, and adds rules for data tables, alt text and colour choices. Content is published under the Open Government Licence v3.0, and the system's accessibility commitment is built around WCAG.

## When to open it

Open it when a chart must work for everyone, including screen-reader and keyboard users, or when you need a decision table that maps data shapes to chart types with reasons.

## Most useful

- **Data-to-chart mapping**: each data shape gets named chart forms with examples
- **Mandatory tables**: guidance to publish the data behind the chart as a table
- **WCAG-grounded rules**: accessibility is checked, not suggested
- **OGL v3.0**: content is open for reuse with attribution

## Using it with agents

There is no llms.txt, API or MCP server. The guidance is plain pages, so an agent can fetch the charts page and apply the mapping as a checklist. Reusing the prose is allowed under OGL v3.0 with attribution.

## Watch out for

- Examples use Scottish public data and terminology; relabel before reusing elsewhere
- Graphic assets are excluded from the OGL, so reuse the guidance text, not the images

## Reusable ideas

- Pair every chart with its data table as a rule of the system, not a nicety
- Publish a mapping from "what your data looks like" to "which chart", with the why on each row
