# Harshit Raghuwanshi

## What it is

Harshit Raghuwanshi's portfolio combines a developer profile with a project archive. The page uses a pixel-art workstation banner, a framed profile block and a long sequence of project and experience sections.

## When to open it

Open it when you need a reference for giving a developer portfolio a distinct visual motif while keeping familiar routes to projects, experience and contact, or for organizing a dense set of projects with category filters.

## Most useful

- **Pixel-art banner**: a wide scene of a developer at a workstation gives the top of the page a recognizable theme without taking over the project content.
- **Profile card**: a framed identity area pairs a small portrait, name, role and location, with the command-palette control placed alongside it.
- **Project filters**: frontend, backend and full-stack categories sit above a sequence of project cards with preview images, concise descriptions and separate demo/repository links.
- **Side utilities**: theme switching, search and a vertical icon rail keep secondary navigation visible around the narrow central content column.
- **Editorial texture**: thin rules, light hatch patterns and compact uppercase project labels add structure to the otherwise white page.

## Using it with agents

No agent-facing integration was visible during the review. The profile, project descriptions, filters and external links were readable in the browser; the filtering, command palette and theme switch were not exercised.

## Watch out for

- The page contains many projects and sections; verify that the project's own priority is clear before copying this density.
- The portfolio displays a recent view count and GitHub activity, which are time-sensitive values.
- No reuse licence was found for the design, code or images. Treat it as look-only; responsive behavior was not separately tested.

## Reusable ideas

- Carry one visual motif, such as pixel art, through a profile page without making every section compete with it.
- Pair filters with both a preview and a direct source link so visitors can scan or inspect further.
- Keep a command palette available beside a profile summary to make a long page easier to navigate.
