# CSS Nectar

## What it is

CSS Nectar is a curated website gallery with a daily featured site, nominee and winner sections, search, and browseable categories. Gallery records include a thumbnail, maker credit and a link to the actual website. The submission form listed a $9 fee at review; browsing is free.

## When to open it

Open it when you want a quick shortlist of live marketing, portfolio or commerce sites, then follow the external link to inspect layout and interaction in context. The categories and winner lists are more useful than the homepage feed when you are looking for a particular kind of site.

## Most useful

- **[Category browser](https://cssnectar.com/css-gallery/nominees/categories/)**: start here to scan the gallery by category; also use the nominees and winners sections in the main navigation.
- **[UMT Website by Atomicdust](https://cssnectar.com/css-gallery-inspiration/umt-website/)**: the gallery detail links to the [published site](https://umtglobal.com/). On the live homepage, study the oversized split-weight “WHEN IT MATTERS” headline over a full-bleed freight photo, then how the navy navigation and lime action color carry into the sections below.
- **[Unbothered](https://cssnectar.com/css-gallery-inspiration/unbothered/)**: compare the nominee card with its [published site](https://unbothereds.com/). The live page uses a yellow-and-black comic-like grid and heavy condensed type. It is a useful example of a visually bold, high-contrast composition, not a recommendation of the site's subject matter.

## Using it with agents

The reviewed pages expose ordinary site links and gallery navigation; no public agent channel appeared. Use the gallery card to find candidates, then give an agent the published-site URL and a description of the actual design move after inspecting that live site. The card thumbnail is only a preview.

## Watch out for

- Quality varies across nominees and winners, and a paid submission does not itself establish design merit.
- The site thumbnail is not visual proof of the current live site. Check the linked site for present layout, responsive behavior and motion.
- CSS Nectar's terms leave submitted websites and their content with their owners. Do not treat a gallery entry as an asset licence.

## Reusable ideas

- Separate nominees, winners and featured work so discovery does not depend on one undifferentiated feed.
- Pair a visual preview with creator credit and a direct link to the published work.
- Offer browse paths by both site category and visual features such as color, typography or motion.
