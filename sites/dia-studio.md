# DIA Studio

## What it is

DIA Studio's homepage is a work archive: at review, hundreds of project images formed a tightly packed, mostly monochrome mosaic beneath a small masthead. Filter and Search controls sit alongside Work, About, Process and Index links. Opening [Nissan Journey to Zero](https://www.dia.studio/work/nissan-journey-to-zero) replaces the grid with a project view: a large media area, minimal title bar, next/close controls and project credits.

## When to open it

Open it to study how a studio can turn a broad archive into its homepage, or how project detail can live in an overlay without losing the path back to the grid.

## Most useful

- **Work mosaic**: images with varied crops and contrast create a dense contact-sheet effect; the small controls preserve room for the work.
- **Filter and Search**: separate entry points support browsing by collection and finding a known project.
- **Project overlay**: the title and Next/Close controls stay in a narrow top strip while media fills the page; credits and a short description follow the visual work.

## Using it with agents

No published agent channel was found. Ask an agent to inspect the live archive and a project overlay for grid density, filtering, media hierarchy and return navigation. Use the studio's work as visual reference only; no reuse licence was stated for its code, images or client work.

## Watch out for

- The archive's hundreds of media items make the page visually dense and can take attention away from a specific project; use the filters or search when looking for one.
- The project media may load progressively. The Nissan case opened with a brief loading state before its film and stills appeared.
- No public pricing or reuse licence was found at review.

## Reusable ideas

- Let project imagery establish a studio's character immediately, then keep navigation and search controls compact.
- Use a focused overlay for case studies when visitors need to move quickly between an archive and its details.
- Give media-first projects a clear title, short context and credits without building a second dense interface around them.
