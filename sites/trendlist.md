# Trend List

## What it is

An archive that sorts graphic design by appearance alone. Ondřej Zita and Michal Sloboda started it in Prague in 2011 to name the visual habits that move through print design, and the taxonomy it produced is the useful part: trends are named as devices, not moods. Left, Right, Up & Down (1,831 entries at review), Exposed Content (1,312), Center Aligned (1,283), Frame (1,128), IK Blue (1,093), Letterspace (1,036), Underlined, Staircase, Slash, Stretched, Scanned, Blank Cover, Repetition, Gradients, Type on Path, Redacted, Torn, 4 Corners. Fifty-eight in all, each with a count.

Under that sit tags by subject and material — typography, photography, book, flyer, packaging, monochrome, geometric — and a country filter that runs from Germany and France down to single entries. The grid is dense and variable-height, with a control for thumbnail size and a light or dark theme, over a hundred and twenty-eight pages.

Each entry is a page of its own: the piece, the studio, the country, the year, the trends it was filed under, and a link to the original source. The site is showing other people's print work and says where it came from.

## When to open it

Open it when you know the device you want — letterspacing, a frame, centre alignment — and need forty examples of it rather than one, or when you suspect the idea you are about to use is a trend and want to see how worn it is. It is a poor source for web layout: almost everything here is covers, posters, catalogues and invitations, and the translation to a browser is your work, not the gallery's.

## Most useful

- **The named trends themselves** are a working vocabulary: "staircase", "slash", "type on path" and "redacted" are things you can specify to another designer in one word.
- **Counts beside every trend**, which turn taste into evidence — a device with 1,831 entries is a convention, one with 8 is an experiment.
- **A country filter**, which shows that some devices are local scenes and others are everywhere.
- **Year filters back to 1990**, so a device can be traced rather than just sampled.
- **Credits and source links on every entry**, so a piece leads to the studio and eventually to the process.
- **An adjustable grid height**, which suits both scanning for a device and studying a single cover.

## Using it with agents

No `llms.txt`, API or JSON at review. Trend names and counts are in the page text, so an agent can read a filtered page and list the devices and their sizes; entry URLs are stable slugs, `/images/<slug>`, which are guessable when a page is cited in a brief. There is no bulk export, and the images should not be scraped.

## Watch out for

- It is a print archive. Type sizes, gutters and colours are for paper; a 4pt letterspace that works on a sleeve does not survive a 1440px viewport unchanged.
- Thumbnails are cropped covers, so the composition you see is the site's framing, not necessarily the full object.
- A count measures how often something was filed, not how good it is.
- The archive documents the dominant look of the last fifteen years, which means it will flatter whatever is currently fashionable.
- No licence is stated; treat every image as look-only and follow the credit to the source before reusing anything.

## Reusable ideas

- Name the formal device, not the feeling. It makes the reference findable and the instruction writable.
- Count your categories and publish the counts; it stops a taxonomy from becoming a wish list.
- Filter the same collection by device, subject and country, so one archive answers three different questions.
- Cite the maker on the thumbnail's own page, with a link to the original.
