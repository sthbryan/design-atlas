# OnePromptDesign

## What it is

A browsable image-prompt collection organized around visual categories such as posters, images, mockups, gradients and backdrops. The gallery pairs prompt text with generated-image examples and palette swatches; it is a source for visual direction rather than interface components.

## When to open it

When you need a quick moodboard starting point for an image-led campaign, poster, editorial composition or color palette. Use the images to compare art direction, then adapt the visual language to the actual interface or brief.

## Most useful

- The [gallery](https://onepromptdesign.com) uses a high-contrast editorial serif headline above a horizontal category capsule and a dense image grid; the changing image cards make it easy to scan distinct styles.
- **Velvet Editorial 09** appears in the gallery and opens a detail panel (no stable item permalink was exposed when checked) with the image, copyable prompt, descriptive tags and six editable swatches from deep blue-black through pale grey. This makes palette extraction concrete rather than leaving color selection to guesswork.
- Other visible examples include a white-stone modernist pavilion against red foliage and blue sky, and a grainy neon illustration, showing how the gallery spans distinct image treatments.

## Using it with agents

The prompt text can be copied from an individual item's detail panel. No public MCP, API, CLI or agent documentation was found during this review.

## Watch out for

- Public pricing and terms pages were not accessible during review, so rights for the generated images and prompts are not stated here. Treat them as references, not assets to republish.
- This is an image-art-direction reference; it does not provide UI layouts, component behavior or motion examples.

## Reusable ideas

- Pair a generated image with editable color swatches and concise tags so a visual reference can be translated into a usable palette.
- Keep category filters visible above a dense gallery, then expose the prompt and palette only when a visitor opens one example.
