# POP IS YOU SAKAE

## What it is

A campaign microsite for pop-culture events in Sakae, Nagoya. The 2026 page is live and names Aichi, Nagoya City and Sakae; the official organizers listed on the page include J. Front Retailing, Nagoya PARCO and Matsuzakaya. It brings a program of local art, animation, music and event listings together with a schedule and venue map.

## When to open it

- When you are designing an event guide that needs to connect listings with nearby physical venues.
- When a campaign needs to bring several organizers and event categories into one coherent identity.
- When you want to study a multilingual Japanese event page with an explicit path from introduction to program, schedule, map and campaigns.

## Most useful

- Browse the [2026 site](https://popisyousakae.com/) from its oversized POP IS YOU SAKAE identity through the Program, Schedule and Map sections. The header repeats the wordmark across Japanese, English, Chinese and Korean phrases; the program entries carry dates, venue names and category labels.
- In the [Map section](https://popisyousakae.com/#map), select venue toggles to relate places such as PARCO and OASIS 21 to their event listings. The page also has +/− map controls.
- Treat the campaign as a live design reference, while noting the event dates and ended states before using its content as current information.

## Using it with agents

No MCP, API, `llms.txt` or agent export was visible at review. An agent can inspect the page in a browser and use the visible map controls and section links. Map interaction depends on the embedded Google Map and browser scripting.

## Watch out for

- The campaign's listed dates are July 22–August 16, 2026, and most events are marked ended at review. The page remains useful as an archived visual and information-architecture example, but its schedule is not current event guidance.
- Some branding is delivered as images, so text extraction does not capture its full typographic treatment.
- No reuse licence for the page or event assets was stated. Use it as a look-only reference.

## Reusable ideas

- Connect program cards, a date grid and map markers so the same event can be explored by subject, time or place.
- Give a multi-organizer campaign one concise identity, then repeat it as a visual thread between functional sections.
- Expose map locations as a selectable list as well as map pins, so venue discovery does not depend on map interaction alone.
