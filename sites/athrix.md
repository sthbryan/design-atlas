# Athrix

## What it is

Atharvsinh Jadav's developer portfolio, with a profile, work history, skills, projects, GitHub activity and a keyboard command palette.

## When to open it

Open it when a portfolio needs a clear editorial identity while still presenting a long work history and project list.

## Most useful

The live page uses a faint dotted grid to mark a broad canvas, then aligns the main content to one narrow column. A large serif name and section headings contrast with sans-serif body text; small technology marks sit inline in the introduction. Soft leaf shapes at the page edges add color without competing with the text. The experience entries begin as sparse rows and expand into details.

## Using it with agents

No agent-facing integration was found. Use the visible page as a visual reference and verify any design choices independently.

## Watch out for

The decorative leaves and verified badge belong to this personal identity. Treat them as references for placement and scale, not reusable assets.

## Reusable ideas

- Use a low-contrast grid as a quiet alignment guide across a long page.
- Pair a serif display face with a neutral sans-serif for a clear editorial hierarchy.
- Keep decorative shapes near the canvas edges so they frame rather than interrupt the content.
