# One Page Love

## What it is

One Page Love is a gallery of single-page websites and landing pages. Rob Hope launched it in March 2008. In July 2026 it was acquired by Some Studio UG and is now curated by Piet Terheyden, who also runs Minimalissimo and Minimal Gallery. The site archive is separate from its cropped section archive. Site records include screenshots, a short review and tags for genre, style, platform, tech, typeface and colour. The site only accepts pages whose main navigation does not lead to separate pages, and rejects mockups and lightly edited templates.

## When to open it

Open it when you are building a launch page, waitlist, event page, personal page or portfolio that has to work as a single scroll. The section archive helps when you already know the page's outline and want to see how others handle one block, such as pricing, FAQ, testimonials or a lead-capture hero.

## Most useful

- **Style and genre archive**: [Brutalism](https://onepagelove.com/style/brutalism) is a direct route to tagged examples; combine style with a page type such as portfolio, digital product or landing page to narrow the visual reference set
- **Sections archive**: [page-section examples](https://onepagelove.com/sections) are grouped by block type and link back to the full page review. Use this when the design question is about one part, such as a hero, pricing table, FAQ or footer
- **Tech and platform tags**: filter for tools such as Tailwind CSS, GSAP, Next.js and Three.js, or builders such as WordPress, Webflow, Framer and Carrd
- **Typefaces archive** showing which fonts turn up across the gallery
- **Templates** split into free and premium, by builder and by category

## Using it with agents

A free MCP server is documented at [`/mcp`](https://onepagelove.com/mcp) and runs at `https://api.onepagelove.com/mcp`. It exposes one `search` tool; filter by style, genre, colour, section, platform or typeface. Each result includes a screenshot, the live site URL and its One Page Love record. For a request such as “a brutalist portfolio,” start with the [Brutalism archive](https://onepagelove.com/style/brutalism), choose two or three relevant records, then open each live URL in the browser and inspect the actual desktop and mobile layouts. Use the screenshot to locate the reference, then note its hierarchy, type, spacing, colour and interaction before adapting those decisions to the project. The separate API is still in private beta.

## Watch out for

- The MCP search is free and returns visual references; the separate API is not generally available while it remains in private beta
- Sponsor cards sit in the main grid (third position) and in the sections archive. They are labelled, but look like entries
- Treat archived screenshots as a starting point: verify that the linked site is still live and that its current design matches the screenshot before using it as a reference

## Reusable ideas

- Enforce one clear inclusion rule (a true single page) and publish examples of what is accepted and what is not
- Crop sections out of full-page captures and link each crop back to its source page
- Put the screenshot, live URL and archive record together so a designer can compare the capture with the current site
- Keep sponsors in the same card format, clearly labelled, instead of third-party ad scripts
