# Lovely Package

## What it is

An archive of packaging design, organised by what is inside the box rather than by style: alcoholic drinks, beer, and on through the categories a supermarket would recognise. Entries are photographic — a bottle on a coloured sweep, a box at an angle, a label shot flat — so the material and the print finish are as visible as the layout.

It is a print-first collection sitting in a design atlas about screens, and that is exactly why it is here: packaging is where colour systems, type hierarchy and material constraints are tested at their most brutal, and where a palette has to work on a curved, reflective, tiny surface.

## When to open it

Open it when a brief needs a colour system that survives being printed on something odd, when you want a reference for a limited palette on a small canvas, or when a brand identity needs applications beyond a website. Use it early, before the palette is fixed.

## Most useful

- **Category navigation that matches how people shop**, which is faster than searching by keyword.
- **Photography that shows finish** — foil, embossing, matte stock — the part a screen reference usually loses.
- **Repetition within a category**, so you can see how a shelf of competing products differentiates itself.
- **A search box**, since the archive is large and the categories are blunt.

## Using it with agents

No `llms.txt` at review: the path redirects rather than serving an index, and there is no API or MCP server. An agent can read the rendered category pages, but the collection is image-led, so the useful information is largely visual.

## Watch out for

- Everything here is someone else's packaging, reproduced as photography; nothing is licensed for reuse.
- Physical constraints drive most of the decisions, so a screen-only project cannot borrow them wholesale.
- The aesthetic skews premium and craft, which flatters every product on the shelf.
- Print colour and screen colour diverge; do not sample values from photographs.

## Reusable ideas

- Organise a visual archive by product category, not by design style.
- Shoot the object at an angle and flat, so structure and surface are both legible.
- Repeat the same crop across entries; comparison is the service.
- Let a print-first reference inform palette and hierarchy before the interface is drawn.
