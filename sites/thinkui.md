# ThinkUI

## What it is

ThinkUI is a hosted MCP server that gives coding agents interface references from real, shipped products: screens, user flows, ready-made components, animated icons and typefaces. You ask how a paywall frames a trial, and you get the screens other products shipped, with the project and source attached.

## When to open it

Open it when you want an agent to ground a design decision in shipped product UI instead of its training defaults.

## Most useful

- **Five tools, one library**: every plan uses the same tools and library, so the free tier is the real thing in miniature.
- **Beyond screenshots**: components, animated icons and typefaces, not only screen images.
- **Source attached**: each reference carries its product and source, so the agent can cite what it followed.

## Using it with agents

The MCP server is the product, with an `llms.txt` describing it. The free plan includes 12 tool calls with no card, which is enough to test the workflow.

## Watch out for

- The free tier is capped at 12 calls total; sustained use needs a paid plan.
- References are other products' UI; use them as direction, not as copied design.

## Reusable ideas

- Keep the tool surface small (five tools) and let the library do the work.
- Attach product and source metadata to every reference so agents can reason about provenance.
