# Business Cards on the Web — STstudio

## What it is

STstudio's case for a 2025 poster and browser-based business-card workshop held at Design Academy Eindhoven. The studio describes itself on its home page as working between Eindhoven and Seoul, and lists addresses in both places.

## When to open it

Open the [case page](https://www.ststudio.co.kr/work/cardsweb) for a compact reference that shows how a studio can present one print-and-web project with clear metadata and a strong art-directed image.

## Most useful

- The studio's black project page uses a fixed-looking split composition: title, tags and project metadata on the left; a Korean description on the right; and thin electric-blue lines radiating across the canvas.
- The poster itself sits lower in the page on an acid-green field. Engraving-like hands and embossed coin forms sit beside tightly arranged serif lettering, creating a deliberate contrast with the interface's monospaced labels.
- The case labels the work as Poster, Web and Development, with the client identified as Design Academy Eindhoven. The [home page](https://www.ststudio.co.kr/) uses a layered archive of project images to introduce the studio's work across print, web and space.
- The page offers Korean and English controls; the project description is visible in Korean on the English-selected view, so inspect the metadata and poster directly if the text is not readable.

## Using it with agents

No MCP, API, CLI, skill or `llms.txt` surfaced. The standard `llms.txt` path returns 404. An agent can use the English navigation and project tags in a browser, while the case description is available in Korean.

## Watch out for

- The poster sits below the opening project metadata, and an analytics choice dialog may cover part of it on a first visit. Declining optional analytics leaves the page available.
- The Eindhoven workshop is the project's client context; the studio itself lists bases in both Eindhoven and Seoul.
- No reuse licence for the poster or site assets was stated. Treat them as look-only.

## Reusable ideas

- Keep title, discipline tags and project facts in a stable column while giving the artwork a separate viewing area.
- Use thin lines as a page-wide graphic structure, then let one vivid project image supply most of the colour.
- Set concise project metadata in a monospaced face to distinguish it from the larger display typography in the artwork.
