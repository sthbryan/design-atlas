# SaaS Landing Page

## What it is

SaaS Landing Page is a WordPress-built gallery of SaaS marketing pages run by designer Davide Pacilio, who also runs the sister app-UI gallery SaaS Interface. The home page counted 840 landing pages at review. Each entry has a tall full-page screenshot, a short product summary, the fonts used, five palette hex codes, the build stack and tags. Separate lists cover pricing pages (64 at review), about, features, blog, testimonials, FAQ and contact pages. The advertising page says it has been running since 2018.

## When to open it

When you want to know which typefaces and colours a SaaS landing page uses, not just how it looks. You can also filter by font or stack to see, for example, every page set in Geist Sans or built with Next.js.

## Most useful

- **Font pages** (Inter, Graphik, Geist Sans, Suisse Int'l, Roobert, Tiempos Headline and more) listing the pages that use each typeface
- **Palette hex codes** on every entry
- **Stack filters** for React, Next.js, Tailwind CSS, Webflow, GSAP, Framer and WordPress
- **Page-type lists** for pricing, about, features, blog, testimonials, FAQ and contact pages
- **Template directory**: 83 SaaS templates at review, free and paid, for Framer, Webflow, React, HTML, Next.js, Tailwind CSS and Vue
- Arrow-key browsing between entries

## Using it with agents

There is no API, MCP or `llms.txt` (the path returns a 404 page). The pages are plain server-rendered HTML with a Yoast sitemap and an RSS feed, and the robots file allows crawling. An agent can read an entry's fonts, hex codes and stack as text. Use that as a starting brief and ask for an original layout, not a copy.

## Watch out for

- Paid "Sponsored" entries appear in the main grid next to curated ones
- Many outbound links (Mobbin, Beehiiv, Humblytics) are affiliate or referral links
- Nothing states how screenshots may be reused; treat them as look-only
- Font and stack data is gathered by the curator and may lag behind site redesigns

## Reusable ideas

- Record typefaces and a five-colour palette with every reference so the collection can be searched by style, not only by look
- Link each font to every page that uses it; that gives you a type-pairing index for free
- Keep page types (pricing, about, FAQ) as separate lists so each can be benchmarked on its own
