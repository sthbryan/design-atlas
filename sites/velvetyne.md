# Velvetyne

## What it is

Velvetyne Type Foundry (VTF) is a French non-profit association and collective. Frank Adebiaye started it in 2010, and about a dozen core members now run it from France, Belgium and Germany. It publishes libre, often experimental typefaces: pixel and ASCII faces, stencils, organic and "punk" display letters, and a few workhorse grotesques such as Grotesk, Karrik and Terminal Grotesque. The current catalogue has 41 typefaces. Each font page has a download, a link to the source files (mostly on gitlab.com/velvetyne), styles, tags, writing systems, a PDF specimen, the release date, a design story and photos of the font in use. In November 2023 the foundry retired 29 older families and published a list of where each one can still be found.

## When to open it

Open it when a poster, event site, zine, album cover or bold landing page needs a display face with real character, and you want one you're free to use, change and share. It's less useful for long body text or for products that need broad language support.

## Most useful

- **Catalogue sort**: "fresh first" or "unfamous first", which pushes lesser-used faces up so you don't pick the one everyone else uses
- **Source files**: most fonts link to a public repository, so you can fork one or add missing glyphs
- **Writing systems**: besides Latin, some faces cover Cyrillic, Greek, Armenian, Georgian, Tifinagh or Vietnamese
- **Design stories and in-use gallery**: each page explains how the font was made and shows real projects
- **Velvetyne Libre Friends**: an open list of other libre foundries, which the foundry publishes to spread attention beyond its own catalogue
- **Custom work and workshops**: the collective takes commissions and runs type-design workshops at schools

## Using it with agents

There is no API, llms.txt or package registry. Download the fonts yourself, commit the files together with their licence file, and have the agent write self-hosted `@font-face` rules and a sensible fallback stack. Don't point an agent or crawler at the site. In a February 2026 post the foundry wrote that AI agent scraping, up to about 500,000 requests a day, had knocked the server offline. It is now testing bot barriers, and it rate-limited this review after a few dozen page loads.

## Watch out for

- Not all fonts use the same licence. CUTE is a French-language licence, and the "Be Nice" licence is not OFL, so read the file before commercial use
- The FAQ asks you to credit the designer and Velvetyne whenever you use a font, or at least when you post photos of the work online. Donating doesn't replace this. It is the foundry's request on top of the OFL text
- The FAQ says many fonts are deliberately incomplete. Check accents, punctuation and numbers before you commit
- If you change an OFL font, keep the OFL and check whether the font reserves its name. If it does, your version needs a different name
- The foundry says it will keep retiring and changing fonts, so keep your own copy of anything you ship

## Reusable ideas

- Sort a catalogue by "least used" to fight sameness
- Put the licence, source link and writing systems in the same block as the download button
- Publish a clear list of what you removed and where it still lives, so links don't just die
- Ask for credit in a way that also works when a logo can't carry it (in captions, portfolios and posts)
