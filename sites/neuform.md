# Neuform

- **URL:** https://neuform.ai
- **Type:** AI builder · remix template gallery · prompt skills · DESIGN.md source
- **Topics:** design-md, agents-and-prompts, inspiration, landing-pages
- **Pricing / licence:** browsing is free; generating needs a paid plan (3-day trial with 20 prompts, then Pro $25, Max $50, Ultra $100 per month, or half that billed yearly). Commercial use for client work is listed only on paid tiers. The terms leave you responsible for the rights to anything you publish or reuse. No licence is stated for other creators' public templates, DESIGN.md files or skill prompts.
- **Reviewed:** 2026-09-25

## What it is

A prompt-to-page builder that appears to be a sibling of Aura: Aura's footer links to it as "HTML Designs", and several of its skills are credited to @mengto, Aura's creator. The public side is a community gallery of generated HTML pages ("remix templates"), where each template has its own design-system breakdown, plus a library of 71 prompt "skills" for styles, layouts and effects. You can open any template and remix it into a new page once you're signed in.

## When to open it

- When you want a WebGL-heavy or editorial-looking landing page direction and would rather start from a live, remixable example than from a blank prompt.
- When you need a ready-made style or effect instruction (border gradients, masked text reveals, framed grids, dither backgrounds) to paste into your own agent.
- When you want to see how one page's look breaks down into tokens and rules before writing your own DESIGN.md.

## Most useful

- The skills library: each skill page shows the full prompt text you can copy, the author, a usage count and the public designs built with it. The site states 71 skills and about 75.9K recorded uses.
- Template detail pages break a design into Overview, Typography (heading, accent and body families), Colors (primary, secondary, tertiary and neutral ramps from 50 to 900), Spacing (base rhythm and scale), Icons, Buttons, Elevation & Depth, Shapes (radius scale), Do's and Don'ts, Motion (durations and easing), plus WebGL and Three.js notes when the page has them.
- Community feeds (featured, trending, upcoming, pro) and filtering by tag.
- A Learn section of video walkthroughs on DESIGN.md-driven workflows.

## Using it with agents

- Skill prompts are plain text you can copy straight into Claude Code, Cursor or any other agent as a style or effect directive.
- Each template has a DESIGN.md tab. The sections above follow Google's DESIGN.md order with motion and WebGL added. Some public templates showed "no DESIGN.md content" to a signed-out visitor, so you may need an account to get the raw file.
- No MCP server, CLI or public API is stated. For agent access to the shared catalogue, see Aura's MCP.

## Watch out for

- The terms are only a few short paragraphs. They cover acceptable use and say you're responsible for generated content, but they grant no reuse licence for community templates or their DESIGN.md files.
- The free plan can't generate anything, and commercial use is tied to a paid subscription.
- Much of the gallery leans towards dark, WebGL-heavy hero sections, so it's a narrower palette than general DESIGN.md libraries such as [DESIGN.md](designmd.md) or [Refero Styles](refero-styles.md).
- Template descriptions are auto-generated boilerplate and don't say much about the design itself.

## Reusable ideas

- Pair every generated page with a structured design breakdown (type, color ramps, spacing, radius, motion) so a one-off page can become a system.
- Package reusable style or effect instructions as named, versioned "skills" with an author and a usage count, separate from any single page.
- Give each prompt skill "tuning knobs" and an "avoid" list, so an agent knows which settings it may change and which failures to steer clear of.
