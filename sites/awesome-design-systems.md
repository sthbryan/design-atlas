# Awesome Design Systems

## What it is

A maintained GitHub index of public design systems and pattern libraries. Each row links to a named system and marks whether it offers coded components, voice and tone guidance, a designer kit, or publicly viewable source code. The repository describes itself as a collection of design systems; it is a discovery index rather than a visual gallery or a source of reusable assets.

## When to open it

Use it to find a concrete system to study for a product area or to compare how organizations publish component code, design files and content guidance. For examples, follow the list's links to the [GOV.UK Design System](https://design-system.service.gov.uk/) or [IBM Carbon](https://carbondesignsystem.com/). These official sites are where you inspect the systems themselves; the index only discovers them and does not show their interface designs.

## Most useful

- **Capability columns** make it quick to shortlist systems that include code, design kits or voice guidance.
- **Direct links to individual systems** provide a starting point for focused comparisons. [GOV.UK](https://design-system.service.gov.uk/) separates styles, components and task patterns; [Carbon](https://carbondesignsystem.com/) links to design guidance, implementation and framework libraries.
- **Source links** help distinguish a public documentation site from a project that also exposes implementation code.

## Using it with agents

There is no MCP server, API, CLI or dedicated agent guide. The Markdown table is readable in the repository, so an agent can filter its rows by the capability columns and follow a selected system's official documentation. Verify each destination's current status and licence before relying on it.

## Watch out for

- The checkmarks describe whether material exists, not its quality, completeness or current maintenance.
- Some destinations are old, changed or unavailable; verify the linked system before recommending it.
- The licence on this repository applies to the index, not to the linked systems, their code, design kits or brand assets.

## Reusable ideas

- Describe what a reference contains with a small, consistent set of capability fields.
- Link discovery entries directly to the authoritative design system and, where available, its source repository.
- Use an index to find examples, then inspect the official system for actual visual and implementation details.
