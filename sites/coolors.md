# Coolors

## What it is

Coolors is a palette-making and color-reference site. Its fast generator lets you hold selected swatches while cycling the rest, and its visualizer applies a palette to example designs. Other tools extract colors from images, inspect color values and test text/background contrast. A free account has limits; Pro unlocks the full library, all palette visualizer layouts, more saved work and other tools.

## When to open it

- When you need quick color directions and want to compare them on a composition instead of judging five swatches in isolation; open the [Palette Visualizer](https://coolors.co/visualizer/fffd98-bde4a7-b3d2b2-9fbbcc-7a9cc6).
- When you want to extract a palette from a mood-board image or check a specific text/background pair.
- When browsing palettes by color, theme or mood before forming your own system.

## Most useful

- **[Palette Visualizer](https://coolors.co/visualizer/fffd98-bde4a7-b3d2b2-9fbbcc-7a9cc6)**: its Mobile/Web UI category places the selected palette onto interface mockups; separate Branding, Typography, Pattern and Illustration categories make it possible to compare other uses. At review, the page showed several included designs and a Pro gate for the full set.
- **Palette generator**: lock the colors worth keeping and regenerate the remaining slots; the palette URL preserves the color sequence for sharing.
- **Image Picker**: sample a source image to make a starting palette.
- **Contrast Checker**: test a foreground/background pairing against text-size contrast thresholds.

## Using it with agents

There is no published MCP, API, CLI, registry, skill or llms.txt. The generator and visualizer can be inspected in a browser, while account-based saving and some layouts require a user. The site licence explicitly bars scraping or stockpiling palettes, so use it interactively and do not build an agent that harvests its palette catalogue.

## Watch out for

- Treat the mockups as color-placement studies, not finished layout or component recommendations.
- Some visualizer examples and palette checks are Pro-only; the free visualizer has fewer layouts.
- The palette licence permits use in your own products but not distributing palettes as standalone collections, embedding them in templates or registering them as a brand mark.

## Reusable ideas

- Put color previews into distinct design contexts, so the same palette can be judged on UI, type and graphic patterns.
- Lock useful values while exploring alternatives for the remaining roles.
- Offer direct contrast checks alongside the palette rather than making users copy colors into another tool.
