# Uizze

## What it is

Uizze is a UI reference library for AI agents: 800,000+ real web and iOS screens with full user flows, searchable by what you are designing next. It arms Codex, Claude Code, Cursor and similar agents with product-specific references so they stop shipping generic UI.

## When to open it

Open it when an agent keeps producing the same generic patterns and you want to point it at real shipped screens for a specific flow, such as a paywall or onboarding.

## Most useful

- **Flows, not just screens**: complete journeys, so the agent sees the sequence, not only the frame.
- **Search by intent**: ask what you are designing next and get the relevant screens and journeys.
- **Agent-first positioning**: the library is packaged for coding agents from the start.

## Using it with agents

An `llms.txt` describes the library for agents, and the site promotes use with Claude Code, Cursor and Codex. Access to the full library is paid.

## Watch out for

- It is a paid library ($9 a month or $199 lifetime at review); the free surface is limited.
- Screens belong to their products; use them as references, not as assets to ship.

## Reusable ideas

- Index references by flow (paywall, trial framing) so an agent can ask for the moment it needs.
- Pair a large screenshot corpus with an agent-readable index, not just a gallery.
