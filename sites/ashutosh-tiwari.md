# Ashutosh Tiwari

## What it is

A personal portfolio that combines an illustrated profile, project collection, work history, technical stack and writing in a long page. The site includes a light/dark theme control and a command-palette button.

## When to open it

Open it for ideas on giving a dense developer portfolio a clear visual frame, or on combining a personal hero with detailed project and career sections.

## Most useful

The wide, colorful landscape illustration acts as a strong opening panel above a structured profile block. Dashed grid rules and small corner marks carry through the page, while project entries pair a title and description with technology labels. The compact search shortcut opens a command palette; a separate Projects route provides a deeper view of the work.

## Using it with agents

The footer links to `llm.txt`, so an agent channel is advertised. The linked file could not be opened in the browser at review; provide the portfolio URL and inspect the destination before relying on agent-specific guidance.

## Watch out for

The illustration and long résumé-style page may dominate a portfolio with little project material. Check the theme toggle and narrow layout before borrowing the full frame. Project screenshots and text belong to their creators.

## Reusable ideas

- Let one panoramic image establish the page's mood, then keep the profile and work details in a consistent grid.
- Use fine dashed rules and small registration marks to make section boundaries part of the visual identity.
- Put a keyboard shortcut beside search so a long portfolio remains quick to navigate.
