# Websitevice

## What it is

Websitevice is a website example directory organized by business and site categories, including agencies, artists, ecommerce, healthcare, portfolios, restaurants and SaaS. The homepage pairs each outbound link with a short note about the design feature or page structure that stands out.

## When to open it

Open it when the design brief starts with an industry or organization type and you need real examples for that context.

## Most useful

- Browse the category list at the left, then scan the screenshot cards and descriptions for examples relevant to the intended business.
- The [artist section](https://websitevice.com/artist-examples) links to Fernando Mastrangelo's [live studio site](https://mastrangelo.co/). It uses a spare white canvas and condensed all-caps navigation above oversized artwork photography, a useful arrangement for an artist portfolio.
- Its annotations call out concrete choices such as full-screen sliders, color pairings, photography, and layout, giving a quick reason to open a card.

## Using it with agents

No MCP, API, `llms.txt` or agent-specific interface was visible on the reviewed pages. An agent can browse category pages, read the short annotations and follow links to live sites. Verify the original before recording its present design.

## Watch out for

- The categories emphasize business type and use case; browse the live page for the specific visual details you need.
- No general reuse licence was stated for the directory's references. Use them as visual research and check source terms before reusing assets or code.

## Reusable ideas

- Organize visual references by the real-world context in which a site needs to work.
- Add a concise rationale to each example so readers can scan for a specific layout, image treatment or color decision.
