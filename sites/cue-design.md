# Cue

## What it is

Cue is a curated library of web interactions and UI components, arranged by type and visual technique. Cards lead to a specific demo and a short description, with tags that help locate treatments such as conic gradients, dark UI, scroll animation or WebGL. Its value as a reference is the breadth of finished interactions and the way the catalog groups them, rather than a single house design system.

## When to open it

Use Cue to find a concrete interaction treatment for a chat input, page transition, loader, hero, slider or visual effect. Browse the featured picks for visual direction, then filter by component category or technique to compare more targeted examples.

## Most useful

- The Signature Picks row surfaces selected examples before the longer feed; further down, categories such as WebGL make a technique easy to explore.
- A selected card opens a side panel while keeping the gallery visible. The panel combines a large demo, an italic editorial title, compact technique tags and access details.
- The inspected Morphing Glow Chat Input uses a dark surface with a thin pink-to-orange edge glow; its glow contracts into a spinning conic-gradient border during processing.
- Individual cards identify whether a prompt or source is included and whether access is premium, so the gallery gives a quick sense of which examples can be studied immediately.

## Using it with agents

Some entries provide copyable prompts intended for tools such as Cursor, v0, Bolt, Framer AI and Claude. Free access is limited; premium prompts and some examples require Cue+ or an individual purchase. The separate Cue Kit is MIT-licensed, but that licence does not apply to the Cue gallery or its other content.

## Watch out for

- The prompt and React source access differs by component. Check the access label on the individual card before planning around it.
- Cue's licence terms for the gallery content are not stated; treat its examples as look-only unless a component's own licence says otherwise.
- Several effects are intentionally expressive. Reduce glow, contrast and motion to fit the surrounding interface.

## Reusable ideas

- Put a live component preview beside its technique tags so the visual can be recognized before reading implementation detail.
- Show the visual states of an interaction, especially idle and processing, in the same example.
- Let category and technique filters work together when one pattern crosses multiple component types.
