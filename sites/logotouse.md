# Logo To Use

## What it is

A hand-curated library of well-known company logos, built for people who need a realistic mark inside a mockup, deck or template. The catalogue is organised around the one decision you actually make when placing a logo: which version. Every mark is offered coloured, black and white, in SVG and PNG, plus an editable Figma file, and a Pro tier adds bulk ZIP download. At review the site claimed more than 50 logos in its Figma community file and offered the same set inside a Webflow app and a Sketch file.

## When to open it

Open it when a design needs a plausible logo row, an integration grid or a client mockup and the marks have to look right in both a light and a dark surface. The three-variant toggle is the reason to be here rather than searching each brand's press kit.

## Most useful

- **Variant toggle**: coloured, black and white side by side, which is exactly how a logo row fights with a dark mode.
- **Format coverage**: SVG for layout work, PNG for quick comps, Figma for a file you can edit.
- **"Famous & Cool" showcase** sorted by most downloaded and most liked, which surfaces the marks people actually reach for.
- **Bulk ZIP on Pro**, useful when a template needs sixty logos at once.
- **Figma and Sketch starter files**, so the assets arrive in the tool rather than in a downloads folder.

## Using it with agents

No `llms.txt`, API or export was found at review. The catalogue is readable as text, but downloads sit behind the account and the Pro tier, so an agent cannot fetch assets. The honest workflow is a person downloading the SVG set and the agent wiring it into a logo component with the right sizing and colour rules.

## Watch out for

- These are trademarks. A commercial licence from the site covers its own files, not the right to imply endorsement or to use a mark as your brand.
- Promoted placements sit in the header and between sections — including for Modulify, the same group behind Ikonik — so the page is part advertising.
- Pro gates the formats that matter for real work: SVG, Figma and bulk download are paid, the free tier is browsing.
- Logo sets age badly: rebrands are not always tracked, so check the brand's own press page for anything current.
- The library shows marks for reference, not the brand guidelines that govern clear space and minimum size.

## Reusable ideas

- Offer every asset in the three variants designers actually need, in the same view, instead of a separate downloads page.
- Show a light and a dark surface preview next to the file types.
- Sort a library by what has been downloaded most; it is a better default than alphabetical.
- Ship the same set as an app inside the design tool, not only as files.
