# TOOOLS.design

## What it is

A directory of design tools and resources with category pages for inspiration, UI, icons, illustrations, motion, typography and more. The dedicated [inspiration index](https://www.toools.design/ui-web-design-inspiration-websites) groups external galleries and reference sites by subject.

## When to open it

Use the inspiration index when you need to discover a source for a particular format, such as dark-mode websites, mobile screens, motion, portfolios or landing pages. The page links directly to sites such as [Dark Mode Design](https://www.darkmodedesign.com/) and [Mobbin](https://mobbin.com/).

## Most useful

The inspiration page uses category chips to jump through a long directory, then presents each source as a labeled card with a short description and free, paid or freemium marker. Its UI section separates screenshot archives and interface references from general web galleries; its web section lists live-site galleries. TOOOLS is a discovery route, not a visual example itself. Follow a listing to the source and inspect current pages there.

## Using it with agents

No MCP, API, CLI, `llms.txt` or agent-specific access was found at review. The directory is browser-readable, but its legal notice expressly prohibits automated retrieval and AI data mining of the site's contents. Use it manually to find a source, then check that source's own agent access and licence.

## Watch out for

The home page includes affiliate links, partner picks and sponsored placements; the site marks those sections. Its legal notice says affiliate relationships do not influence selections, but check whether a specific entry is marked as a partner. The resource listing is not a licence grant for the linked tools or assets.

## Reusable ideas

Narrow discovery by the kind of interface or asset you need, then inspect the destination directly. Record the source and its current terms, since a directory's pricing label and short description are only a starting point.
