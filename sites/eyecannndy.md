# Eyecandy

## What it is

A visual technique library organized around searchable terms such as flash cut, floating UI, match motion, split screen and typography. Each technique page pairs a short explanation with a broad grid of attributed clips and stills.

## When to open it

Use it when a motion or art-direction brief names an effect loosely, or when you need visual examples to clarify the timing, framing or treatment. It is a film and video reference, so translate the observed technique to interface context rather than copying the footage.

## Most useful

- [Flash Cut](https://eyecannndy.com/technique/flash-cut) pairs a plain definition and photosensitivity warning with a dense, varied example grid.
- [Floating UI](https://eyecannndy.com/technique/floating-ui) is a direct route for studying composited interface elements in moving image.
- The homepage puts a large set of technique names in one compact index, then lets you search and sort the matching visual cards.

## Using it with agents

There is no published API or agent integration. An agent with a browser can use the named technique index and stable `/technique/<slug>` pages to inspect examples. Preserve the source link and describe the useful beat or framing in your own words.

## Watch out for

The library says it is a work in progress and that category names can be informal. Its terms identify the material as copyrighted and intended for educational fair use; they say not to publicly use or distribute footage without permission. Some pages also include a photosensitivity warning. Treat the clips as references, not reusable assets.

## Reusable ideas

- Put a clear technique label and a one-paragraph explanation beside examples, so a visual effect can be found by name and understood before viewing.
- Keep the index searchable while preserving a direct URL for each named technique.
- Use several examples to show the range of one effect rather than presenting a single clip as a definitive recipe.
