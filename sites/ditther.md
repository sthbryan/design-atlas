# Ditther

## What it is

Ditther is a browser-based image and video editor centered on dither, pixel, ASCII, halftone and print effects. Its public effects gallery and Learn tutorials make the site useful as a visual reference as well as a tool.

## When to open it

- When a poster, background or illustration needs a constrained-palette, screen-printed or text-rendered treatment.
- When comparing how dot density, character fields and block shapes affect image contrast and legibility.

## Most useful

- **Effects gallery**: individual pages for [dither](https://ditther.com/effects/dither/), [ASCII](https://ditther.com/effects/ascii/), [Lego](https://ditther.com/effects/lego/), [halftone](https://ditther.com/effects/halftone/) and [pixel art](https://ditther.com/effects/pixel-art/) show different ways to reduce a photograph to a repeatable graphic pattern.
- **Live examples**: the homepage cycles through Japanese and Latin character fields, dots and halftone over photographs, so compare the image's tonal structure with the resulting pattern.
- **Poster tutorials**: [editorial poster](https://ditther.com/learn/editorial-poster/) and [retro game poster](https://ditther.com/learn/retro-game-poster/) combine image effects with text, gradients and shapes in complete compositions.
- **Editor**: layer text and shapes over images, stack treatments, then preview motion; the free tier exports up to 1080p, while 4K and higher-end video exports are paid.

## Using it with agents

There is no published MCP, CLI, registry or agent-readable reference at review time. Link an agent to a specific effect or tutorial page for visual direction; the editor itself is an interactive browser app.

## Watch out for

- The tool is a visual editor, not a code component library; its gallery demonstrates appearance rather than providing reusable CSS or assets.
- The free tier has export limits, and the site's terms URL redirected repeatedly during this review. No licence for its site images or editor output was confirmed.
- Check readability after applying dense patterns, especially behind small text and controls.

## Reusable ideas

- Match dither frequency and contrast to the source image's tonal range instead of applying one screen uniformly.
- Keep text and shape layers separate from image treatments so poster hierarchy remains adjustable.
- Use a small set of distinct pattern families to create contrast between foreground, background and supporting imagery.
