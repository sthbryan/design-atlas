# Flowbase

## What it is

Flowbase is a subscription library of website sections for Webflow, Figma and Framer, run by Flowbase Pty Ltd in Brisbane, Australia, since 2017. According to its own `llms.txt` and pricing page, Pro+ includes 3,500+ premium components, 1,000+ "Chalk" wireframes, 1,000+ illustrations and 15,000+ icons. It also includes "Boosters", copy-paste scripts and attributes that add behaviour to Webflow sites. Components are grouped by section type (headers, navigation, features, pricing, FAQ, testimonials, blog, integrations, footers) and released in named families. You copy them from the website or through a Chrome extension, a Figma plugin or a Framer plugin.

## When to open it

When a site is being built in Webflow and you want finished, responsive sections to paste instead of building from divs. The wireframe set is useful earlier, for blocking out page structure with a client before any visual design exists.

## Most useful

- **Webflow components**: the core of the library, with interactions already set up.
- **Chalk wireframes**: a grey, low-fidelity system for planning layouts in Figma, Webflow or Framer.
- **Boosters**: no-code scripts for common Webflow gaps, some free and some premium.
- **Icons and illustrations**: a large SVG set mixing open-source and premium items.
- **Free tier**: about a hundred components and the plugins, enough to judge the quality.

## Using it with agents

Not agent-ready for code. There is an `llms.txt`, but it only describes the product and links to pages; it does not expose components. Everything is copied to the clipboard in a builder's own format, and there is no API, registry or MCP server for design assets.

## Watch out for

- The licence ties use to an active subscription, and Flowbase says it monitors copying and may cut off accounts for excessive copying.
- Monthly accounts are capped at 200 component copies a month.
- Copying components does not work in Safari, according to the pricing page.
- Templates are not included in Pro+, even though they appear in the same library.

## Reusable ideas

- Offer a matching wireframe layer, so structure can be agreed before visual design starts.
- Release sections in named families, so pieces from one family look consistent together.
- Ship small behaviour scripts next to layouts to fill gaps in a no-code builder.
