# Wedoflow

## What it is

Wedoflow sells Webflow templates: 216 at review, priced individually between $39 and $169, with an all-access pass for the whole library. The catalogue is the interesting part. Every card carries the same three pieces of information in the same order — template name, price, vertical — so the grid reads as a sortable list rather than a mood board: Catania (Consulting), Maxero (Startup), EcoFusion (Investment), Marmaris (Architecture), Tuna (Restaurant), Zagreb (Law Firm), Melbourne (Interior design). Names are place names, which keeps them memorable without describing the design.

## When to open it

Open it when you need a complete marketing page for a specific trade and want to compare how several designers handled the same brief. Filter by vertical, not by style, and open three or four in the same row to see the house patterns repeat.

## Most useful

- **Vertical labels**: finance, medical, education, architecture, restaurant, law firm and event sit beside SaaS and agency, so you can find references for briefs that generic galleries ignore.
- **Price as a design signal**: within one vertical, the $129 templates tend to be the ones sold hardest, which makes it easy to compare the more elaborate previews against the $79 baseline.
- **Uniform card anatomy**: name, price, category, download action. No tag soup, no masonry.
- **"1,300+ unique pages"** claim, which sets expectations that inner pages ship too, not just a homepage.
- **All-access economics**: one pass covers every template, so the library is priced as a research budget as much as a build budget.

## Using it with agents

No `llms.txt`, API or export was found at review, and the preview is rendered inside Webflow, so an agent reading the page gets names and prices but not layout. Treat it as a human shortlist tool: a person picks the template, then the agent works from the exported page or a screenshot.

## Watch out for

- A 95% off countdown sits above everything, and the all-access page pushes urgency. The discount, not the catalogue, is being sold.
- The licence is a Webflow template licence. Buying does not license the fonts, photography or illustrations inside, and none of that is spelled out on the listing.
- Prices vary $39 to $169 with no visible difference in what you get, and all catalog cards say "Subscribe to Download" even for single purchases.
- Templates repeat one structure across verticals. Copying a layout wholesale produces a site that reads as a template.
- Cards are all the same shape, so nothing tells you whether a preview is worth opening beyond price.

## Reusable ideas

- Label every catalogue item with the brief it answers, not just the style it uses.
- Keep one card anatomy across a large catalogue and resist adding badges.
- Name items so they can be spoken in a meeting; the place-name convention does that.
- If you sell a pass, say what the pass includes per item, not just the discount.
