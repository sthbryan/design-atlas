# VividSites

## What it is

VividSites is a library of website-building prompts paired with the source video used for each example. The home page shows free and premium cards, including named concepts such as Brand New Day, Plinth, Massif and Murmur; filters narrow the library by page type and theme. The pricing page listed 228 prompts at review.

## When to open it

Open the [library](https://www.vividsites.app/#library) when you want to explore several visual directions, then follow one prompt and its source video to understand how the reference is assembled. It supports website discovery as well as prompt-based recreation.

## Most useful

- Search or filter by type, such as landing page, hero or 3D section, then narrow by a theme like travel, architecture, fashion or product.
- Start with the free entries to inspect the card treatment and linked visual. Premium items are marked in the library.
- Use the [MCP page](https://www.vividsites.app/mcp) to search the live library, fetch a prompt and wire its video background into a coding assistant. Free prompts work without a key; a key unlocks the account's premium prompts.
- The [pricing page](https://www.vividsites.app/pricing) offered $19 monthly, $49 yearly and $199 lifetime access at review.

## Using it with agents

The site provides a remote MCP connector and an install path for Claude Code, plus a `video-sites` skill for assistants that do not use MCP. The documented server can search the library and fetch prompts; premium access needs the account API key. Treat that key as a secret, as the connector URL includes it.

## Watch out for

- The terms permit using prompts, components and hosted assets to build commercial sites, but forbid redistributing the prompts, videos, components or guides or turning them into a competing library.
- A prompt and its source video demonstrate one direction. Inspect the linked site or build result before treating it as evidence of a complete, working website.
- The library count and plan prices can change; both figures above are at review.
- The root `llms.txt` route could not be checked because the browser blocked the request twice; the MCP documentation was available.

## Reusable ideas

- Connect each reusable prompt to the visual source that inspired it, so users can compare intent with result.
- Combine search, page-type filters and theme filters to support both deliberate queries and open-ended visual discovery.
- Mark free and gated entries on the card itself, before a user commits to opening or copying an item.
