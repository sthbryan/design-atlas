# Droppy Code

## What it is

Droppy Code is a free, open-source macOS workspace for coding agents. Its product site documents the native app with annotated screenshots of chats, diff review, model controls, floating panels and a 26-theme tinted-glass palette.

## When to open it

Use it as a reference for a dense native desktop workspace, especially when multiple chats, side panels and provider-specific states need to coexist without losing the main conversation.

## Most useful

- The Hydra section shows parallel work as subordinate agent rows and status pills within the lead chat.
- The “Panels that snap” examples demonstrate docked and floating panels that adapt to available screen width.
- The feature rail documents questions, queued follow-ups, per-turn diffs and a command palette as concrete interaction states.
- Theme examples show how the same translucent surfaces can take on distinct colour identities.

## Using it with agents

The app is itself an agent workspace rather than an agent-accessible design catalogue. The GitLab source and AGPL-3.0 licence are linked from the download section for inspection.

## Watch out for

- This is a native macOS product, not a web component library; use the screenshots to study composition and interaction, not as drop-in web assets.
- The interface depends on macOS 26 Liquid Glass and Apple silicon.
- The product name and icon are excluded from the source licence.

## Reusable ideas

- Let secondary work appear in adjacent panels while keeping the active conversation visually dominant.
- Use compact status pills to summarize asynchronous work without duplicating its full transcript.
- Carry provider colour into a shared control such as an effort slider to explain a multi-provider setting.
- Offer a small, structured set of tinted themes while retaining common surface geometry.
