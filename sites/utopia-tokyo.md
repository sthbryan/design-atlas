# Utopia Tokyo

## What it is

Utopia Tokyo is an interactive story about traditional Japanese masks in a surveilled, futuristic city. The home page combines a mask showcase, a short setting description and a character builder with six adjustable attributes.

## When to open it

Open it when you are shaping a bold editorial landing page, a story-led 3D experience, or a character-customization flow that needs to feel part of the world.

## Most useful

- **Safety choice**: an opening notice explains the high-contrast effects and fast transitions, then offers Safe Mode before the experience begins.
- **Hero grid**: saturated red fills a heavy black grid. An oversized outlined wordmark spans the top, while a three-part headline, mask carousel and compact story copy occupy separate ruled panels below it.
- **Mask collection**: a later section can present the masks as a grid or list, then gives each one a clear visual identity within the larger fictional setting.
- **Character builder**: six paired Japanese and English stats use sliders, a total and a mask preview to make customization legible as both game UI and art direction.
- **Supporting frame**: coordinates, version labels, monospace microcopy and corner-cut panel edges keep the interface inside the same sci-fi visual language.

## Using it with agents

No agent interface or `llms.txt` was found; `/llms.txt` returned a designed not-found page. The browser exposes the page's headings, text, mask names and builder controls, so an agent can inspect the structure as well as the live visuals.

## Watch out for

- The site warns that high-contrast visuals and rapid transitions may trigger photosensitive seizures; it offers Safe Mode at entry. Keep this kind of choice visible before effects begin.
- The experience uses large visual panels and small technical labels. Check text size and keyboard access in the exact flow you are building.
- No reuse licence for the site or mask artwork was stated. Treat it as a visual reference only.

## Reusable ideas

- Put a clear safety choice before a visually intense experience and make the reduced-effects route easy to find.
- Use one consistent grid to connect the identity, story, image carousel and controls.
- Pair each fictional or technical label with plain-language context so the visual world remains understandable.
