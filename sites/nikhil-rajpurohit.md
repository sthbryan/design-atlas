# Nikhil Rajpurohit

## What it is

A compact personal portfolio with a short introduction, experience, GitHub activity, projects, sponsorship information and writing. A small theme switch sits beside the profile header.

## When to open it

Open it when exploring a text-led portfolio that gives projects and writing room without relying on a large hero image or a card-heavy landing page.

## Most useful

The centered column uses generous white space, small profile imagery and restrained type; the name is set in a serif face while the surrounding copy stays plain and readable. Section labels use a simple `#` prefix. Project links carry concise descriptions and stack icons, and experience items expand in place. A subtle hand-drawn pointer connects the avatar to the name.

## Using it with agents

The footer links to an `index.md` page, but the browser could not open that Markdown destination at review. No MCP, CLI, API or installable skill was visible on the home page.

## Watch out for

The minimal presentation depends on readable text and spacing, so it offers fewer visual cues for scanning many projects. The theme switch was visible, but mobile behavior and its alternate state were not verified.

## Reusable ideas

- Let a narrow text column and generous vertical gaps carry a portfolio when imagery is not the main content.
- Keep section titles and project metadata quiet so short descriptions remain the visual focus.
- Use disclosure controls for secondary career details instead of showing every line at once.
