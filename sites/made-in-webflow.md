# Made in Webflow

## What it is

Made in Webflow is a searchable showcase of sites built by the Webflow community. Visitors can browse categories including Animation, Interactions, CMS, Ecommerce and Portfolio, sort results, and filter for sites marked cloneable. A detail page separates the showcase thumbnail from links to a preview and the published live site.

## When to open it

Open it when you need to inspect a real, published site or find an interaction that can be studied and, where explicitly allowed, cloned in Webflow. Use the filter controls to move from broad discovery to a particular category or cloneable project.

## Most useful

- **[Showcase](https://webflow.com/made-in-webflow/showcase)**: filter by Animation, Interactions, CMS, Ecommerce or Portfolio, then enable “Cloneable sites only” when you need a project the author has made clonable.
- **[Clone - Background Parallax by Aaron Ocampo](https://webflow.com/made-in-webflow/website/true-background-parallax)**: the detail page has both **Open in Webflow** (a preview) and **Open live site** links. On the [published site](https://wf-background-parallax.webflow.io/), scroll to see the background image move beneath the fixed “Background Parallax” heading.
- **Webflow MCP**: the [official setup docs](https://developers.webflow.com/mcp/reference/getting-started) describe an MCP server that connects an agent to Webflow projects. Use it with sites and access you are authorized to edit; the showcase itself is a reference directory.

## Using it with agents

Webflow documents an MCP server at `https://mcp.webflow.com/mcp` for connecting agents to Webflow projects. A showcase entry is usable through that server only if it is cloneable and the user has the necessary Webflow access; agents can then inspect and customize the authorized clone. The directory and project pages remain useful as ordinary browser references.

## Watch out for

- A card thumbnail or preview frame is not the same as the published site. Use the separate live-site link to inspect the actual page and its interactions.
- Only clone projects whose creators enabled cloning, and use Webflow's clone flow rather than copying their content or assets into another project.
- Publishing a showcase listing requires a paid Site or Workspace plan. Browsing the public showcase is free.

## Reusable ideas

- Let visitors distinguish a live preview from a source project or clone action before opening it.
- Make interaction categories and a cloneable-only filter part of the discovery controls.
- Keep the creator, project detail, preview and published site connected but clearly labeled.
