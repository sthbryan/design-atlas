# 23rd

## What it is

A small shadcn registry of deliberately opinionated, effect-heavy components by a solo developer who goes by radiumcoders (Jay). Its `llms.txt` listed 14 components at review, grouped as backgrounds, shaders, footers, characters, pages and sections, and every one ships twice: a React item and a Svelte 5 item (28 registry entries). Each is built as a framework-free engine with thin React and Svelte wrappers. The repo started in July 2026, had about 120 stars at review and was updated the day before.

## When to open it

When a landing page needs one memorable moving piece rather than a kit: a WebGL sky or fire behind the hero, an ASCII wordmark that scatters on click, a footer with rubber overscroll, or a 404 page that burns under the cursor. It is also one of the few registries in this space that serves Svelte 5 as well as React.

## Most useful

- Three quiet WebGL hero backdrops (gradient wash, sparse fire, sky with clouds or rain) that follow the light or dark theme
- ASCII pieces: a fluid background quantised to characters and an interactive ASCII logo
- Two unusual footers: stretchy overscroll with an aurora, and nested rings of circular marquee text
- A dithered, Bayer-pixel 404 section

## Using it with agents

`/llms.txt` gives a one-line description and docs link per component, and `/r/registry.json` is the index. Install with the CLI through the `@23rd` namespace (`pnpm dlx shadcn@latest add @23rd/shader-gradient`, or the `-svelte` variant), or straight from GitHub. The repo also ships a beta agent skill, installed with `npx skills add radiumcoders/23rd.dev --skill 23rd`, that describes which component fits which job, its real props, and when not to use it.

## Watch out for

- No licence: the GitHub repo has no licence file and the registry items carry none, so reuse rights are not stated; ask the author before shipping
- Very small and very new; expect the list and APIs to change
- Several pieces are WebGL or canvas effects, so check performance and reduced-motion behaviour on low-end devices

## Reusable ideas

- Write each effect as a framework-free engine and wrap it per framework, so one source serves React and Svelte
- Include "when not to use this" guidance in the agent skill, not just install steps
- Sell sponsorships as visible placement only, keeping every component free
