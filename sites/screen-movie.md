# Screen Movie

## What it is

Screen Movie is a native macOS screen recorder and timeline-based video editor. Its product site demonstrates animated screen captures, 3D device mockups, cursor treatments and backgrounds as finished product-demo videos.

## When to open it

- When planning motion for a product walkthrough, launch clip or feature announcement.
- When a static screenshot needs to become a framed, cursor-led sequence with captions or camera footage.

## Most useful

- **Hero composition**: the [homepage](https://screen.movie/) layers a blue-to-orange light field behind a centered app icon, compact navigation and oversized two-line headline.
- **Motion examples**: the feature sections show cursor-following zooms, tilted screens, 3D devices, animated text and scene-to-scene timeline transitions.
- **Background treatments**: gradient and shader examples show how soft color fields can separate a framed UI capture from a dark canvas.
- **Templates and effects**: the editor includes 40+ motion presets, cursor effects, 3D rotation, captions and music.

## Using it with agents

There is no MCP, CLI, registry or agent guide visible at review time. This page is a visual reference; the app is a paid Mac download.

## Watch out for

- The app is a paid proprietary product, listed at $39 for one device during an early offer and $79 regular price; exact current checkout price may change.
- Terms allow built-in assets in exported videos but prohibit extracting or redistributing those assets as separate files.
- Most references are motion-video examples rather than production web components; watch at the target size and keep zooms slow enough to preserve interface context.

## Reusable ideas

- Use cursor position and movement to guide attention toward one feature at a time.
- Change scale and perspective gradually so viewers retain the location of interface elements.
- Give each scene a single purpose, then use captions and transitions to connect the steps.
