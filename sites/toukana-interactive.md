# Toukana Interactive

## What it is

Toukana Interactive is an indie game studio site. Its homepage uses a side-by-side carousel of game worlds, followed by numbered feature panels; the Dorfromantik page carries that artwork into a broad hero with platform buttons.

## When to open it

Open it when a studio or entertainment site needs to present several projects while giving each one a distinct visual identity. The homepage and Dorfromantik page show how a studio can move from a compact game index into a focused launch page.

## Most useful

- **Split homepage carousel**: two differently sized panels show adjacent projects at once, with large edge arrows and a small menu button.
- **Numbered project story**: the homepage uses a three-part sequence with a position marker, title, short summary and a route to each project.
- **Dorfromantik hero**: a pale blue field leaves room for a large wordmark, short introduction and bright platform buttons beside oversized game artwork.
- **Persistent language and menu controls**: compact controls sit at the top corners without competing with the hero.

## Using it with agents

No published agent channel was found. Share the homepage and the [Dorfromantik page](https://www.toukana.com/dorfromantik/) and ask an agent to describe how the carousel, numbered project sequence and launch-page hero organize multiple games. Use the game's art and branding as look-only references.

## Watch out for

- The homepage carousel and project artwork carry much of the identity; keep project names and navigation clear when images are unavailable.
- The bright illustrated game art is specific to the studio's releases and is not licensed for reuse here.
- Game purchase options appear on project pages, but no price was stated on the reviewed homepage. The studio site is free to browse.

## Reusable ideas

- Show a neighboring project in the carousel so visitors can see that the studio has more than one release.
- Use a consistent position marker and short introduction to make a project sequence easy to scan.
- Give the launch copy a quiet color field, then place platform actions together where they remain visible.
- Let each project use its own art while keeping language and navigation controls in familiar positions.
