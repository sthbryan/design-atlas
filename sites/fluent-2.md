# Fluent 2

## What it is

Fluent 2 is Microsoft's design system for products spanning web, Windows and mobile. The site is a full system hub: foundations and tokens, component guidance, Figma kits and code guidance, organized so a designer and an engineer can find the same component from their own starting point.

## When to open it

- When a product family needs one system across web and native surfaces, with shared tokens and naming.
- When design guidance must cover both the visual pattern and the code pattern, and keep them in sync.
- When a large enterprise system needs foundations (type, color, spacing) documented before components, so guidance stays consistent.

## Most useful

- Foundations before components: tokens, color, type and motion rules are documented once, then components inherit them.
- Each component pattern carries designer and developer views of the same thing, in one place.
- Figma kits are part of the official offer at review, so the system ships as design assets and code, not as a PDF.
- The site itself is a reference for enterprise systems: deep structure without visual noise.

## Using it with agents

- No agent channel is declared on the site at review.
- The guidance is human-readable; an agent can read the site and docs at review, but there is no registry, MCP or llms.txt published for it.

## Watch out for

- Microsoft retains brand and asset rights at review; build with the system, but do not redistribute assets or copy examples as your own.
- Figma kit versions and code package versions move independently; check the current version of each before adopting.
- The system's breadth means adoption is a program, not a download; read the getting-started guidance before committing.

## Reusable ideas

- Document foundations (tokens, type, color) before components, so component guidance stays short.
- Give every component both a designer view and a developer view, with the same name and states.
- Ship the system as kits plus code packages, with versions stated, so design and engineering cannot drift.
