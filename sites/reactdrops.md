# ReactDrops

## What it is

ReactDrops is a collection of React components, animations and effects: preview each one live, make it yours and bring it into your next project. It positions itself against pages that all look like AI output.

## When to open it

Open it when you need a standout animated component or effect that a default library does not have.

## Most useful

- **Preview first**: every component runs before you take it.
- **Effects as components**: the library leads with animations and effects, not basic form controls.
- **Sponsor-supported**: the library is funded by sponsor placements rather than a paywall.

## Using it with agents

No MCP, API or agent guide is published; the live previews and source are the working path.

## Watch out for

- No reuse licence was stated at review, so confirm before shipping in a commercial product.
- Effect-heavy components need reduced-motion handling in your app.

## Reusable ideas

- Lead with the effect and let the preview sell it.
- Keep the library free and fund it with sponsorships instead of gating components.
