# Admire The Web

## What it is

An index of live websites, organised the way a studio actually searches: by what the site is for. Agency (963 entries at review), Portfolio (657), Product (452), Responsive (1,546), Service (178), Professional (173), Site of the day (178), then the thinner ones — Microsite 27, Landing 52, Templates 104, Charity 23. Twenty-seven categories in all, each showing its count, plus colour tags for red, blue, green and the rest, and a separate Interactions section for sites whose argument is motion.

Every entry is a real site with its own page and a Save action, and the whole index runs to 76 pages. There is an RSS feed and a weekly mailing list, both of which matter more than they sound: a gallery with a feed can be subscribed to instead of remembered.

## When to open it

Open it when the brief names a sector — a charity, a restaurant, an architecture practice — and you need to see how that sector is being designed right now, or when you want a long, boring, reliable list rather than a handpicked one. It is weaker when you need a specific component: the unit here is the whole site.

## Most useful

- **Counted categories by sector**, which makes the sample size visible before you commit to browsing.
- **Site of the day as a filter rather than a badge** — 178 entries, a usable shortlist of what the editors rated.
- **A colour filter across the index**, useful when the brand palette is already decided.
- **An Interactions section** separate from the static index, which is how motion should be catalogued.
- **RSS and a newsletter**, so new work arrives without a return visit.
- **76 pages of depth**, which is rare among galleries that start fresh each year.

## Using it with agents

No `llms.txt`, no API and no JSON at review. Category URLs are stable and predictable (`/category/agency/`), so an agent can fetch a category page and read the site names, but the design itself is in screenshots and live sites. A human or a vision step is required for anything visual.

## Watch out for

- `/terms` and `/privacy` both return 404, so there is no stated licence for the thumbnails and no privacy page for the newsletter form.
- Entries are sites, not components, and there is no date per entry beyond pagination order.
- Category counts mix single pages and whole sites; "Responsive 1,546" is not a curated set of responsive exemplars.
- The editorial bar is broad rather than strict, so the index has as much ordinary work as exceptional work.
- Saving requires an account, and the saved list is the only personal feature.

## Reusable ideas

- Show the count beside every filter, so the reader knows the size of the set before clicking.
- Separate interaction work from static pages into its own index.
- Publish a feed for an index; it turns browsing into a subscription.
- Curate a "site of the day" list that doubles as a shortlist of the year.
