# Siiimple

## What it is

A minimalist gallery that has been publishing since 2008, and its own interface is the first argument: a cream page, a small wordmark with a registered mark, and an index line that counts the collection out loud — "The index / 1,253 websites". Entries arrive newest first in a grid of tall screenshots, each cropped to the top of the page rather than to a device frame, so the type and the grid are what you see first. Every entry carries a short written profile that names compositional choices instead of describing the business: a tiny grotesque set enormous and allowed to leave the frame, a single product photograph on a coloured field, a portfolio that hides its navigation until you scroll.

## When to open it

Open it when you need minimalist examples with a reason attached, rather than a wall of white pages. It is also the rare gallery where the category counts tell you what the curators see as variants of the same idea: Very Minimal, Bold, Art & Culture, Portfolio, Ecommerce, Architecture.

## Most useful

- **A written note per entry** naming the composition, which is the part most galleries skip and the part an agent can actually use.
- **Category counts right in the navigation** (Ecommerce 137, Fashion 41, Interior design 22 at review), so you can tell a deep category from a thin one before clicking.
- **Top-crop screenshots** that show type and layout instead of a laptop mockup, letting two entries be compared at a glance.
- **A saved list with a visible count**, a small pattern that works on any long index.

## Using it with agents

`llms.txt` is present and useful: it states the curation rules, the largest categories and the sitemap, and it exposes stable category URLs (`/category/very-minimal/` and similar) that an agent can fetch directly. There is no API or MCP server at review, and the entry pages are ordinary WordPress pages.

## Watch out for

- The counts disagree: the page index said 1,253 websites at review while `llms.txt` said 900+, so neither is safe to quote as fact.
- Selection is an editorial position — restrained palettes and generous white space — so the collection is a poor source for dense, maximalist or retail-heavy interfaces.
- Screenshots are the point and are not yours to reuse; link to the live site instead.
- The gallery is run by the founder of a hosting and theme company, which is worth knowing when placement looks flattering.

## Reusable ideas

- Write one sentence about the composition of each item in an index; it turns a gallery into a reference.
- Publish category counts next to the category names.
- Crop to the top of the page, not to a device, when the thing being shown is type and layout.
- Keep a saved list with a count in the header — it costs almost nothing and it tells people the index is meant to be worked through.
