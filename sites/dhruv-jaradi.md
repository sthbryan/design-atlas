# Dhruv Jaradi

## What it is

A personal portfolio with profile, about, activity, experience and education sections, plus a separate Projects page. The home page also includes a theme control, command-search shortcut and small profile interactions.

## When to open it

Open it for a portfolio that uses a visible page grid and small pixel-art details to give résumé content a more distinctive frame.

## Most useful

A wide dotted banner introduces the page, followed by a large profile row with avatar and live activity status. Thin rules divide the layout, and a diagonal hatch marks transitions into content sections. The display name has a lightly pixelated feel; a music card and a pixel-art cat add compact personal details. Experience and education entries collapse to keep their supporting information out of the initial scan.

## Using it with agents

No `llms.txt`, MCP, CLI, API or installable agent skill was found on the reviewed page. Use the live site as a visual reference.

## Watch out for

The dot field, hatched dividers and pixel art are a specific visual voice; use them selectively if the rest of a product has a quieter style. The theme control is visible, but the alternate theme and mobile layout were not verified.

## Reusable ideas

- Give a profile a broad textured banner, then reserve denser content for a narrower central column.
- Use a subtle grid and a single distinct section divider to structure résumé-like information.
- Collapse supporting experience details so the role and date remain visible at a glance.
