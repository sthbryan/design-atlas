# Navbar Gallery

## What it is

Navbar Gallery is an inspiration gallery dedicated exclusively to navigation bars, explicitly created in the image of footer.design but for navbars.

## When to open it

- When you need to decide which type of navbar to use (sticky, mega menu, sidebar, full screen) and want real examples of each before choosing.
- When you're looking for well-executed mega menu or full-screen menu references for a site with heavy content hierarchy.
- When you want inspiration for one specific navigation element: search bar, announcement bar, breadcrumbs or tabs.

## Most useful

- Classifies navigation into 9 types: static/sticky, dropdown/flyout, mega menu, side bar menu, search bar, announcement bar, full screen menu, breadcrumbs and tabs.
- Real examples from brands like Supaste, Chesapeake Plywood, Velt, Clonix, Aveon, Orchid, Cloudflare and ConsenSys, each with screenshots and feature tags.
- A blog with articles dedicated to specific navbar types (e.g. when to use a mega menu vs. a simple dropdown).
- Lets you submit your favorite navbar via a modal form.

## Using it with agents

No export or MCP; use it as a visual reference: open an example of the navbar type you need, describe it to the agent (structure, breakpoints, what collapses into a hamburger menu) and ask it to implement that pattern in your stack.

## Watch out for

- No advanced filters or search beyond "load more": for large libraries, pair it with another source that filters by industry or style.
- Screenshots come from real products with their own branding; use them for the structural pattern, not to copy the full visual design.
- No licence or pricing information is given.

## Reusable ideas

- Classifying navigation by "pattern type" (mega menu, sidebar, full screen...) instead of only by industry makes it easier to find the fix for a concrete UX problem.
- Pairing the gallery with a blog explaining when to use each type adds judgment, not just examples.
- Explicitly launching as "the footer.design of navbars" shows how an already-validated niche can be cloned into a neighboring component.
