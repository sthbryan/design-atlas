# Interact Gallery

## What it is

Interact Gallery is a curated directory of browser-based 3D and 2D experiences, including product configurators, virtual tours and interactive presentations. At review, its app index listed 135 entries. You can narrow it by industry, technology, rendering mode and commerce integration, then sort by overall score, UX, performance, recent updates or feature count. Each app page combines screenshots, a short description, feature tags, technical details and a link to the live experience. The curator also offers consulting for interactive 3D projects; pricing is not stated.

## When to open it

Use it when you need real examples of product configuration, spatial planning, browser-based 3D or other interactive product experiences. Start with an industry or feature if you have a use case in mind, then compare the implementations and open the original site. It is a focused reference source rather than a gallery for general landing-page art direction.

## Most useful

- **Browse all apps**: filter by industry, engine, render type and commerce flow, or sort the directory by score, recency and features.
- **App reviews**: compare screenshots, supported actions, rendering mode, commerce integration and named technology on one page. The review scores separate UX from performance and break each down into individual criteria.
- **Feature index**: open a concrete pattern such as [guided camera paths](https://www.interact.gallery/explore/features/guided-camera-paths) and find apps that use it.
- **Samara Backyard**: the [gallery review](https://www.interact.gallery/apps/samara-backyard-3d-configurator) links to the [live configurator](https://www.samara.com/adus/configure/?source=interact.gallery). In the reviewed interface, a rotatable white house sits in a large preview on the left, with configuration choices in cards on the right; a blue outline marks the selected option. This is useful for studying how a real estate configurator pairs a spatial preview with step-by-step choices.

## Using it with agents

There is no published MCP, API, CLI or `llms.txt` surfaced on the reviewed pages. An agent can read the gallery and individual app pages as ordinary web content. For implementation work, open a specific app review, give the agent the official live URL, and describe which feature you want to study; the listing's screenshots and tags are useful for selecting the reference, not a substitute for checking its current behavior.

## Watch out for

- The scores are editorial assessments, sometimes combined with a small number of user reviews; treat them as a comparison aid rather than a performance benchmark.
- The collection is limited to interactive 3D and 2D experiences, so it will not help much with ordinary page layouts or general visual inspiration.
- Screenshots and editorial content have no stated reuse licence. Use them to study the work, and check the original site's terms before reusing any assets.
- Some original configurators may require a capable device, location, account or substantial loading time.

## Reusable ideas

- Describe each interactive example through observable capabilities, technical details and a screenshot, then link directly to its live version.
- Separate UX and performance scores, and show the criteria behind each one so readers can understand what a rating covers.
- Index examples by both their purpose and implementation: industry, rendering mode, engine, commerce flow and interaction features.
- Pair visual examples with decision aids such as price calculation, configuration saving and mobile support, so teams can study the complete product task.
