# Keel Workspace

## What it is

Keel Workspace is a live CRM-style demo for the fictional Loomwell company. The Today screen combines a dark operations dashboard with sales pipeline metrics, meeting activity and an AI crew's proposed work.

## When to open it

Use it as a visual reference for an internal sales workspace where AI agents monitor records and suggest follow-up actions for people to review. The strongest material is the activity and approval workflow, rather than the CRM data model.

## Most useful

- The top row compresses coverage, win rate, forecast, response time, crew spend and the next meeting into compact cards with small charts and explicit units.
- Each decision card ties an agent's proposed action to a company, source documents, confidence and concise context, then offers clear approve, edit, reassign, skip or dismiss controls.
- A keyboard hint communicates that decisions can be reviewed with J/K and approved with Return.
- The activity stream distinguishes live work from earlier activity and names the source behind each event.

## Using it with agents

There is no published API, MCP, CLI, registry, llms.txt or skill. The live demo can be inspected in a browser; no agent integration is documented.

## Watch out for

- No public terms, pricing or licence were found, so treat the page as look-only and do not reuse its code or assets.
- The product data and company are presented as a demo. Do not infer that its metrics or agent actions describe a real service.
- The dashboard is dense and dark; test contrast, narrow layouts and chart labels if adapting its visual patterns.

## Reusable ideas

- Make agent work reviewable by placing its proposal, evidence and confidence beside the decision controls.
- Pair pipeline metrics with a short readable trend rather than relying on a large dashboard chart for every measure.
- Put queue actions and keyboard shortcuts next to the queue heading so the review model is visible before the first item.
