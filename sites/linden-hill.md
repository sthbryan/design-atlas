# Linden Hill

## What it is

Linden Hill is Barry Schwartz's digital version of Frederic Goudy's Deepdene. The League of Moveable Type page presents a live specimen with Regular and Italic states, linked source files, an extensive glyph inventory and examples of the font's OpenType features.

## When to open it

Open the [Linden Hill specimen](https://www.theleagueofmoveabletype.com/linden-hill) when evaluating a bookish serif in roman and italic, or when building a page that needs to explain glyph coverage and typographic features visually.

## Most useful

- **Style switch** — Regular and Italic buttons change the live specimen; the selected style is also reflected in the page URL.
- **Glyph inventory** — at review, 397 glyphs were shown with character names, alongside 11 character sets and 112 supported languages.
- **Feature examples** — small paired samples explain features such as small caps, historical forms, ligatures, fractions, swashes, kerning and case-sensitive punctuation.
- **Source and licence** — download, source code and OFL links point to the public GitHub repository, which includes both font files and the licence text.

## Using it with agents

There is no published MCP, API, CLI or agent guide. An agent can use the live style switch, read the glyph and feature sections and follow the source and SIL Open Font License links to GitHub. The League states that its fonts are free, open source, available for commercial use and subject to the OFL.

## Watch out for

- The page has a long glyph and OpenType feature inventory; use the named sections to reach the relevant examples instead of reading every entry.
- Linden Hill offers Regular and Italic rather than a broad weight family, so it is most useful for bookish text, restrained editorial headings and italic contrast.
- The OFL covers the font software. It does not grant permission to reuse the specimen page's visual design or copy.

## Reusable ideas

- Let visitors switch between roman and italic on the same specimen page, and expose the selected state in the URL.
- Pair each OpenType feature name with a short sample that makes its effect visible.
- Make large glyph sets browseable by showing each character beside its technical name.
- Link the specimen directly to source code and the exact licence file, not just a generic licensing page.
