# Korea Web Design

## What it is

A Korean-language directory that collects live Korean sites and presents them as a wall of uniform screenshots, each with a date. The interface stays in Hangul throughout — tabs for websites, mobile sites, blogs, reference links, and a separate strip for education, events and jobs — and the page title is set in Latin capitals as a counterpoint: "SITES OF KOREA". Every thumbnail is cropped to the same rectangle, roughly sixteen by ten, so an entry is never judged by its aspect ratio. Dates are compressed to four characters of year, month and day with dots between them, which reads as an archive stamp rather than a publication date.

## When to open it

Open it when you need density that Western galleries rarely show: e-commerce with a dozen promotion blocks above the fold, banking and telecom pages built around service grids, corporate sites that carry far more navigation than a comparable European or American site. It is also a good source for Hangul and Latin set together, which is a different typographic problem from a Latin-only page.

## Most useful

- **Mobile and desktop catalogued as separate entries**, so you can compare how one brand solves the same page at two widths.
- **A uniform crop across the whole index**, which makes scanning fast and forces the comparison onto layout and colour.
- **Dates in YY.MM.DD** on every card, letting you judge whether a design is current or five years old without opening it.
- **Reference links as their own category**, mixing actual sites with articles and resources about the Korean web.

## Using it with agents

`llms.txt` is served at review, so an agent can list the categories and entry URLs without scraping the grid. Entries live at predictable paths (`/kwd809/` and similar), and the thumbnails are ordinary WordPress uploads.

## Watch out for

- The interface and the entry notes are in Korean; an agent or a designer without the language can read layout and colour but not the reasoning.
- Links go to live sites, so anything older than a year may already have been redesigned — the screenshot is the record, not the link.
- The set is heavily commercial, with relatively little portfolio or editorial work, which skews the impression of Korean web design toward retail.
- No licence is stated, so treat both screenshots and copy as look-only.

## Reusable ideas

- Separate mobile and desktop into different categories instead of one responsive entry.
- Crop every thumbnail identically and let the design inside do the differentiating.
- Put a short date on each card in a compact, unambiguous format.
- Keep a saved list, since a directory this dense is meant to be filtered by the reader.
