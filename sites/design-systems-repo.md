# Design Systems Repo

## What it is

A curated directory of design systems, style guides and pattern libraries. Entries are organized alphabetically, with a recent-items view and direct links to each publisher.

## When to open it

Use it to discover a real design system by name or follow a listed source such as [IBM Carbon](https://carbondesignsystem.com/) or the [GOV.UK Design System](https://design-system.service.gov.uk/). The directory is a route to those references, not a visual example to study by itself.

## Most useful

Follow a directory entry into its live system and inspect the actual component and guidance pages. For example, GOV.UK's [button guidance](https://design-system.service.gov.uk/components/button/) documents several button variants with live examples and usage rules; Carbon's home page links to its design and development guides and component libraries. These source pages show the implemented visual language; the directory only helps locate them.

## Using it with agents

No MCP, API, CLI, `llms.txt` or agent-focused index was found at review. An agent can read the directory's links in a browser, then inspect a selected publisher's own guidelines and licence. Don't infer source terms from the directory description.

## Watch out for

The alphabetical list is broad and has no visible review dates for each entry. Some systems may be stale, archived or inaccessible, so check the destination before relying on it. Directory entries and screenshots do not establish reuse rights; the linked system's own licence controls.

## Reusable ideas

Treat a directory as a starting point: select a relevant system, then compare its live foundations, components and patterns against the UI you are building. Record the originating publisher and check current availability and terms for every source.
