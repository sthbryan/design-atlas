# Compresto

## What it is

Compresto is a macOS app for batch compression of video, images, PDFs and GIFs, with a separate image-compression API and free online utilities. The landing page is a useful product-marketing reference because it pairs each media type with a concrete before-and-after example.

## When to open it

Open the homepage when designing a utility page that needs to make an invisible processing step understandable, or when looking for a compact structure for presenting multiple formats under one product. It is one product site, not a gallery of design examples.

## Most useful

- [Homepage](https://compresto.app/): inspect the two-part headline, product demo and format-specific comparison sections for video, images, GIFs and PDFs.
- [Pricing](https://compresto.app/pricing): compare one-time plans and their device limits.
- [Image Compression API](https://compresto.app/api): inspect the developer-oriented page, interactive demo and code samples.
- [llms.txt](https://compresto.app/llms.txt): a machine-readable index of product, documentation, comparison, API and tool pages.

## Using it with agents

The public [llms.txt](https://compresto.app/llms.txt) provides a page map, while the API page documents a compression endpoint and an unauthenticated demo. These are ways to find and use the product; they do not grant permission to reuse the site's screenshots, copy or other media. No installable skill or MCP was linked from the reviewed pages.

## Watch out for

The displayed before-and-after values are vendor examples, not a promise for every input file. At review, the homepage's animated aggregate counters visibly showed zero users, files and storage despite nearby product-use claims; verify dynamic counters before copying that pattern. The app is paid, and the terms describe processing as local; the separate image API has its own data path and pricing.

## Reusable ideas

- Pair a processing feature with the actual input and output sizes so the benefit can be judged without translating a feature list.
- Give each file format a labelled comparison panel, then repeat the same structure across formats to make the coverage easy to scan.
- Contrast the plain-weight storage claim with a slanted, underlined emphasis phrase to give a short, number-led headline a clear second beat.
- Place platform requirements and the download action directly below the main product explanation, with the secondary platform action visually distinct.
