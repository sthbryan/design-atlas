# Kidus Yohannes

## What it is

Kidus Yohannes's portfolio is a dark, section-based profile for an AI and full-stack engineer. The opening view introduces the name and role over a subtle star field, with rounded project and contact actions and a floating row of section icons.

## When to open it

Open it when you want to study a restrained dark hero, a fixed icon navigation rail or a portfolio arranged as a horizontal journey through profile, experience, skills, projects and contact.

## Most useful

- **Quiet star field**: small background specks add depth behind the oversized name and role without interfering with the text.
- **Compact action pair**: project and contact controls use two rounded buttons with distinct emphasis and ample space between them.
- **Floating section dock**: a low, pill-shaped group of circular icons provides a persistent way to move among the main portfolio sections.
- **Horizontal skills presentation**: the page invites visitors to glide through grouped areas such as AI, cloud, backend and data/search.
- **Evidence-rich projects**: the project sequence pairs imagery and concise descriptions with visible technologies, while experience items give the details more room.

## Using it with agents

No agent-facing integration was visible during the review. The sections and project content were present in the browser accessibility tree; the horizontal scrolling interaction, contact behavior and narrow-screen layout were not verified.

## Watch out for

- The queue's `v2.kidus-yohannes.engineerr` address did not resolve. A focused search returned the developer's GitHub profile linking to `kidus-yohannes.engineer`; that canonical site was reviewed here. The subdomain version itself remains unverified.
- No reuse licence was found for the design, code or imagery. Treat it as look-only.
- The layout's horizontal journey may depend on input and viewport size; test the intended audience's device before adapting that pattern.

## Reusable ideas

- Place a persistent section dock where it can support a long portfolio without competing with the opening content.
- Group technical skills by the kind of work they support instead of presenting one undifferentiated list.
- Use restrained ambient detail behind the hero and reserve the strongest contrast for the name, role and next actions.
