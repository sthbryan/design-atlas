# Zoomquilt

## What it is

Zoomquilt is a collaborative painting designed to zoom endlessly through its own scenes. The current work is presented as a full-viewport image with a small overlay identifying the project and its contributors; the up and down arrow keys adjust navigation.

## When to open it

Open it when studying a continuous transition that carries a viewer through a sequence of places without a conventional page break. Its main value is a single, distinctive motion idea rather than a set of UI patterns.

## Most useful

Watch the [live painting](https://zoomquilt.org) for how each illustrated layer hands off to the next at a different scale. The current view moves through a dark, architectural scene: pale, angular structures and clouds frame a vivid orange ribbon that winds through the composition. Use the arrow keys to change the pace and direction of the journey.

The project page also links to [Zoomquilt 2](https://zoomquilt2.com/), [Arkadia](https://arkadia.xyz/) and [Infinite Flowers](https://infiniteflowers.net/), related works that shift the same infinite-zoom premise toward different visual worlds.

## Using it with agents

There is no code sample, API or agent guide on the page. Give an agent the live link and ask it to describe the scale changes, scene handoffs and focal path; do not treat the images as reusable assets.

## Watch out for

- The uninterrupted zoom is deliberately immersive and can disorient some viewers. It is a motion reference, not a pattern to run continuously behind dense interface text.
- The art is credited to multiple illustrators, but the page does not publish a reuse licence. Ask the rights holders before reproducing or adapting it.

## Reusable ideas

- Match the edge of each scene to the next scene's interior so a transition can continue without a visible cut.
- Let a repeated path or shape carry the viewer through changes in scale and setting.
- Keep navigation instructions and credits small enough to leave the artwork dominant, while retaining a clear way to adjust or leave the experience.
