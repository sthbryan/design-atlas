# Uwarp

## What it is

Uwarp is a free collection of browser tools for designers, frontend developers and design engineers: image, document, audio and video conversion, design assets such as icons and fonts, colour tools, text and code utilities, downloaders, games and best-website references, indexed by an `llms.txt`.

## When to open it

Open it as a directory when you need a small browser utility (convert, resize, pick a colour, find an icon) without installing anything.

## Most useful

- **Breadth in one place**: conversion, assets, colour, text, code and media tools under one index.
- **Browser-based**: the tools run in the page, so nothing is installed.
- **Agent-readable index**: the `llms.txt` makes the directory discoverable for agents.

## Using it with agents

The `llms.txt` is the agent channel; the tools themselves are interactive web utilities.

## Watch out for

- A directory of tools, not a library: quality varies by tool.
- No reuse licence was stated for the assets it surfaces.

## Reusable ideas

- Index a tool directory as text so agents can find the right utility by name.
- Keep the tools in the browser so there is nothing to install for a one-off conversion.
