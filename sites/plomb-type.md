# Plomb Type

## What it is

Plomb Type is an independent type foundry in Lyon. Its Savate page combines a vivid, art-directed type specimen with editable samples, glyph coverage and examples of the face used in commissioned identities.

## When to open it

Open [Savate](https://plombtype.com/savate/) for a visual reference on expressive type-led pages, or to study how a single family can span display lettering, longer text and identity work.

## Most useful

- **Opening composition** — a bright blue field, lemon yellow wordmark and oversized type overlap a cutout boxer sculpture. The fixed navigation and contrasting purchase sticker frame the art without competing with the type.
- **Live specimens** — replace sample text and adjust size and weight. Separate blocks demonstrate several weights and italics against long-form copy, short phrases, numerals and symbols.
- **Real uses** — the “Savate in use” section links to six identity projects, including Soul Juice, Arcadian Field and Teoría King Kong. Follow those examples to see the font outside the foundry's own art direction.
- **Glyph map** — expandable groups cover basic and extended alphabets, figures, punctuation, language marks, ligatures and symbols.
- At review, the family had eight upright and eight italic weights, variable and static formats, and broad Latin language support.

## Using it with agents

There is no published MCP, API, CLI or agent guide. An agent can inspect the public specimen in a browser, edit the sample controls, and follow linked identity examples. The font is also linked from Google Fonts and its SIL Open Font License 1.1 is linked on the page.

## Watch out for

- A decorative animated-media region did not play in the browser at review; the rest of the specimen and its controls loaded.
- The page's visual direction is deliberately loud. Lift the useful type scale and overlap ideas selectively for quieter products.
- The OFL applies to Savate's font files. It does not grant permission to reuse the foundry's site design, project images or other assets.

## Reusable ideas

- Put an oversized word across a cutout object so the type and image share one focal point.
- Let sample blocks show distinct jobs for a font family, then make each block editable with its own size and weight controls.
- Link each specimen to a set of real client uses, so visitors can judge the type in a finished identity.
- Group an extensive character inventory into labelled, expandable sections rather than placing every glyph in one long strip.
