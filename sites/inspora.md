# Inspora

- **URL:** https://www.inspora.design
- **Type:** inspiration gallery
- **Topics:** inspiration, typography-and-styles
- **Pricing / licence:** Not stated (free to browse; its llms.txt says Inspora is not the rights holder of featured work and asks for creator credit plus a link to the original source)
- **Reviewed:** 2026-09-25

## What it is

Inspora is a small, editorially tagged archive of recent visual design work, mostly interface shots and motion clips posted by designers on X. Each entry gets a short written description and structured tags for industry, color and style, with a link back to the original post.

## When to open it

- When you want a quick scan of what designers are shipping this month rather than a large historical archive.
- When you're searching for a look, not a component: the color and style tags (chrome, iridescent, glossy glass, liquid metal) make it easier to pull references for a visual direction.
- When you need a short, citable description of a piece of work to paste into a brief.

## Most useful

- Eight top-level categories: Web, Branding, Product, Motion, Illustration, 3D, Print, plus All.
- Per-entry tags split into Industries, Colors and Styles, alongside a one-line editorial description and the creator's handle.
- Latest and Featured sort orders, multi-slide entries, and a side panel with previous/next navigation.
- The homepage says it is updated hourly; the sitemap listed around 140 project pages at review time.
- A weekly email digest.

## Using it with agents

It publishes an llms.txt that explains what the archive covers and how to credit entries, and points to the sitemap. There is no MCP, API for agents or prompt export (its robots.txt disallows the /api/ routes). The practical workflow is to give an agent an entry's description and style tags as a starting vocabulary for the look you want.

## Watch out for

- Small catalogue: good for freshness, thin for exhaustive research on one pattern.
- Contact runs through the curator's X account; there are no terms or about pages.
- All featured work belongs to its creators; the site only curates and describes it.

## Reusable ideas

- Tagging each reference by color and style words, not just category, lets people search by mood ("chrome", "iridescent") instead of by component.
- A one-sentence editorial description per entry makes a visual gallery readable by text search and by agents.
- Publishing attribution rules in llms.txt tells agents how to cite the archive correctly before they start quoting it.
