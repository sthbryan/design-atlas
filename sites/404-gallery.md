# 404 Gallery

## What it is

404 Gallery is a one-page collection of error pages run by Alexey Bychkov, a Russian web designer. At review it held about ninety screenshots, each captioned with the kind of business that page belongs to rather than with a style label: an air-conditioning shop, a door shop, a yacht rental, a pizza delivery, a film catalogue, a security systems vendor. The premise is that the error message should be about what the company sells, so a fishing shop puts you in a desert and a gallery leaves an empty frame behind. Everything is on the homepage, in one scrolling column of screenshots.

## When to open it

When a 404 has to be more than a nice illustration and the brief is to make the error belong to the product. It is also the fastest way to show a client what "the joke has to be yours" looks like across a dozen unrelated industries, which is easier to argue with than a general gallery sorted by visual style.

## Most useful

- **Sector captions**: each screenshot is named after its industry, so you can scan for the closest analogue to your project and read what the joke would be for that product.
- **The metaphor axis**: air conditioning playing on heat, logistics delivering an empty box, a gallery showing an empty frame. That is a transferable recipe, not a visual style.
- **Breadth of business types**: from medical centres and beauty salons to crypto and gaming, which helps when the site is not a SaaS landing page.

## Using it with agents

Nothing machine-readable: no `llms.txt`, no MCP, no API, and no outbound links to the pages shown. An agent cannot fetch any example from here. Give it the metaphor in words instead — "the error page should be the product failing in its own terms, e.g. an empty frame for a gallery" — and it can build the page; the gallery is for choosing that idea. Captions are in Russian, so translate the sector name before passing it to an English-speaking model.

## Watch out for

- No entry links to its source site, so you see a still image and not the live page: no interaction, motion, copy or code to inspect. Several captions are jokes rather than descriptions, which makes the underlying site harder to identify.
- The whole page is Russian, including the navigation words that scroll across the header.
- All rights reserved, with no statement about how the screenshots may be used; they are third-party pages captured by the author.
- It is a personal page rather than a maintained product: no search, no filters, no favourites, no submission form.

## Reusable ideas

- Caption each example with the industry it belongs to, not only with its visual style, so the gallery answers "what would my version be".
- Tie the error copy and illustration to what the product does, so the page reads as the brand rather than as a template.
- Put ninety screenshots on one page and let the browser's find command do the filtering; for a single inspiration visit that beats a paginated grid.
