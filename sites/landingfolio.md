# Landingfolio

## What it is

Landingfolio is a visual reference library operated by Postcrafts. The Inspiration gallery shows full landing-page captures, filterable by industry, device and colour. A separate Components gallery isolates sections from real sites and groups them by block type. Do not confuse those reference captures with the separately sold Tailwind, Webflow and Figma component products.

## When to open it

Start at [Components → Hero](https://www.landingfolio.com/components/hero) to compare hero compositions, or use [all section examples](https://www.landingfolio.com/components) and its category list for a different block. For a whole-page direction, browse [Inspiration](https://www.landingfolio.com/) by industry, device and colour. Open a card to see its source page; the full-page reference, where available, includes desktop/mobile views and links to the featured site's sections. Then open the live source in the browser and inspect its current layout at the viewport you are building for.

## Most useful

- **MCP server**: returns screenshots of section examples with their category and a link to the source page. At review, the category list showed Feature (1,005), Hero (466), Footer (396), Header (390) and Pricing (89), alongside less common groups such as Before After, Competitors and Cookie
- **Section examples**: the [Hero category](https://www.landingfolio.com/components/hero) presents a long grid of named captures. Clicking a card opens a preview; the linked inspiration page can lead to a full-page capture and the live site
- **Full-page references**: the homepage's industry, device and colour filters narrow the collection; the individual page shows its palette and page sections, with desktop and mobile views when available
- **Component library**: downloadable blocks for Tailwind, Webflow and Figma, grouped into global, marketing and app sections
- **Premium single-page templates** for Tailwind and Webflow, included with the pass

## Using it with agents

The [MCP setup page](https://www.landingfolio.com/mcp) is live and documents Claude Code, Cursor, Codex, Windsurf, VS Code and other clients. An agent needs a free account and token; the public tier allows 100 requests per token per day and 10 per minute, while the paid pass lists 1,000 a day at review. Its tool returns reference screenshots, a category and source link, not implementation details. Have the agent compare a few captures, describe hierarchy, type scale, image placement, colour and spacing, then open the source site and take a fresh browser screenshot before adapting those ideas to the project. The site says it logs tool calls per account but not code, prompts or project files.

## Watch out for

- The MCP requires an account and bearer token, so it is not anonymous access
- Gallery and MCP screenshots show third-party sites; they are visual references, and no reuse licence for those sites is stated
- The paid component licence permits commercial client and personal end projects, but forbids reselling or distributing the downloaded item, and forbids selling themes, templates or derivatives of it on marketplaces
- Ads, affiliate links and course promotions (including a pre-order course of agent skills) run through the site

## Reusable ideas

- Pair section-level comparison with a visit to the original site: the capture shows the composition quickly, while the live page reveals its current responsive layout and behavior
- Use adjacent section captures from the same source to see whether the hero's type, colour and spacing continue through the rest of the page
- Offer a small free request quota so people can try an agent integration before paying
