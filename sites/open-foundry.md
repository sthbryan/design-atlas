# Open Foundry

## What it is

Open Foundry is a curated catalogue of open source typefaces, run by a studio and around for over a decade. Its homepage is a specimen grid, twenty-five cards at review, and each card is set in the face it sells: the font renders its own name, with the designer underneath and a short "Explore" action. A font page adds a large specimen, a classification, the licence, the designer, the credits for the specimen, and the available weights and italics, before the same grid of more fonts.

## When to open it

- You need an open licence for a face and want a shortlist chosen by someone with taste rather than by popularity.
- You are looking for a display or text face outside the usual Google Fonts set, and want to see it set as type before downloading.
- You need to confirm a licence quickly; the font page states it, with a link, above the samples.

## Most useful

- **The card is the specimen**: the name is set in the face at a size that shows its character, so the grid filters by eye before you read a single description.
- **Licence on the page**: each font page names the licence — Archivo, for example, is listed as SIL Open Font License v1.1 — and links to it, which saves a detour to a source repository.
- **Weights listed with styles**: the font page enumerates what is actually available (regular, italic, medium, semibold, bold and their italics), so you know whether the family can carry a full hierarchy.
- **Specimen credits**: naming the person who set the sample is a small, good habit; a specimen is a piece of design work, not a datasheet.
- **A short list, kept**: twenty-five cards on the homepage is a curator's edit. The value is the leaving out.

## Using it with agents

No agent channel at review: no `llms.txt`, no API, no MCP server. Font files are downloaded by hand from each font page, so an agent can research a family's licence from the page text but not install it without the human in the loop.

## Watch out for

- The licence varies by family, and an entry can be OFL, another open licence, or a family whose terms live elsewhere. Read the font page, then the licence itself, before shipping.
- Many of these faces are already widely used. A curated catalogue is not a guarantee of distinctiveness, and Inter, Roboto and Poppins are here too.
- Open licences usually keep the reserved font name and require the copyright notice to travel with the files. Renaming a subset is not the small freedom it looks like.
- The catalogue is thin on new releases and on variable fonts; it is a settled library rather than a feed.
- Some specimens are set as artwork. Judge the letterforms, not the composition, when you choose.

## Reusable ideas

- Set each catalogue card in its own typeface; the specimen is the strongest filter you can offer.
- State the licence on the detail page, linked, next to the download rather than buried in an FAQ.
- Credit the person who set the specimen.
- Keep a curated list short and stable instead of growing it with every release.
