# Beamline UI

## What it is

Beamline UI is a library of polished, editable React components and complete screens for custom applications: 240+ components and 340+ complete screens at review, covering settings, dashboards, trading surfaces and AI and agent interfaces, with real motion, micro-interactions and optional interface sound.

## When to open it

Open it when you need whole product screens (not just components) that already feel finished, and you are willing to pay once for the library.

## Most useful

- **Screens, not only parts**: 340+ complete screens, which is the hard part of a product UI.
- **Motion built in**: micro-interactions ship with the components.
- **Agent paths**: a hosted MCP endpoint and a shadcn-compatible registry, plus `connect.md` instructions for agents.

## Using it with agents

The hosted MCP server and the shadcn registry install flow are the documented agent channels; the free sample gives an agent something to work with before purchase.

## Watch out for

- It is paid after the free sample ($49 once for one person at review), so check the licence for team use.
- Screen-heavy libraries tempt copy-paste product design; adapt the screens to your flows.

## Reusable ideas

- Sell complete screens, since assembling them is where teams actually lose time.
- Include sound as an optional layer, not a default.
