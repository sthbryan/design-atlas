# Designeer

- **URL:** https://designeer.xyz
- **Type:** directory · discovery tool
- **Topics:** inspiration, components, assets
- **Pricing / licence:** Not stated (free to browse; includes sponsors like Loops)
- **Reviewed:** 2026-09-25

## What it is

Designeer is a curated directory of tools, components, inspiration galleries and learning resources for designers and "design engineers": an index of indexes for the design ecosystem, maintained by Dhruv Jaradi.

## When to open it

- When you don't know what tool exists for a specific problem (prototyping, asset conversion, icon generation) and prefer a curated directory over searching from scratch.
- When you want to discover other niche galleries (like navbar.design or footer.design) without already knowing about them.
- When you're looking for resources specific to the "design engineer" profile (the border between design and code) in one place.

## Most useful

- Six main sections with their own stated resource counts: Inspiration (122), Components (120), Build (64), Visuals (55), Utilities (61) and Design Engineers (132).
- Inspiration aggregates both generalist galleries (Dribbble, Behance, Awwwards) and interface-pattern-specific ones (Mobbin, Pttrns, Collect UI), SaaS-specific ones (Saaspo, SaaSFrame, LandingFolio), and niches like navbar.design, footer.design and Dark Mode Design.
- Components groups headless primitives (Radix, Base UI, Headless UI), pre-styled sets (shadcn/ui, daisyUI, HeroUI), motion-focused collections (Motion Primitives, Cult UI, Magic UI) and specialized registries (Kibo UI for AI, Tremor for dashboards, emailcn for email).
- Quick search (Ctrl+K) and an exploration mode (Ctrl+E).

## Using it with agents

No export or MCP of its own; its value with agents is as a starting map: ask the agent to check the relevant Designeer sections (e.g. Components or Build) to pick which library to use before generating code, instead of letting it guess a dependency.

## Watch out for

- It's a link directory, not a catalog with its own preview: every entry sends you off-site to the original tool.
- Relying on manual curation, some links can go stale over time.
- No advanced filters are visible on the homepage beyond the six sections and search.

## Reusable ideas

- Organizing a directory by "stage of work" (inspiration, components, build, visuals, utilities) instead of alphabetically makes everything easier to find depending on where you are in the process.
- Showing the resource count per section next to its name gives a quick signal of how deep each category is before you click in.
- A section dedicated to "design engineers" recognizes that this hybrid profile needs different resources than a pure designer or developer.
