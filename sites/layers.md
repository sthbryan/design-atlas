# Layers

## What it is

Layers is a Dribbble-style home for designers to share work, get feedback, build a profile and find jobs. It was built by Liam McCabe as a response to designers' frustration with older showcase sites, and its tag data dates from October 2022. Each post (a "layer") is a shot or clip with a title, description and tags such as product-design, ui or web-design, posted by individuals, studios and agencies. The site also has teams, collections, colour palettes and a job board. It is built with Remix.

## When to open it

Open it when you want to see what product and web designers are sharing right now (dashboards, SaaS sites, mobile concepts), or when you want a public profile and feedback on your own work.

## Most useful

- **Explore feed**: Hot and All views of the latest posts, plus search by tag and designer.
- **Profiles and teams**: follow studios and designers whose work fits your direction.
- **Jobs**: a design-only job board with recent listings on the explore page.
- **Plus**: ad-free browsing, post scheduling, analytics, a profile badge and, per the upgrade page, API access.

## Using it with agents

No public API documentation, llms.txt or MCP; the API access listed under Plus had no published docs at review. Treat it as a manual reference: save a few posts, write down the layout, density, colour and component patterns you want, and hand that summary to the agent.

## Watch out for

- Much of the feed is concept work made for the feed, not shipped products. Check real-world constraints before adopting a pattern.
- Pages render with JavaScript, and posts come with no licence, so screenshots are reference only.
- The terms have not been updated since 2023, and the only member count found (20k+) comes from third-party listings, not the site.

## Reusable ideas

- Let members schedule posts and see analytics, so a showcase feels like a publishing tool.
- Combine portfolio, feedback and job board in one profile so the site is useful between job searches too.
- Offer team accounts so studios can post as one voice.
