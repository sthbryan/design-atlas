# Too Much Type

## What it is

An experimental foundry and web-specimen lab by No Replica and Gabriel Drozdov. Its original and remixed variable fonts can be tested in the browser and downloaded, while individual specimen pages explore how type can respond to controls, motion and user input.

## When to open it

Open it for expressive display-type behavior, an unconventional specimen interaction, or examples of variable-font axes being made visible instead of hidden in CSS. Use it as a source of technique and visual direction, then check the font’s own licence before reuse.

## Most useful

- **Music Box** — [/fonts/music-box/](https://toomuchtype.com/fonts/music-box/) is a variable font with Amplitude and Frequency axes, mapped to an animated kick-and-snare pattern. The live specimen fills a dark checkerboard field with huge white pixel-like glyphs; its bottom control strip changes speed, amplitude, alignment, size, spacing and line height. It demonstrates a type tester as the whole composition, rather than as a small sample card.
- **Mini Mochi** — [/fonts/mini-mochi/](https://toomuchtype.com/fonts/mini-mochi/) is an original specimen route linked from the catalogue; compare its motion and font controls with Music Box’s beat-driven display.
- **Fun Font** — [/fonts/fun-font/](https://toomuchtype.com/fonts/fun-font/) is an experimental multicolour specimen that breaks glyphs into components and shifts their colours over time.
- **Catalogue** — the home page separates original fonts, remixes and experimental specimens. Each route offers a direct specimen and, where available, downloadable font or specimen code.

## Using it with agents

There is no published MCP, API, CLI or llms.txt. An agent can read the catalogue and linked GitHub specimen code in a browser. The code link is useful for understanding how an effect is built, while the live page shows whether the motion remains legible. The site describes projects as open source, but does not name a universal licence.

## Watch out for

- The playful, edge-to-edge specimens prioritize expression over familiar page chrome. Test the type in a normal content hierarchy before carrying over the scale or movement.
- The project includes remixes of Authentics Sans, Avara, FT88 and Work Sans. Respect the original project’s credit and licence as well as any terms stated by Too Much Type.
- “Open source” is the site’s wording, but most pages do not name a standard licence. Music Box specifically lists the SIL Open Font License; verify each download individually.
- Motion and large samples may not suit reduced-motion preferences or small screens. Preserve a still state and let the sample text remain editable if adapting the interaction.

## Reusable ideas

- Make a specimen respond to the font’s idea: connect axes to rhythm, colour, distortion or another characteristic, instead of presenting generic sliders alone.
- Keep controls in a persistent strip while the specimen owns the rest of the viewport.
- Let people replace the sample text and adjust basic typography so they can judge both expression and fit.
- Credit original type authors near remixes and make the code for the specimen discoverable beside its live behavior.
