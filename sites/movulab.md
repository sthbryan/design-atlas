# Movulab

## What it is

Movulab is a browser-based editor for turning a word into a looping animated type treatment. The editor combines an artboard, a live timeline and a control rail for effects, appearance and text.

## When to open it

- When exploring a short typographic loop for a title card, social graphic or motion study.
- When comparing how one word changes under blur, halftone, glitch, ink, liquid, echo or dither treatments.

## Most useful

- **Effect rail**: switch among nine visible effect families at review, including Chrome, Acid Blur, Halftone, Glitch and Dither.
- **Type controls**: edit the word, choose a font, and adjust size, case, tracking, leading, skew, fill and position.
- **Loop controls**: scrub the animation, set its duration and inspect the seam.
- **Looks**: save or select appearance presets, then refine the effect with its own palette and parameters.
- The first-run tour explains the artboard gestures: edit text, drag to move and pull a corner to scale.

## Using it with agents

No MCP, API, CLI, registry, `llms.txt` or agent guide was linked at review. It is an interactive visual editor, not a code component source.

## Watch out for

- The default onboarding overlay covers the canvas; dismiss it before judging the current composition.
- The page links to an optional tip jar, but no commercial reuse licence for exported work or included typefaces was stated. Verify those rights before shipping an export.
- Treat effects as motion references; the editor does not provide a documented implementation handoff for an app UI.

## Reusable ideas

- Put timeline scrubbing and loop duration beside an animated preview so the loop can be inspected as well as watched.
- Group controls into effect, appearance and text, and expose effect-specific settings only when that effect is selected.
- Explain direct canvas gestures in context during the first visit.
