# No AI Slop Manifesto

## What it is

The No AI Slop Manifesto, written by the speakers and attendees of the AIE Code Summit 2026, is a short set of principles for refusing generic, AI-looking output, in the spirit of the 2001 Snowbird gathering that produced the Agile Manifesto.

## When to open it

Open it when you want a shared, quotable statement of principles to point an agent or a team at before a build.

## Most useful

- **Principles, not a checklist**: a manifesto you can cite in a prompt or a review.
- **Community authorship**: written by summit speakers and attendees, so it carries weight beyond one vendor.
- **Short**: it is a page, not a design system.

## Using it with agents

No MCP or skill is published; the manifesto works as text you paste into a prompt or a project doc.

## Watch out for

- It is principles, not an implementation: pair it with a library or skill when you need concrete output.
- No reuse licence was stated, so quote sparingly and in your own words.

## Reusable ideas

- A short manifesto travels further than a long style guide when the goal is to change defaults.
- Name the enemy (slop) so the principles have something to push against.
