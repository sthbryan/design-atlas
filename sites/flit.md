# Flit

## What it is

Flit is a paid dictation app for macOS. Its site is both a product in its own right and a detailed set of interface demos: it shows dictation, correction, contextual wording, agent prompts, language switching, privacy and app settings through illustrative mockups. The examples are Flit's own product presentation, not independent client sites.

## When to open it

- When studying how to explain a desktop utility through specific, animated or interactive product scenarios.
- When designing voice input, transcript review, correction, dictation history or language controls.
- When looking for a concrete example of a spoken brief being composed in a coding-agent prompt field.

## Most useful

The [agent workflow section](https://flit.fyi/#agents) shows a spoken request becoming a clean task in Claude Code, Codex or Cursor. Other useful examples include [context-aware replies](https://flit.fyi/#context), [language switching](https://flit.fyi/#languages), and [review before insertion](https://flit.fyi/#more). These are demonstrations of Flit's own interface. The [alternatives page](https://flit.fyi/alternatives) offers a separate route for discovering comparable dictation products and following them to their own sites.

## Using it with agents

The marketing site documents Flit typing dictated prose into coding-agent prompt fields, but the reviewed pages do not publish an MCP, API, CLI or installable agent skill. The site's [llms.txt](https://flit.fyi/llms.txt) link was visible, but the browser blocked that path on two checks, so its contents could not be verified. See the [terms](https://flit.fyi/terms), [pricing](https://flit.fyi/pricing) and [privacy statement](https://flit.fyi/privacy) for current product details.

## Watch out for

- Flit is a macOS product; the site lists macOS 14 or later and Apple silicon as requirements.
- Prices, promotions and license terms can change; confirm current details on the linked pages.
- This is a paid, proprietary app. Its interface examples are for visual study, not assets or code offered for reuse.

## Reusable ideas

- Show one feature through a recognizable user scenario, with input and resulting state visible together.
- Split a long feature story into named chapters so readers can jump to a specific capability.
- Show the difference between a suggested correction and an automatic action, including what remains under the user's control.
