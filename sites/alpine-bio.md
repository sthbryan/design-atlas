# Alpine Bio

## What it is

Alpine Bio is a brand website for biotech ingredients. [Resn's project announcement](https://www.linkedin.com/posts/resnglobal_announcing-our-latest-work-for-alpine-bio-activity-7290201577808662529-iHFX) links to this live site. Resn's portfolio remained on its loading screen during review, so this published client site is the accessible visual reference.

## When to open it

Open the live page when you need art direction for a technical product that should feel tangible. Its first screen places an oversized white headline over a close-up ingredient image, with a floating navigation panel and a rounded blue action.

## Most useful

- **Hero composition**: one full-bleed ingredient image carries the background, while faint vertical guides keep the display text aligned.
- **Type and contrast**: a narrow sans-serif headline fills much of the viewport; white lettering remains legible against the warm image.
- **Navigation**: a compact white panel floats above the hero, separating site controls from the photographic canvas.
- **Action hierarchy**: a blue sample-request button stands apart from the otherwise restrained palette.

## Using it with agents

No agent endpoint was verified for the live site. An agent can open the page in a browser, capture the rendered composition and study the spacing, type scale and contrast. Use the Resn announcement only to confirm attribution; inspect the client site for the current design.

## Watch out for

- This is one client website, so its ingredient imagery and brand cues are specific to that product.
- Resn's own portfolio did not pass its loading screen in this review; open Alpine Bio directly rather than relying on the studio index.
- No reuse licence was stated for the site's assets or design. Create original imagery and branding.

## Reusable ideas

- Anchor a large headline to a small set of column guides over one continuous image.
- Float a compact navigation panel above a full-bleed hero without covering the main focal point.
- Give the primary action a single contrasting colour that stays visible against detailed photography.
