# Typographer

## What it is

Typographer is a font tool for finding, testing and buying typefaces: 10,000+ typefaces at review, live testing in the browser, and a desktop app that syncs licensed fonts to your machine. It sits between a font marketplace and a font manager.

## When to open it

Open it when you are choosing type for a project and want to test real families in place before buying licences.

## Most useful

- **Test before buying**: try the typeface in your own layout, not a specimen page.
- **Sync app**: licensed fonts arrive on the machine, so design and build use the same files.
- **Licence clarity**: the subscription states the pageview ceiling in plain language.

## Using it with agents

No MCP, API or agent guide was found at review; the tool is a human-facing app.

## Watch out for

- The subscription's pageview ceiling (15,000 a month at launch) is low for a growing product, so check before you standardise on it.
- It licenses access to fonts, not ownership; the foundry terms still apply.

## Reusable ideas

- State the pageview ceiling next to the price; font licensing confusion is the main purchase blocker.
- Let people test a typeface in their own layout before paying.
