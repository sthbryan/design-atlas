# Montagu Slab

## What it is

Montagu Slab is a variable slab-serif display typeface by Florian Karsten and designer Květoslav Bartoš. Its family page uses an oversized, editable specimen to demonstrate how the weight and optical-size axes change the letterforms, then gives technical details and downloads.

## When to open it

Open the [live tester](https://fonts.floriankarsten.com/montagu-slab#tester) when comparing a typeface at display and text sizes, or when designing controls that make variable-font axes understandable.

## Most useful

- **Variable controls** — the main specimen exposes weight and optical size sliders. A lower control strip also adjusts leading and tracking; a toggle switches between variable and static display.
- **Multiple text scales** — the page pairs a huge headline sample with medium and small paragraphs, each with separate size, leading and tracking settings.
- **Multilingual proofing** — the samples include French, Polish and Czech text, while the page describes Latin, Vietnamese and Pinyin coverage and lists 687 glyphs at review.
- The information block names the designer, formats, OpenType features and links the specimen PDF, GitHub download and SIL Open Font License.

## Using it with agents

There is no published MCP, API, CLI or agent guide. An agent can use the public browser tester, read the technical specification and download the font from its linked GitHub release. The page explicitly links the SIL Open Font License 1.1.

## Watch out for

- The specimen is a foundry's font demonstration, not a complete production website; use it to study variable controls, typography and spacing.
- The weight and optical-size axes affect different properties. The page explains that optical size changes x-height, spacing, contrast and apertures, so do not treat the axes as interchangeable.
- The font's OFL does not license the foundry's page design or specimen copy.

## Reusable ideas

- Keep the main type sample large and direct, then place the controls in a persistent strip at its edge.
- Put the weight and optical-size axes side by side and name each axis with its current value.
- Show the same family in headline, subhead and paragraph contexts, with per-sample size and spacing controls.
- Use real multilingual text to expose how glyph proportions and line density change between scripts.
