# Reelfolio

## What it is

Reelfolio turns screenshots and screen recordings into short portfolio videos using prebuilt motion templates. Its public home page previews the editor and a selection of template outputs, so it can be studied as a visual reference without signing in.

## When to open it

Use the [template section](https://reelfolio.io/#templates) to compare ways of presenting interface work in motion. The [Rig](https://reelfolio.io/#templates), Viscose, Folio, Comet, Rolodex and Rise previews show different image sequencing, pacing and depth treatments. The four-step walkthrough also shows how a template picker, media strip and adjustment panel fit together.

## Most useful

- Template previews show the final motion rather than just a poster frame; examples include a cascading build, a liquid ring, a folder-to-grid transition and a vertical 3D roll.
- The editor walkthrough exposes useful controls for aspect ratio, background, blur, opacity, corner radius, media scale and duration.
- A simple Template → Upload → Customize → Export sequence communicates a media workflow without a conventional timeline.
- The same output is shown in landscape, portrait and square formats, useful for thinking about cross-platform export controls.

## Using it with agents

Reelfolio has a [render API](https://reelfolio.io/docs) for programmatic exports, but it requires a paid plan and API key. Public template previews are suitable as visual references; the service's own API docs should be used for current integration details.

## Watch out for

- The app and templates are proprietary. Commercial rights stated on the site apply to exported videos, not to redistributing the templates or app UI.
- The terms say uploaded images and rendered video URLs are publicly accessible, including after account deletion; do not upload confidential work.
- The public editor shown on the marketing page is a demo. Full use of the creation flow requires an account and paid access.
- This is a video presentation tool, not a substitute for designing the underlying interface.

## Reusable ideas

- Let a visual template preview play on hover so visitors can compare actual motion before opening a detail view.
- Keep media selection and output tuning visible together when users are arranging a short reel.
- Treat aspect ratio as an export-level choice and let the same project serve several destinations.
- Replace a complex timeline with a small number of named stages when the product has already designed the motion system.
