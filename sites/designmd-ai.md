# DESIGNmd

## What it is

DESIGNmd is a community library of design systems written as DESIGN.md files for AI coding tools: explore, download and use contributed systems, with a thin MCP server (seven tools, about 2K tokens of context at review) and a CLI so an agent can search the library without a browser.

## When to open it

Open it when you want a text design system to seed an agent, and you would rather search a community library than read through products one by one.

## Most useful

- **Search inside the agent**: the MCP server adds little context and exposes the library directly.
- **Per-file licences**: each upload states its own terms, which is honest for a community dump.
- **Format documentation**: the site also documents the DESIGN.md structure.

## Using it with agents

The MCP server and the CLI are the agent channels; the library itself is browsable with an account.

## Watch out for

- Quality and completeness vary by contributor; a downloaded system is a starting point, not a review.
- Per-file licences differ, so a mixed set of files is a mixed licensing obligation.

## Reusable ideas

- Keep the MCP surface thin so the library does not eat the agent's context.
- Record the licence per file when a library mixes sources.
