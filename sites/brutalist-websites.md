# Brutalist Websites

## What it is

A single-style gallery, and unusually for one, it argues for the style before showing anything. The opening paragraph states the position: in its ruggedness and its refusal to look comfortable or easy, brutalism reads as a reaction by a younger generation to the lightness and optimism of current web design. The header is a bare name and a dash, with a submit link — the aesthetic starts at the chrome.

The entries carry it through: raw type at default-looking sizes, visible structure, images that are not retouched, links that look like links. What the gallery collects is not ugliness but a deliberate refusal of finish.

## When to open it

Open it when a brief calls for rawness and you need to see the range of what that means, or when you are trying to explain to a stakeholder that "unfinished" can be a considered position with rules. It is also a useful corrective when your own work has drifted toward the same soft gradients as everything else.

## Most useful

- **A written definition at the top**, which makes the collection an argument rather than a mood board.
- **A narrow, consistent selection**, so the style's variations are visible: some entries are bare HTML, others are dense and typographic.
- **Submission by anyone**, which keeps the set closer to what people are actually making than a juried award list.
- **No framing around the screenshots**, so the work is judged as it is.

## Using it with agents

No `llms.txt`, API or feed at review. The page is server-rendered enough that an agent can read the entry list and links from the HTML, but there is no structured index to query.

## Watch out for

- Brutalism is easy to imitate and hard to justify: copying the look without the constraint produces a site that is merely awkward.
- Raw type and default styling frequently fail contrast and focus requirements; the style is not an exemption from accessibility.
- The collection skews toward portfolios, studios and personal sites, so it says little about product interfaces.
- Some entries lean on hostility as a gimmick, which is a taste choice worth naming rather than copying.

## Reusable ideas

- Define the style you collect in one paragraph; it converts a gallery into a position.
- Let the gallery's own page adopt the aesthetic it collects, at least in typography.
- Reward exposure over finish when the point is structure: visible borders, real underlines, no shadows.
- Keep submission open if you want the current state of a style rather than its canon.
