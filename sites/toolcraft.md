# Toolcraft

## What it is

Toolcraft is an open-source starter kit and UI library for building your own design apps with AI: create branded asset generators, explore new visual styles and turn repetitive design tasks into reusable tools. The repository carries an MIT licence (1,200 stars at review).

## When to open it

Open it when you are building a design tool (asset generator, style explorer) and want the scaffolding and UI library instead of starting from an empty canvas.

## Most useful

- **Starter kit, not snippets**: the whole shape of a design app, ready to brand.
- **UI library included**: components for the tool's own interface, not only the canvas.
- **MIT licensed**: fork it freely for commercial design tools.

## Using it with agents

No MCP or agent guide is published; the open-source repo is the working path, and the kit is designed to be built with AI assistance.

## Watch out for

- It is a foundation, not a finished design tool; expect to build the tool-specific logic.
- The repo is the source of truth, so check its recent activity before committing.

## Reusable ideas

- Sell the scaffolding, not the tool: branded asset generators are the use case, the kit is the product.
- Ship the UI library with the starter so the tool looks designed from day one.
