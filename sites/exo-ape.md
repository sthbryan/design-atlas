# Exo Ape

## What it is

Exo Ape is a digital design studio from the Netherlands, and its site is the portfolio: motion-first, immersive case storytelling where the interaction is the credential. There is no feature list because the site itself is the feature.

## When to open it

- When a studio or freelancer site needs to sell craft without a sales pitch, using the site's own motion as the proof.
- When case studies must feel like stories (full-bleed media, transitions, pacing) rather than project grids.
- When interaction details (cursors, hovers, page transitions) are the client-facing signal, not decoration.

## Most useful

- Project storytelling with pacing: each case unfolds as a sequence, not a gallery of thumbnails.
- Motion treated as the brand: transitions, reveals and cursor behavior carry the identity more than any statement does.
- Typographic confidence: large, deliberate headlines that set the tone before any project appears.
- The site stays focused: one studio, its work, its name, with minimal chrome around the experience.

## Using it with agents

- No agent channel is declared on the site at review.
- An agent can only read the public pages; the interactions are the content, so a study needs a browser, not just the text.

## Watch out for

- The site is a portfolio, not a template; every interaction is bespoke and the work is the studio's own.
- All content is look-only at review; do not reuse the motion patterns or copy as production code without reworking them.
- Performance-heavy motion is part of the experience; study it with the browser, since a text extraction loses it.

## Reusable ideas

- Sell craft with the site's own motion as the credential, instead of describing craft in words.
- Present case studies as paced stories with full-bleed media, not as grids of thumbnails.
- Let typography set the tone before any project appears, so the first screen already signals the standard.
