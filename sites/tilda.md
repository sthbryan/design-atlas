# Tilda

## What it is

Tilda is a block-based website builder, and the block library is the design argument: over 550 pre-designed blocks at review, grouped by job — fullscreen covers, typography-led text blocks, photo galleries, background video, forms. Pages are assembled by mixing blocks, and a "Zero Block" canvas editor takes over when a block is not enough. Its typography page makes specific claims worth reading for anyone designing a template system: line length, spacing and font sizes are set inside each block, so a page stays readable without the author making type decisions.

## When to open it

Open it when you need a page fast and want to see how a large block library stays coherent, or when you are designing a section library and need a reference for how blocks should be composed — one job per block, type already set.

## Most useful

- **Block taxonomy**: covers, galleries, text and forms are separated by what the section does, not by how it looks.
- **Typography handled by the block**: line length and spacing are pre-set, which is the main reason Tilda pages read cleanly at default settings.
- **Fullscreen and video covers** as first-class blocks, with the layout rules that make them usable.
- **Zero Block** for the cases where a pre-designed block fights the design.
- **AI page generation from a short brief**, which at review fills a page with copy and images rather than an empty grid.

## Using it with agents

No `llms.txt`, MCP server or API was found at review, and generated pages live in the account. An agent can read the block library as a reference for section anatomy, but cannot build in Tilda. The practical loop is a person assembling blocks and an agent writing or reviewing the page copy and structure.

## Watch out for

- The free plan limits both the block set and the domain, so the library you see in marketing is not the one you get for $0.
- Code export is only on Business, so a site built on cheaper plans is locked to the platform.
- Blocks are designed to look good in isolation; mixing many of them can produce pages with six different rhythms.
- Cookie banner and consent copy take space above the hero on Tilda's own site.
- The AI generation is described in marketing terms; the quality of the output is not shown on the pages reviewed.

## Reusable ideas

- Group a section library by the job it does, so people pick by intent instead of by picture.
- Set type inside each block rather than exposing a global stylesheet; it keeps a page readable by default.
- Provide a canvas editor for the cases a block library cannot cover, rather than adding infinite block variants.
- Pre-set line length and spacing as part of the block, and say so.
