# Bounshy

## What it is

Bounshy is a public Framer specimen for a text effect called Glitch Input Canvas. It lays out editable text fields beside examples of different shake intensities, glitch colour groups, particle shapes and border treatments.

## When to open it

Open it when a hero, poster-like label or short piece of display type should react to a pointer. It is a narrow effect reference rather than a general typography gallery or documented component library.

## Most useful

- **[Live demo](https://bounshy.framer.website/)**: the first screen centers a black rectangle with a white gothic pixel wordmark on a sparse, dotted white field. A heavy heading and compact gray explanation sit directly below it.
- **Shake and colour samples**: later sections repeat the same text field with three named shake strengths and several three-colour palettes, making effect intensity and chromatic separation easy to compare.
- **Particle samples**: the lower examples introduce trails, bursts and alternate particle shapes; the page also shows text and particle borders over an image.

## Using it with agents

No MCP, API, CLI, `llms.txt` or agent-specific usage guide surfaced. The page describes hover-triggered motion, but this review could not trigger or verify the pointer effect. Use the examples to specify a visual direction and test interaction and reduced-motion behaviour in your own implementation; do not assume the component code is available for reuse.

## Watch out for

- The page reads like an experimental showcase: its repeated examples, inconsistent section labels and emphatic closing treatment are useful as effect samples but not as a complete page structure.
- Shake and particle effects can distract from longer text. Restrict them to short labels and provide a static or reduced-motion state.
- The page does not state component pricing, a download path or a reuse licence.

## Reusable ideas

- Show a motion effect at several strengths side by side so a designer can choose a restrained setting.
- Treat the chromatic offsets as a small palette that can be swapped without changing the text layout.
- Keep the effect sample inside a consistent field so the viewer can compare motion and particle differences without a new composition each time.
