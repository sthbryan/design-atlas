# Collected

## What it is

A design index that refuses the grid. The whole interface is a small wordmark, a tagline — "new web design inspiration on every visit" — and a shuffle control, above a single entry at a time. Each entry names the site and the studio that made it, so the credit is part of the item rather than a footnote. The rest of the page is empty by design.

That is the interesting decision: with no grid, there is nothing to scan, so the only way to use the site is to look at one thing properly and then ask for another. Browsing becomes a sequence with a rhythm instead of a contact sheet.

## When to open it

Open it when you want to leave a project alone for ten minutes and look at something you would not have searched for, or when you are designing an index and want an argument for showing less. It is a poor fit for targeted research: there is no filter, no category, no search.

## Most useful

- **One item per view**, which makes each entry compete on its own rather than as a thumbnail.
- **The studio credited beside the site**, useful when you want more work from the same hand.
- **A single shuffle control** as the only interaction — the interface is one decision wide.
- **Entry pages that keep the same restraint**, so the visit does not become a different product halfway through.

## Using it with agents

No `llms.txt`, API or feed at review, and because the content is randomised client-side, an agent that fetches the home page gets one entry at most. Sitemaps or individual entry URLs are the practical route, and they are not advertised.

## Watch out for

- Randomised browsing is hostile to research: without a filter, you cannot ask for "editorial sites with big type".
- No index page means you cannot see the collection's range before committing to it.
- The selection taste is narrow — small studios, art and culture — so the sample is not representative of the web.
- No licence is stated; treat entries as look-only.

## Reusable ideas

- Show one item at a time when the collection is meant to be enjoyed rather than searched.
- Credit the maker next to the work; it turns a bookmark into a lead.
- Give a random view a single obvious control and nothing else.
- Keep the entry view as quiet as the index, or the index's argument collapses.
