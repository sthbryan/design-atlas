# Mesh

## What it is

A focused browser tool for creating a full-screen mesh gradient. Its initial view shows a prompt field, three named starting points and a PNG download control.

## When to open it

Open it when you want to explore a soft, multicolor background quickly and export a large raster image for a visual mockup.

## Most useful

The gradient fills the viewport, with the prompt field and three example prompts centered in a translucent pill group. A single Download control sits near the bottom edge. The inspected default creates a broad blend of blue, violet, pink and warm yellow, with smooth transitions and no visible panel of numeric controls; the page title and initial preset describe the tool as a mesh generator.

## Using it with agents

No published agent channel, API, CLI or skill was visible in the reviewed page. An agent can use the site as a visual reference, but the prompt and export workflow needs a person or browser interaction.

## Watch out for

The PNG control is visible, but export behavior, prompt generation, responsive layout and generated-asset rights were not verified. Treat output as look-only until the site states its licence.

## Reusable ideas

- Let a preview occupy nearly the whole screen when the generated color field is the main decision.
- Keep a few curated starting prompts close to the input to make an open-ended generator easier to try.
- Put export in a stable, separate position so it remains easy to find without competing with the preview.
