# Typewolf

## What it is

An independent web-typography reference pairing live site showcases with identified typefaces, font recommendations and practical pairing notes. Site entries link to the live work and list the fonts used; typeface pages collect screenshots of that family in context and suggest alternatives or pairings.

## When to open it

Open it when choosing a web type pairing or when you need to compare how a face behaves in a real page hierarchy. Start with [Site of the Day](https://www.typewolf.com/site-of-the-day), a [font page](https://www.typewolf.com/grenette), or a curated [Google Fonts list](https://www.typewolf.com/google-fonts).

## Most useful

- **Daylight** — [/site-of-the-day/daylight-health](https://www.typewolf.com/site-of-the-day/daylight-health) names Grenette and Styrene and links to the live site. The Typewolf page presents the pairing under a centered serif title, a compact bold sans label and a large site preview; inspect the linked site for the full hierarchy. This is a useful route from a pairing to its actual web context.
- **Google Fonts recommendations** — [/google-fonts](https://www.typewolf.com/google-fonts) pairs each face with examples of sites using it. Open the example rather than treating the specimen as the complete design; the page separates font choice from the surrounding layout.
- **Font pages** — each family page includes alternatives and suggested pairings, which helps test whether a type choice can carry both display and supporting roles.
- The free [Typography Resources](https://www.typewolf.com/resources) directory and [free-font lists](https://www.typewolf.com/free-fonts) are useful follow-on paths when the visual direction is set but the licensing budget is limited.

## Using it with agents

There is no published MCP, API, CLI or agent guide. The public web pages are readable in a browser and expose text alongside the screenshots, so an agent can identify a pairing and open its example route. Keep suggestions grounded in the named typefaces and images; Typewolf does not provide an installation or implementation integration.

## Watch out for

- The site is a visual reference, not a font host. Check the foundry’s current web licence before using a commercial face.
- Some guides, lookbooks and the Flawless Typography Checklist are paid. The checklist is $399 at review; core site showcases and many lists are free.
- Popularity rankings and annual recommendation lists are the editor’s selection, not a neutral measure of fit for a particular product.
- A screenshot preserves a useful hierarchy example but can age. Follow the live-site link before relying on its current layout or typography.

## Reusable ideas

- Show the actual site screenshot beside the font names, then make each face link to its own reference page.
- Put a small, explicit “fonts used” line next to each featured page so readers can move from visual impression to a concrete pairing.
- Organize pairings around jobs such as headline and body, rather than only by abstract font categories.
- Offer practical alternatives on the typeface page, where a designer is already evaluating a family.
