# Sahil Singh

## What it is

Sahil Singh's design engineer portfolio combines a dark, ruled page layout with sections for an introduction, experience, projects, interactive components and writing. A command palette and theme control sit in the top navigation.

## When to open it

Use it to study how a portfolio can double as a small interface catalogue. The Components route shows working interaction examples such as a keyboard, image-generation card and searchable dropdown, alongside the project and blog sections.

## Most useful

- Thin borders divide the black page into a three-column frame; section titles occupy a separate left rail from the content.
- A sparse dotted panel introduces availability above the profile, while diagonal hatch bands separate major sections.
- The command-palette shortcut and theme switch sit beside the main navigation rather than being buried in the page.
- Component entries pair a live example with a short description and a route to the full demo.

## Using it with agents

No published agent channel was found. Give an agent the homepage or a specific route under `/components/` and ask it to describe the grid, component behavior and page hierarchy observed there.

## Watch out for

- The grid and thin dividers create a strong dark theme; keep section boundaries and type contrast clear if adapting it to a light palette.
- Several component examples are interactive and include sound or animation, so provide a reduced-motion and silent path in a similar portfolio.
- No reuse licence was stated for the site content or component presentations.

## Reusable ideas

- Separate section labels from section content with a consistent page-wide grid.
- Treat a command palette and theme switch as part of the portfolio's global navigation.
- Pair each component preview with a concise explanation and a stable detail route.
