# Code and Chill

## What it is

Code and Chill is a library of animated UI components and website templates in plain HTML, CSS and JS, aimed at client sites. Each one is shown working before you buy it, and the licence covers use in your own and client work.

## When to open it

Open it when you need animated components or full templates without a framework, or when a client project needs a done-for-you animated section.

## Most useful

- **Plain HTML, CSS and JS**: no build step or framework lock-in for the components.
- **Templates as well as parts**: complete website templates alongside individual components.
- **Client-work licence**: the licence explicitly covers client projects, which many libraries leave ambiguous.

## Using it with agents

No MCP, API or agent guide is published; an agent can read the component source and adapt it in a browser or editor.

## Watch out for

- It is a paid library; check the licence page for what the licence does not allow before buying.
- Hand-written CSS animation means you own the performance tuning.

## Reusable ideas

- Show every component working before asking for a purchase.
- State the client-work licence on one screen instead of burying it in terms.
