# Overtone

## What it is

Overtone is an independent design studio based in Aarhus, Denmark. Its home page presents a large, pale-green-to-gray headline above a compact floating navigation, then leads into featured work, type design and journal sections.

## When to open it

Open it for a current studio-site reference that connects expressive display type, a concise services overview and a route into project case pages.

## Most useful

- **Home page** — the oversized headline carries the opening view while the rounded navigation and separate Contact control stay small and easy to find.
- **Work pages** — a [featured case layout](https://overtone.dk/work/kunsthal-spritten) shifts into a dark ground and large editorial images, with project details arranged before the image sequence.
- **Type design** — the home page exposes a separate type-work route, useful when a studio portfolio needs to distinguish bespoke typography from broader identity and digital work.

## Using it with agents

No MCP, API, CLI or agent guide is published; `/llms.txt` returns the site's not-found page. An agent can inspect the public home, work, type and journal pages in a browser.

## Watch out for

- The pale gradient text is low contrast against white in the opening view. Keep display styling separate from essential body copy and controls.
- The portfolio is free to browse; service prices and a reuse licence were not stated at review. Treat the work as look-only.

## Reusable ideas

- Pair one oversized headline with small, consistently placed navigation controls.
- Let a clear tonal shift separate the studio introduction from image-heavy case pages.
- Give custom type work its own route so visitors can find it without searching through the general project archive.
