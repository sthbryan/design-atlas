# IconMind

## What it is

IconMind is an open-source icon library for AI-era software: 5,287 icons at review covering LLMs, agents, MCP, RAG, data, DevOps and general interface needs. Every icon is drawn from one 24×24 rule, in outline and duotone across three weights.

## When to open it

Open it when a product needs icons for AI and developer concepts (agent, model, tool call, embedding) that generic sets lack.

## Most useful

- **AI vocabulary**: the concepts that usually get improvised from unrelated icons.
- **One drawing rule**: consistent geometry across the set, so mixed icons still match.
- **Six drawings per icon**: two variants across three weights, so weight can follow context.

## Using it with agents

An MCP server and `llms.txt` are published, so an agent can search the set by concept.

## Watch out for

- It is still pre-1.0 (0.8.4 at review), so names and coverage can shift.
- AI-concept icons are a fast-moving vocabulary; expect additions.

## Reusable ideas

- Draw every icon from one rule, then offer weights rather than a second family.
- Cover the vocabulary of the product's domain, not only generic UI verbs.
