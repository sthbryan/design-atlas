# BentoGrids

## What it is

A browsable reference collection for bento-style compositions. The catalogue groups examples into Discover, Graphic Design, Web Design and Animation, with additional light and dark filters. Each entry opens a detail view with a link to its source site.

## When to open it

Use it when a page needs a grid of unequal tiles, a modular product story, or a compact way to combine brand, interface and feature previews. Start with Web Design for full-page layouts and Graphic Design for identity-led compositions.

## Most useful

The entry for [Chroma](https://bentogrids.com/shots/cmf19eok60001lau6o6thn8x7) links to [Chroma's live site](https://www.trychroma.com/). The current site uses framed product panels and contrasting interface areas over a monochrome illustrated backdrop; compare the catalogue preview with the live page because featured designs can change. BentoGrids itself presents examples as a dense, image-led card grid with simple category controls.

## Using it with agents

There is no published MCP, API, CLI, `llms.txt` or agent skill visible in the reviewed site. An agent can browse the catalogue and follow its source links; treat images and featured designs as visual references only.

## Watch out for

The About panel says the displayed work belongs to its respective creators and is shown for educational purposes. No general reuse licence or terms page was stated. Ask the relevant creator before reusing an image or design asset.

## Reusable ideas

- Build a bento composition from a few clear content roles, then vary tile size to establish hierarchy.
- Compare light and dark examples to see how tile boundaries, imagery and background contrast carry the layout.
- Follow a catalogue card to the current source before relying on its details; a thumbnail does not guarantee the live site still matches it.
