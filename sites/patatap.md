# Patatap

## What it is

Patatap is a small browser instrument built around a keyboard and a canvas. Pressing a letter produces a short sound and a matching geometric animation; the page also links to related music projects and a key-to-sound conversion table.

## When to open it

Open it when you need to study a playful sound interaction, a one-screen creative tool or a restrained canvas that changes in response to input.

## Most useful

- **Canvas response**: after the page has focus, a letter key draws a simple black dotted arc on the light gray field. The shape appears while the rest of the canvas stays uncluttered.
- **Prompt placement**: a small centered hint explains the keyboard interaction; supporting links sit in a low-contrast strip along the bottom.
- **Sound pairing**: each letter is mapped to a visual and an audio response, so the interaction can be explored without navigating a settings panel.

## Using it with agents

There is no published agent interface or `llms.txt`. Give an agent the page and ask it to describe one key press as a sequence of input, sound and visual feedback. The key-to-sound conversion table is linked from the page footer.

## Watch out for

- The page warns that it contains flashing images. Check motion sensitivity and offer an alternative before adapting rapid visual responses.
- Audio requires a user gesture and working speakers to experience the full interaction.
- The linked privacy policy describes aggregate button-use tracking and Google Analytics. It does not state a reuse licence for the experience.

## Reusable ideas

- Map a small set of direct inputs to immediate audiovisual feedback, with no setup step beyond focusing the canvas.
- Keep the canvas visually quiet between interactions so each response reads as an event.
- Pair the visual action with a compact instruction and a reference table for discovering available inputs.
