# Design Engineer Tools

## What it is

Design Engineer Tools is a single page listing tools that its curator, James Warner, recommends for web-focused design engineers. Each item is just a name that links out, grouped under 20 headings, with no descriptions, screenshots or pricing. It is a small Next.js site on Vercel, and the Wayback Machine has copies from November 2024. It is not related to [DesignEng](designeng-tools.md) at designeng.tools, which has a near-identical domain but a different owner and format.

## When to open it

- When you want one person's short list of picks across the whole design-engineering stack, not a big catalogue.
- When you need a starting point for areas that UI directories often skip: volumetric capture, glTF tooling, node-based visual tools or digital fashion.

## Most useful

- About 128 links at review under 20 headings: Inspiration, AI Code, Components, Web Utility, Desktop Utility, Video & Capture, Whiteboard, Organization, Fonts, Visual, Interface, Motion, Audio, Volumetric, 3D, glTF, Digital Fashion, Research, Browser and Emoji.
- **Inspiration** (about 22) mixes web galleries with game-UI references such as HUD and in-game interface archives.
- **Visual, Motion and 3D** cover node-based and shader tools, motion editors (Cavalry, Jitter, Lottie tools, Theatre.js) and 3D apps from Blender and Houdini to Spline.
- **glTF** and **Volumetric** list pipeline tools (gltfjsx, gltfpack, a viewer) and photogrammetry and splat apps.

## Using it with agents

No llms.txt, MCP or API, and the entries carry no descriptions an agent could use. Treat it as a checklist for yourself: pick a tool, then give the agent that tool's own documentation.

## Watch out for

- Names only: you have to open each link to learn what it is, what it costs and whether it's still maintained.
- Much of the list is general software (AI code editors, browsers, terminals, note apps, screen recorders), not design references.
- There's no date or changelog, so it isn't clear how recently the list was checked.
- There's no way to suggest a tool, and the page doesn't say how entries are chosen.

## Reusable ideas

- Grouping tools by the job in the pipeline (capture, 3D, glTF, motion, audio) shows what a full web and 3D workflow involves.
- A names-only page stays fast and easy to keep up, but it only works when readers already trust the curator.
