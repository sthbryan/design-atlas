# PaceUI

## What it is

PaceUI is a React UI catalogue for Next.js and TanStack Start. It combines copyable components and layout blocks with animated “crafts,” full templates, starter kits, an MCP server and a shadcn-compatible registry. The home page previews each category in use.

## When to open it

Open it when you need to compare a finished dashboard or marketing section with its smaller reusable pieces. The template and block demos show how cards, tables, sidebars and charts fit together at page scale.

## Most useful

- The [Ultimate Admin Dashboard email preview](https://paceui.com/preview/templates/ultimate-dashboard/apps/email) shows one shell connected to distinct email, calendar, analytics and data views.
- The [AI SaaS template preview](https://paceui.com/preview/templates/ai-saas) provides complete landing-page sections, including pricing and footer treatments.
- Animated crafts such as the voice recorder and rolling-image bento are useful references for motion applied to compact controls and cards.
- The MCP and registry expose the catalogue to coding tools; the free tier is available without a credit card.

## Using it with agents

The site offers an MCP connection and shadcn-compatible installs. Ask an agent to browse the live preview first, then name the component or template and framework before installing or adapting it.

## Watch out for

- The displayed Pro and Team prices are one-time purchase prices, and may change.
- A named component reuse licence was not stated on the pages reviewed; check the purchase terms before redistributing source or templates.
- The catalogue is designed around React and the shadcn/Base UI ecosystem, so adapt its patterns rather than assuming framework-neutral markup.

## Reusable ideas

- Let one realistic app shell show how a family of screens behaves together.
- Keep component previews interactive and place the code/install action directly beside each example.
- Pair restrained dashboard foundations with a few animated accents to give dense screens a clear focal point.
