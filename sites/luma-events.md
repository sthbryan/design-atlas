# Luma Events

## What it is

Luma is an event creation, discovery and ticketing platform. The Spanish-language homepage centers a large headline with a warm gradient accent, then surrounds it with floating invitation cards for different kinds of gatherings. The composition makes the product category legible before the visitor reaches the event-creation call to action.

## When to open it

Use it as a reference for an event product, a localized marketing page or a visual treatment that turns user-created content into the hero. The separate discovery link also shows how the product presents browsing as a second path beside hosting.

## Most useful

- **Floating event cards**: a loose, layered field of invitation art frames the hero without becoming a conventional carousel.
- **Localized copy**: the Spanish homepage adapts its headline, body and calls to action to the selected locale.
- **Two clear routes**: visitors can create an event or discover existing ones.
- **Event discovery**: examples link to real event pages, so the product's output is visible from the landing page.

## Using it with agents

No public MCP, API or agent instruction file for the events product was found. The public site is useful as a visual and UX reference; its event content is user-generated and should not be treated as reusable source material.

## Watch out for

- The service is free for ordinary events, but paid ticketing has processing costs; check the current plan and fee before making a pricing comparison.
- The terms give Luma and applicable hosts a broad licence to content users post. Do not reuse event descriptions or invitation artwork as if it were a public asset library.
- Event listings are controlled by their hosts, so details and availability vary.

## Reusable ideas

- Use a few varied examples of user-created output to make an event tool's promise concrete.
- Offer a primary creation action and a secondary browsing action for visitors with different intent.
- Keep the headline centered and short when surrounding visual cards already carry category context.
- Localize the whole hero, including action labels and supporting copy, rather than only translating navigation.
