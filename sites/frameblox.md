# Frameblox

## What it is

Frameblox is a commercial UI kit and design system for Framer, made by Solt Wagner (the same maker as Icoon). At review the site counted 1,400+ sections and components, 130+ prebuilt pages, 7 CMS collections and 4 full templates, each in light and dark versions. The largest groups are hero (60+ variants), blog (27+), features (25+), about, contact and CTA sections. There are also event, award and bento sections. You work with it through the Framer files, a web library that copies layouts in one click, and a Framer plugin that drags sections straight into a project. A "daily component" series adds new hero and section designs on weekdays. The newest dated entry at review was from March 2026.

## When to open it

When the site is being built in Framer and you want a consistent system of type styles, colour styles and sections instead of stitching templates together. It suits freelancers and agencies who ship many Framer marketing sites and want one licence for all of them.

## Most useful

- **Hero sections**: the biggest set, including video-background and animated versions.
- **Prebuilt pages**: landing, blog, team, contact and about pages that already use the same styles.
- **CMS collections**: ready collections for blogs and similar content, wired to the sections.
- **Styles**: shared text and colour styles, so swapping the brand is one change.
- **Framer plugin**: browse and insert sections without leaving the editor.

## Using it with agents

Not agent-ready. The content lives in Framer files and a Framer plugin that needs an email and licence code. There is no code export, registry, API or `llms.txt` (404 at review).

## Watch out for

- Nothing useful is free: the daily components show a copy button but need Pro access.
- Pricing depends on a running sale, so check the current figures.
- The licence has no refunds for any reason, including a Framer update that breaks something.
- It only helps if you stay in Framer; there is no route to React or HTML.

## Reusable ideas

- Ship a kit as styles plus sections, so a rebrand changes the tokens, not every block.
- Publish one small component every weekday to show the kit growing and give people a reason to come back.
- Sell a separate template-creator tier instead of banning template sales outright.
