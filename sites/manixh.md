# Manixh

## What it is

A dark, long-form portfolio for developer Manish Kumar. It groups profile details, skills, employment, projects, analytics and contact links on the home page, with separate Projects and Resume routes.

## When to open it

Open it for a high-density portfolio that uses a restrained dark canvas and repeated UI motifs to make a large amount of technical information scannable.

## Most useful

The page pairs a compact profile header with short bullet points, then uses dashed-outline social cards and small square icon controls as recurring accents. Skills run in repeated horizontal strips; work and project sections use clear headings, status labels, technology tags and links. The contrast between the dark field and small saturated icon colors keeps the page subdued without making every element monochrome.

## Using it with agents

The linked GitHub repository documents `npx manixh-portfolio` for installing its `AGENTS.md`, `DESIGN.md`, component and architecture notes, and a prompt for AI coding agents. This gives an agent a second route to inspiration: the live portfolio and the project’s own design documentation. The repository is MIT-licensed; the live portfolio footer retains all rights.

## Watch out for

The repeating skill strips and long technical inventory can become noisy on smaller screens. The MIT licence applies to the repository contents it covers; the live portfolio separately says all rights reserved. Check the intended file before reusing it, and do not assume the portfolio imagery is MIT-licensed.

## Reusable ideas

- Repeat one outline treatment across social cards and smaller controls to tie unlike sections together.
- Group a dense skills inventory into horizontal runs, while keeping the section title and content aligned.
- Use status labels and small technology marks to add context to project cards without adding long summaries.
