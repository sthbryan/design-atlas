# Collect UI

- **URL:** https://collectui.com
- **Type:** inspiration gallery
- **Topics:** inspiration, components, motion
- **Pricing / licence:** Not stated (free to browse; funded by sponsor listings in the Panda Network; each design stays credited to its designer and links to the original post on X)
- **Reviewed:** 2026-09-25

## What it is

Collect UI is a daily UI inspiration feed that collects interface shots and motion clips designers post on X, credits each one to its author and files it under component-style categories. It belongs to the Panda Network, alongside Best Designs On X, which is credited as the curator on each item.

## When to open it

- When you need several takes on one specific UI element (dropdown, date picker, command bar, OTP input, file tree) and want to jump straight to that category.
- When you're looking for micro-interactions and motion ideas, since much of the feed is short video rather than static screenshots.
- When you want to find designers who are good at a particular kind of work, via the designer directory and leaderboards.

## Most useful

- Over 150 categories listed with item counts on the Categories page; the biggest are UI Interaction (about 700), Motion, Landing Page, Card, Hero Section, Web Animation, Dark Mode and Sidebar, plus trend tags like Liquid Glass, Orb, Shader and Terminal Aesthetic.
- A full-screen viewer per design with the designer's X handle, the original post text, category tags, a "View on X" link, arrow navigation and a keyboard shortcut to like.
- A Trending page with two leaderboards: most-featured designers by post count and most-clicked designs, each switchable between all time, this week and this month.
- A designer directory (well over a thousand X handles across 58 pages at review time) and a "hire" sidebar pointing to studios.
- Search, newest/oldest sorting, a favorites list, a design submission button and a daily email digest.

## Using it with agents

No MCP, llms.txt, API or export. Use it manually: pick the category you need, open two or three clips, describe the interaction to the agent (trigger, timing, easing, what moves and what stays fixed) and ask it to rebuild the behavior in your stack.

## Watch out for

- Items are posts from X, so the work belongs to the individual designers; treat it as reference, not as assets to reuse.
- Category tagging is loose: some tags appear twice and a single design often carries several unrelated tags.
- Sponsored tools and network cross-promotion sit next to organic entries in the sidebar and inside the viewer.

## Reusable ideas

- A category page per UI element with a visible item count tells users at a glance which patterns have enough examples to be worth browsing.
- Ranking designers by how often they get featured, and designs by clicks, with a time-range toggle, turns a feed into a discovery tool for people as well as pixels.
- Showing the original post text beside the design keeps the designer's own context (tools used, intent) attached to the reference.
