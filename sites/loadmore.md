# loadmo.re

## What it is

loadmo.re is an archive of experimental and unconventional mobile websites, curated by designer and UX/UI educator Kim Lê Boutin since 2021. It describes itself as the first collection dedicated only to mobile sites, and it deliberately favors work that uses the phone as a medium (touch, camera, sound, tilt) over efficient but standard layouts.

## When to open it

- When a mobile layout feels like a shrunken desktop page and you want examples that were designed for the phone first.
- When you're working on a portfolio, cultural, editorial or campaign site where personality matters more than conversion.
- When you're teaching or pitching creative coding and need proof that mobile web can be expressive.

## Most useful

- Around 400 hand-picked entries across 13 pages, each with a screen-recorded video preview, a one-line description, full credits for the studio or designers, the date added and a direct link.
- 30+ tags mixing genre (portfolio, e-commerce, online magazine, event, digital exhibition) and approach (brutalist, glitches, tactile, participative, use of camera, sound design, net.art, playful).
- "Also in" links on each entry that surface other sites sharing a tag, which makes browsing by approach easy.
- A featured pick at the top of the homepage, a newsletter digest and an open submission form.

## Using it with agents

No MCP, llms.txt, API or export. Use an entry as a brief: tell the agent which interaction carries the site (for example camera input or drag-to-reveal), how the layout uses the narrow viewport and which tag it belongs to, then ask for a prototype of that behavior rather than a copy of the site.

## Watch out for

- Additions are occasional; the newest entries seen at review time were added in January 2026.
- Many featured sites are experimental, so some may be slow, broken or offline by the time you open them.
- The focus is expressive work; look elsewhere for mainstream mobile conversion patterns.

## Reusable ideas

- Tags that describe the approach ("use of camera", "tactile", "participative") help designers find ideas by technique rather than industry.
- Crediting every contributor on each entry, not just the brand, builds goodwill with the studios whose work you feature.
- Previewing each site as a screen recording rather than a still shows the motion and interaction that make experimental mobile work worth featuring.
