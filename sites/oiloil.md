# Oil UI

## What it is

Oil UI is an open-source UI design skill for Claude Code and Codex: a plugin that teaches the agent to produce designed interfaces instead of generic ones. It is multilingual, with documentation in more than a dozen languages at review.

## When to open it

Open it when your agent's UI output looks designed-by-default and you want a skill-level fix rather than a component library.

## Most useful

- **Skill, not templates**: it changes how the agent designs, so it applies to any stack.
- **Two agent hosts**: Claude Code and Codex plugin paths from one source.
- **Open core**: MIT-licensed, so teams can fork and adapt the skill.

## Using it with agents

The skill installs as a plugin in Claude Code and Codex; the site documents the setup for both. A Pro tier exists for additional material.

## Watch out for

- A skill steers taste; it does not replace reviewing the rendered UI.
- The Pro tier's scope was not detailed on the pages checked.

## Reusable ideas

- Package design taste as a skill so it travels across projects instead of living in one prompt.
- Publish the core openly and keep advanced material behind a tier.
