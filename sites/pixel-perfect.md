# Pixel Perfect UI

## What it is

A collection of React interface components arranged in a live preview gallery. The Blocks page grouped examples into 19 categories at review, including buttons, backgrounds, motion and shaders. Individual previews expose controls, source code and a registry install command.

## When to open it

Open it to study expressive controls, decorative backgrounds and small motion treatments in isolation. The button category is a quick place to compare materials such as glass, bevel, metallic shine and glow while changing a preview's settings.

## Most useful

The [Blocks gallery](https://www.pixel-perfect.space/blocks) shows multiple component previews in a compact card grid. Select a card to inspect its rendered state and controls; use its Copy action to reveal the source and package-manager commands. The page offers commands for npm, pnpm, Bun and Yarn through a shadcn-compatible registry.

## Using it with agents

The component registry is the published agent-friendly channel: individual cards expose install commands and source. No MCP server, `llms.txt`, CLI or separate HTTP API was found in the reviewed navigation. The linked [GitHub repository](https://github.com/vansh-nagar/Pixel-Perfect) is public, but has no named licence in its root files; treat code as look-only until a licence is provided.

## Watch out for

The gallery is primarily a showcase, so inspect each component's source, dependencies and responsive behavior before adopting it. A free install command does not grant reuse rights when the repository has no stated licence. The site invites a $3 donation; no paid feature tier was presented at review.

## Reusable ideas

- Let people compare a component's visual variants in place, with controls close to the preview.
- Keep a small decorative effect attached to a familiar control shape so its function remains legible.
- Check animated and shader examples with motion preferences and reduced-power devices before use.
