# Metabase

## What it is

Metabase is a business intelligence tool built around one idea: anyone in the company can explore shared data. Dashboards are explorable rather than read-only, and the open source AGPL edition includes unlimited users, which is unusual for BI and central to the product story.

## When to open it

- When dashboards must be explorable by non-analysts: filter, drill and ask questions without SQL.
- When an open source BI edition needs to be genuinely usable, not a crippled demo of the paid product.
- When embedding charts in a product is in scope, and the licensing paths (AGPL, embedding licence, commercial) are laid out clearly.

## Most useful

- The free edition's generosity is the pitch: unlimited users, unlimited questions and dashboards at review, stated on the pricing page.
- Interactive dashboards positioned as exploration surfaces: the same dashboard works for a glance and for a deep dive.
- Licensing transparency: open source, cloud and commercial licences are explained on a dedicated license page rather than buried in terms.
- The site's calm, generous whitespace matches the product's approachable-BI positioning.

## Using it with agents

- Metabase ships an MCP server and an API behind credentials; the free edition includes both at review.
- The public site and docs are the agent reference; live instances need an account or a self-hosted install.

## Watch out for

- AGPL obligations apply to the open source edition and to embedding paths; read the license page before embedding in a commercial product.
- Cloud pricing at review (Starter base plus per-user fees) is stated on the pricing page; confirm live before budgeting.
- Commercial features (SSO, auditing, whitelabel) sit in paid tiers at review, so compare the edition list before choosing.

## Reusable ideas

- Make the free edition's limits about features, not about seats, when the product's story is democratized access.
- Publish a plain licensing page that spells out every path (open source, embedding, commercial) in one place.
- Design dashboards that serve both the glanceable KPI view and the full exploration view from the same layout.
