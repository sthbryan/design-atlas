# Sevalla

## What it is

Sevalla is Kinsta's cloud platform for deploying applications, databases, object storage and static sites. Its homepage is a useful reference for presenting infrastructure as a joined product system: a restrained orange accent, oversized centered headline, clear paired calls to action, and a large dashboard preview lead into product, agent, geographic and pricing sections.

## When to open it

Open it when a developer platform needs to explain several related services without making the landing page read like a feature checklist. The MCP section is also a current example of describing what an agent can do in a production console.

## Most useful

- **Product overview**: four service links sit under one platform promise, with screenshots to make the abstract offer concrete.
- **AI agent section**: explains deployment, scoped access and production debugging as distinct tasks.
- **Location section**: pairs a map with data-center and edge-network facts.
- **Pricing calculator**: visitors can configure resource types and see a monthly estimate before starting.

## Using it with agents

Sevalla publishes an MCP connection guide, API documentation and `https://docs.sevalla.com/llms.txt`. The homepage links directly to the MCP overview. An agent can use the docs to inspect deployment, database and observability actions; account permissions and project scope remain relevant to what it can change.

## Watch out for

- Prices depend on resource size and use. The $5 starting amounts and free allowances are the published starting terms at review, not a final estimate.
- The MCP integration can operate production resources; read the scoped-permission documentation before connecting it to a live account.
- The terms are provided by Kinsta, which owns Sevalla. The site's screenshots, copy and brand assets have no reuse licence stated.

## Reusable ideas

- Start with one plain-language outcome, then use a dashboard image to connect the promise to the actual product.
- Explain an agent integration through specific tasks and permission boundaries instead of a generic “AI-powered” badge.
- Pair geographic claims with a simple map and concrete counts.
- Let visitors build a realistic price estimate from the product's core resource types.
