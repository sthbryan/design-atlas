# Python Graph Gallery

## What it is

The Python Graph Gallery is a curated site by Yan Holtz that collects hundreds of charts drawn with Python libraries such as Matplotlib, Seaborn, Plotly, Altair and ggplot2. Each example is a page: the finished chart, a plain-language explanation of what it shows and when to use that form, and the full reproducible code that produced it. A newsletter wraps the collection with hand-picked lists.

## When to open it

Open it when a chart has to ship from a Python workflow and you want the code, not just a picture. It is also a good reference for choosing among chart forms, because each page states the idea behind the visual in plain words.

## Most useful

- **Reproducible code on every page**: copy the snippet, swap the data, keep the chart
- **Explanations, not just captions**: each page says what the chart is for and what to watch out for
- **Wide library coverage**: matplotlib through plotly and altair in one style of page
- **Newsletter lists**: hand-picked top-300-lists of dataviz projects for free

## Using it with agents

There is no llms.txt, API or MCP server. The pages are plain HTML with code blocks, so an agent can fetch a page and reuse the recipe. Before reusing code, check the licence page linked in the footer, because this review did not confirm a licence.

## Watch out for

- The licence of the example code was not stated on the gallery pages at review; treat snippets as look-only until checked
- Charts are illustrated with the author's datasets, so adapt the narrative, not just the code

## Reusable ideas

- Pair every example with its reproduction code and a sentence of when to use it
- Organise by chart type first, library second, since the reader's question is about the form
