# Piixpal

## What it is

Piixpal is a library of 300+ free, MIT-licensed animated UI components and templates: tiny pixel characters that live on the page (crawling on headings, napping on paragraphs, perching on buttons), WebGL shader backgrounds, animated hero sections and 76 landing-page hero templates, plus ASCII and pixel art.

## When to open it

Open it when a page needs playful, animated life (pixel characters, shader heroes) and you want MIT-licensed source you can ship.

## Most useful

- **Characters that live on the page**: pixel creatures as components, which is a distinctive, memorable touch.
- **Hero templates included**: 76 landing-page heroes, so the animated pieces arrive in context.
- **MIT licensed**: free for commercial use with attribution to the library's terms.

## Using it with agents

An `llms.txt` and a skill are published, so an agent can browse and install components in the session.

## Watch out for

- Pixel characters are a strong style choice; they will not suit every brand.
- Animated heroes need reduced-motion and performance care.

## Reusable ideas

- Ship characters as components with behaviour (crawl, nap, perch), not as static images.
- Include hero templates so animated components arrive in a real layout.
