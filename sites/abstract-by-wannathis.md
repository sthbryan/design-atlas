# Abstract by Wannathis

## What it is

Abstract by Wannathis is a single pack of sculptural 3D objects sold for Figma and Blender, with transparent PNG exports. The set moves between fuzzy surfaces, polished metal, glass, and gradients; its forms include loops, springs, cut spheres, arrays, and irregular organic shapes.

## When to open it

Open the [full Abstract preview](https://wannathis.one/products/abstract-3d-illustrations) when a portfolio, campaign, or product hero needs an expressive object rather than a literal UI illustration. The gallery makes useful comparisons between fuzzy turquoise forms, chrome rings, translucent glass, and vivid gradient objects. Use a single isolated form as an accent, or repeat related forms as a loose background composition.

## Most useful

- Objects have transparent backgrounds, so they can sit over a chosen surface or colour field.
- The pack includes Figma, Blender, and PNG formats, giving designers both ready-to-place renders and source files for further work.
- Its mixed surface treatments make it useful for art direction studies: compare how roughness, reflectivity, and colour change the tone of the same abstract vocabulary.

## Using it with agents

There is no published API or agent integration. An agent can use the product preview as a visual reference, but it should not imply that the images are editable vector shapes. For a generated replacement, describe the silhouette, finish, lighting, and background separately instead of asking for a generic “3D blob.”

## Watch out for

- The product page initially selects a Personal, non-commercial licence. Choose the Commercial or Extended tier before using the asset in paid work; do not assume that the pack's displayed base price covers commercial use.
- The licence forbids reselling or redistributing the source files and prohibits end users from extracting assets from a product. Review the [Wannathis licence](https://plugin.wannathis.one/license) for the selected item and tier.
- The forms are decorative. They can compete with product content if used as multiple large focal points or behind small text.

## Reusable ideas

- Create contrast through surface finish: one soft fuzzy object beside a hard reflective form can add depth without introducing extra UI elements.
- Use a transparent background to control cropping and colour locally, instead of baking each object into a full scene.
- Repeat a shape family at different scales and angles to make a hero composition feel intentional while retaining negative space for type.
