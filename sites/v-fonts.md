# V-Fonts

## What it is

A catalogue for finding and trying OpenType variable fonts. Each entry shows a specimen, the available axes, designer and publisher, character coverage and a licensing category, with a link to the font source. The catalogue showed 377 entries at review.

## When to open it

Open it when comparing a variable family’s actual range, checking what axes it exposes, or finding a font by design trait, script, publisher or licensing category. Try the specimen before following the source page.

## Most useful

- **Catalogue** — [v-fonts.com](https://v-fonts.com/) exposes the axis controls directly beside each specimen. On the visible page, Roboto Flex shows weight, width, optical size, slant, grade and further custom axes; HEX Franklin Variable makes a weight and width range legible at a glance.
- **Exposure VAR** — [/fonts/exposure-var](https://v-fonts.com/fonts/exposure-var) is a serif with an Exposure axis. Use it to compare how a nonstandard axis changes texture, not just weight or width.
- **Roboto Flex** — [/fonts/roboto-flex](https://v-fonts.com/fonts/roboto-flex) lists numerous registered and custom axes and supported scripts. It is a concrete reference for how much typographic control one file can expose.
- **Licensing filters** — [/licenses](https://v-fonts.com/licenses/) separates open-source, trial, paid/commercial and other terms. This is a discovery aid; the catalogue itself warns that each font’s terms can differ.

## Using it with agents

There is no API, MCP, CLI, llms.txt or copyable implementation guide. An agent can browse the public catalogue and read the axis names, supported characters and license categories, then follow the linked source. The specimens are the key evidence; use the linked foundry or repository for font files and authoritative license terms.

## Watch out for

- The catalogue is presented as a limited beta and is not guaranteed to be exhaustive.
- Variable specimens need browser support for OpenType font variations. Without it, a sample can appear static and hide the point of the reference.
- A catalogue label is not the full font licence. Some pages list multiple options, such as open-source and bundled, or trial and paid.
- The catalogue’s version and entry set have not changed much recently; use its live search as a discovery aid and confirm the font at its linked source.

## Reusable ideas

- Put each axis slider beside the glyph sample so its range is understandable in context.
- Show the font’s script coverage and named axes next to the specimen, where they inform whether it can work in a real interface.
- Label licensing categories on the same page as the sample, then link to the source of the actual font files.
- Use unusual axes such as exposure, grade or optical size as examples of what variable typography can change beyond boldness.
