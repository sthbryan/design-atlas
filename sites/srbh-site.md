# Saurabh Sharma

## What it is

Saurabh Sharma's portfolio brings together a profile, experience, GitHub activity, projects, open-source pull requests, component examples, blog posts and a dated learning log. A slim rounded navigation bar sits above a centered stack of bordered panels.

## When to open it

Use it when a developer portfolio should show ongoing activity and open-source work alongside selected projects, or when a card-based page needs to present several kinds of personal content without a conventional case-study grid.

## Most useful

- The page uses one centered column of lightly bordered panels with consistent spacing and restrained corner radii.
- A compact profile card leads into a separate contribution panel; the green contribution grid supplies a clear color accent against the mostly neutral page.
- Projects, recent pull requests, component releases and writing each get their own section with a short list and a route to more.
- The learning log pairs a dated note with a calendar-like grid of daily entries, turning ongoing practice into a navigable record.
- A theme toggle lives in the persistent top navigation.

## Using it with agents

No published agent channel was visible at review. Give an agent a specific section URL and ask it to map the information hierarchy or describe the visible calendar and panel structure.

## Watch out for

- The homepage is information-dense; keeping each section short and linking to a full view helps preserve scanability.
- The project and component lists reflect one developer's current work, not a general component catalogue.
- No reuse licence was stated for the page content or examples.

## Reusable ideas

- Put activity data in its own panel so it reads as evidence rather than decoration.
- Give recurring content types their own short preview and a clear route to the full archive.
- Use a simple date grid to make a learning log browsable over time.
