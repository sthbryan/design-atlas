# Grainient

## What it is

Grainient is a visual library of smooth and textured gradient backgrounds, animated gradients and generated backdrops, with a separate shader editor for making a custom gradient.

## When to open it

- When comparing a calm blurred mesh against a darker, grainier or more directional background.
- When you want to see how color, glow and texture shift the mood of a hero or surface.
- When exploring animated or shader-based backgrounds before choosing a static asset.

## Most useful

- Open the [Noisy / Grainy collection](https://grainient.supply/noisy-grainy). The reviewed grid showed dark previews with colored light streaks, soft halos and visible grain; the locked items indicate that much of this catalog requires Pro access.
- Compare it with [Smooth Blend](https://grainient.supply/smooth-blend) for softer color fields and [Animated Gradients](https://grainient.supply/animated-gradientes) for motion treatments. The latter showed 90 items at review.
- Use the [Shader Tool](https://shader.grainient.supply/) when you want to adjust a gradient rather than browse a finished background.

## Using it with agents

No MCP, API, CLI, `llms.txt` or agent-specific skill was found. Download an asset that your plan and licence permit, then pass its local file to an agent for implementation. The shader editor is a browser tool, not an agent interface.

## Watch out for

- Many previews in the textured collection display lock icons. The site lists separate free assets, but the library as a whole is not a free-download catalogue.
- The licence permits personal and commercial use but prohibits reselling or independently redistributing the assets. The site previews and shader-made results should not be treated as an open-source asset library.
- The current pricing page was internally inconsistent at review: it showed a $299 lifetime offer and multiple yearly prices. Recheck the displayed checkout price before buying.
- Animated gradients add motion and visual weight; test reduced-motion behavior and text contrast in the actual interface.

## Reusable ideas

- Group backgrounds by visual quality, such as grain, smooth blend, animation and AI-generated image, so mood is a useful browsing axis.
- Keep a large visual preview beside controls or categories to support quick comparison.
- Present static assets and a live shader editor as separate ways to reach a similar visual treatment.
