# Trazo

## What it is

Trazo is a set of hand-drawn, wax-crayon style sticker SVGs for the web: chunky crayon sea creatures, cats, arrows, stars, clouds and emphasis marks. Each sticker can be recoloured live, copied as clean SVG, or installed from npm as `trazo-stickers`, which the site counted at 1,523 downloads at review.

## When to open it

Open it when a UI needs the hand-drawn, friendly accent that an outline icon set cannot give, for example onboarding, empty states or playful annotations.

## Most useful

- **Live recolour**: change the crayon colour in the page and copy the resulting SVG.
- **npm install**: the same stickers as React components, so they theme with the rest of the app.
- **Crayon texture**: the wax-crayon look is consistent across the set, so mixed stickers still read as one family.

## Using it with agents

No MCP, API or agent guide is published; the npm package and copyable SVG are the working path for an agent.

## Watch out for

- The style is deliberately rough; it will fight a precise, corporate design system.
- The library is small (114 GitHub stars at review), so treat it as an accent pack, not a full icon set.

## Reusable ideas

- Offer a live recolour control next to the copy button so users pick the exact SVG they ship.
- A hand-drawn accent set works best when one texture rule holds across every sticker.
