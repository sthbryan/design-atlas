# One Switch

## What it is

One Switch collects small macOS toggles — hide desktop icons, dark mode, keep awake, screen saver, AirPods connection — into a single panel, and the page is a list of those switches with a one-line job each. The layout is short: title, subtitle "All your powerful switches in one place", trial button, a Setapp link, then five rows of switch and explanation, then an FAQ that answers licensing rather than design questions.

## When to open it

Open it when you are designing a settings surface for a handful of unrelated booleans and want a reference for naming each one as an action with a consequence, rather than as a preference.

## Most useful

- **Toggle list as the page**: each switch gets a verb-first title and a single sentence of consequence.
- **Stated compatibility** for dark and light appearances, which matters for a panel that sits over the desktop.
- **Trial then lifetime licence**, which is an unusual and welcome model next to subscriptions.
- **FAQ scoped to buying**: trial length, licence delivery by email, updates, support channels.
- **Two purchase routes**, direct and Setapp, kept as text links rather than competing buttons.

## Using it with agents

No `llms.txt`, MCP server or API was found at review, and the switches are system-level. An agent cannot drive the panel, though several of the toggles can be reached through macOS itself.

## Watch out for

- The page carries untranslated Chinese marketplace names (数码荔枝, 少数派) between the English purchase options, which reads as a localisation slip.
- Two different minimum macOS versions appear on the same page (Monterey 12 and Big Sur 11).
- There is no screenshot of the panel; the switches are described in text only.
- Some toggles duplicate features macOS now ships, and the page does not say what the app adds.
- Price is not published, so the trial is the only way to judge value.

## Reusable ideas

- Name each setting as an action plus its consequence, one line each.
- Say explicitly that the panel supports both appearances.
- Answer purchase mechanics in the FAQ instead of a separate page.
- Offer a lifetime licence where the software genuinely does not need a server.
