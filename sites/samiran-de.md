# Samiran De

## What it is

A personal portfolio with a dark, grid-framed layout, pixel-art landscape banner and colorful project previews.

## When to open it

Open it for a portfolio that uses a quiet profile area above a more expressive, varied project gallery.

## Most useful

The home page starts with a wide pixel-art waterfall on black, followed by a large serif name and compact profile details. Project cards keep a common two-column structure and visible borders, while each card uses its own vivid background color and preview image. Status, technologies and links sit close to each project, so the gallery stays legible despite its varied artwork.

## Using it with agents

No published agent channel found. Use the live page as a visual reference.

## Watch out for

The pixel-art banner and saturated project panels establish a strong personal identity; they may overwhelm a product site with a quieter visual language.

## Reusable ideas

- Keep card geometry and metadata consistent while letting project-specific colors vary.
- Place a single pixel-art landscape above a restrained profile to set the tone without crowding the introduction.
- Use clear grid borders to give a dark portfolio structure and separation.
