# Saved

## What it is

Saved is a daily-updated visual design gallery. Its public home page uses a masonry-like grid of image and motion cards, with filters for Web, Interface, Branding, Motion, 3D, Illustration, Typography and Posters. Each work opens a detail page credited to its creator.

## When to open it

Open it when you want a current, varied visual sample across interface and graphic-design work. The category pills make it easy to narrow the feed to motion, 3D or interface work, while the mixed grid helps compare styles without imposing one site's layout on every item.

## Most useful

- [Liquid Glass Chat UI](https://saved.design/works/jaimintf-liquid-glass-chat-ui) shows a mobile message list inside a soft, translucent glass treatment.
- [Agent Home Interface](https://saved.design/works/krispuckett-agent-home-interface) and [Audience Data Dashboard](https://saved.design/works/moguzbulbul-audience-data-dashboard) are useful product-interface examples in the current feed.
- The Web, Interface, Branding, Motion, 3D, Illustration, Typography and Posters filters keep mixed visual references easy to narrow.
- Individual work pages provide a creator attribution and a stable URL for returning to an example.

## Using it with agents

There is no published MCP, API, CLI, registry, llms.txt or skill. An agent can browse the public gallery and its creator pages in a browser.

## Watch out for

- The page labels itself Beta and has a Subscribe control, but no public pricing or reuse licence was found. Treat the gallery as look-only.
- Some cards are animated or video-based and may not render in every browser; use the individual work page when a card preview does not load.
- A featured-work gallery is useful for visual direction, but does not by itself document responsive behavior, implementation details or accessibility.

## Reusable ideas

- Use simple category pills to let visitors move among web, interface and broader visual-design references without leaving the gallery.
- A masonry-like image grid accommodates mixed aspect ratios while keeping the creator's work prominent.
- Give every item its own creator-attributed page so a visual sample can be revisited and credited.
