# ExpoKit

## What it is

ExpoKit is a library of copy-paste UI components, blocks (whole screens), app templates and charts for Expo and React Native. Items are added to your project with a CLI and run on iOS, Android, web and Expo Go. Most of it is free; Pro (pay once) adds the signature motion components and complete production-ready screens.

## When to open it

Open it when you are building a React Native app and want whole screens and charts, not only buttons.

## Most useful

- **Blocks as whole screens**: complete screens to copy and adapt, not just primitives.
- **CLI install**: components and templates land in your project with one command.
- **Cross-platform**: iOS, Android, web and Expo Go from the same source.

## Using it with agents

An `llms.txt` and the CLI are the agent channels; the copy-paste model means the agent edits owned code.

## Watch out for

- Pro screens and motion components are paid (one-time, at review); the free core is the permanent part.
- React Native only, so web-first teams should look elsewhere.

## Reusable ideas

- Offer whole screens as blocks so mobile apps start from a working layout.
- Keep the core free forever and charge once for the signature pieces.
