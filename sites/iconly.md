# Iconly

## What it is

Iconly is a curated reference library of app, game and web-app icons rather than a set you can install. At review it listed 2,400+ icons, each shown as a real product's icon with the product named beside it — the first card on the home page is Acorns, credited to Acorns Grow Incorporated. Icons are browsable by category, style and colour, and Pro adds unlimited saving and collections. New icons are added weekly, which makes it a running survey of how shipping teams are drawing small square marks right now.

## When to open it

Open it when you are designing an app icon or a favicon and want to compare how others solved the same corner-radius, glyph and gradient problem. It is the right stop before drawing, not after: filter by style first, then read the grid as a set rather than looking at single cards.

## Most useful

- **Filters by style and colour** let you see, for example, a run of flat single-colour marks against gradient ones, which is how a house style emerges.
- **Game icons beside app icons**: the same library shows playful, illustrated marks next to restrained product ones, so you can see where the two conventions diverge.
- **Product attribution on each card** makes it easy to look up the live app for the full context: icon in situ, store listing, brand.
- **Collections** for saving a shortlist while you work through a direction.
- **Weekly additions**, which is what a fast-moving category like app icons needs.

## Using it with agents

No `llms.txt`, MCP server, API or agent guide was found at review, and the gallery needs JavaScript to render, so an agent reading raw HTML gets almost nothing. The free tier exposes only 30 icons per view, and saving requires an account. Treat it as a human browsing tool.

## Watch out for

- The icons are real products' trademarks. They are references for form and construction, never files to reuse, whatever the subscription promises.
- Most of the library sits behind the paywall: 30 free icons per category at review.
- The library shows finished marks, not process, grids or sizes, so it teaches outcomes rather than technique.
- Category, style and colour labels are the site's own; expect the same icon to be classified differently from how you would file it.

## Reusable ideas

- Curate others' shipped work and name the product on every card, so the reference stays verifiable.
- Filter a visual archive by style and colour rather than by subject alone; that is how you find a direction.
- Show one artefact type only. A library of just app icons is more useful for that job than a general gallery.
- Keep a small free window open instead of gating everything, so people can judge the quality before paying.
