# Sonniss

## What it is

Sonniss is a sound-effects marketplace, and its Interfaces category collects 185 interface sound libraries (at review) from dozens of publishers: clicks, confirms, unlocks, errors, notifications, and themed sets (sci-fi HUDs, fantasy menus, retro games, casino sounds). Each library states its sample rate, channels and file count, and sounds are sold as packs with royalty-free commercial rights. The wider store covers about 5,000 libraries across all categories.

## When to open it

Open it when a product or game needs a coherent set of interface sounds in one style, with a licence that covers commercial use and no per-project negotiation.

## Most useful

- **Category as a set**: interface sounds sold as packs that sound like they belong together
- **Spec filters**: filter by sample rate, bit depth, channels and file count before buying
- **Royalty-free commercial**: one purchase covers commercial work, no subscriptions
- **Themed packs**: sci-fi, fantasy, retro and cozy sets for genre-driven products

## Using it with agents

There is no MCP server, API or llms.txt. The work is procurement: an agent can help choose a pack from the category filters, but purchasing happens on the site.

## Watch out for

- Per-pack prices vary widely (about $3.60 to $400 at review) and some libraries go on sale often
- Check each pack's file count and formats before buying; large bundles overlap

## Reusable ideas

- Sell interface sounds as coherent themed packs rather than single files
- Filter by technical spec (rate, depth, channels) alongside subject, so buyers narrow before downloading
