# Arc

## What it is

Arc is a React component and block library designed for AI-assisted interface work. The homepage shows live previews, from segmented controls and sliders to charts, card stacks, activity rings and larger AI-product flows. Each preview is marked Free or Pro.

## When to open it

- When you need to compare a polished interaction pattern before building it, especially for dashboard or AI-product UI.
- When you want a component demo that responds to input instead of a static screenshot.
- When you want to check how an AI-oriented React library presents examples and docs to people and agents.

## Most useful

- **Live examples**: the trial-signups chart has selectable date ranges, two series and a range slider; the adjacent segmented control and card-stack previews are also interactive.
- **Whole product flows**: the blocks section groups components into larger wallet, invitation and AI-chat layouts.
- **Free and Pro labels**: the catalogue distinguishes what is visible in the free library from paid pieces.
- **Agent path**: the draft terms advertise a component registry, MCP server, AI-readable docs and CLI, but no working public endpoint or install documentation was verified at review.

## Using it with agents

The draft terms advertise a registry, MCP server, AI-readable docs and CLI, but no working endpoint, public integration docs or installable package could be verified at review. Treat those agent channels as unconfirmed; the page is currently useful as a visual reference.

## Watch out for

- The homepage directs visitors to an early-access waitlist. Direct component and pricing routes returned to the homepage during this review, and no published agent endpoint or package was accessible to verify the integrations advertised in the terms.
- The terms page labels itself a draft pending legal review, so check the published terms again before relying on them.
- Preview names, photos and brand marks are sample content, not assets licensed for your product.
- Price for Arc Pro was not visible at review.

## Reusable ideas

- Give each demo a real control so people can test how the component behaves before reading its docs.
- Put a familiar product context around abstract controls: the date selector and series controls make the chart easier to assess.
- Show small components and complete flows in one catalogue, so visitors can move from a control to a composed screen.
- Mark free and paid previews at the point of browsing.
