# Identity Designed

## What it is

A curated index of brand identity work — marks, type systems, colour, applications — with the studio named on every entry. The home page leads with a plain statement of scope, "Brand identities from around the world, and the studios behind them", and a count that anchors the collection: 365 projects in the index at review. Navigation is three words wide: index, books, about.

The entries are case studies rather than thumbnails, so the value is in the sequence: a mark, then the type it sits in, then the application on a sign, a bag, a screen. That ordering is what a designer needs to judge whether an identity holds up, and it is the same structure an agent can follow when briefing a system.

## When to open it

Open it when a project needs a mark and a type system that live together, when you need to see how a colour scheme survives across print and screen, or when you have to argue for restraint in a rebrand. Less useful for interface patterns — this is identity, not UI.

## Most useful

- **Studio credited per project**, so a direction can be traced to the people who make it and their other work.
- **The index as the main view**, letting you move quickly between identities and compare typographic choices.
- **Applications alongside the mark**, which is where most identities fail and where this collection is strongest.
- **Writing and books alongside the gallery**, unusual for a curated site and useful when you want the reasoning.

## Using it with agents

No `llms.txt`, API or feed at review. Entries are ordinary pages that an agent can read once it has the URL, but there is no queryable index, so a person has to pick the shortlist.

## Watch out for

- Identity work is heavily print-led; screen behaviour, states and responsiveness are mostly out of scope.
- The count is a snapshot — 365 at review — and the index grows.
- Case-study layouts flatter the work; ask what the mark looks like at 16 pixels before borrowing anything.
- No licence is stated, so images and marks are references only.

## Reusable ideas

- Order an identity case study the way a designer judges it: mark, type, colour, then applications.
- Credit the studio on every entry; attribution is what makes an index useful beyond inspiration.
- Keep navigation to three words when the collection is the product.
- Publish a count so readers know how deep the archive is.
