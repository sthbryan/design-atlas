# Studio Dumbar

## What it is

Studio Dumbar/DEPT® is a Rotterdam design studio whose current work spans visual identity, motion, sound, interaction and creative coding. The home page is a visual project index rather than a text-heavy agency landing page; the About page places the studio within DEPT®.

## When to open it

Open it to study expressive typography, identity systems that move across media, and portfolios where the featured work carries the page.

## Most useful

- **Home page**: a compact wordmark and navigation sit above a largely white field where scattered black letters form an animated typographic composition. Project links continue as a visual list.
- **OpenAI DevDay25**: [the case study](https://studiodumbar.com/work/openai-devday-2025) has a black stage for its motion work. A loaded video shows a lime character assembled from code-like punctuation; the page pairs it with a restrained project title and explanatory text.
- **Other work**: the home index links directly to individual identity projects, including NN North Sea Jazz Festival, Google Sans Flex, MTV VMAs and Feyenoord.
- The contact page places the studio in Rotterdam, Netherlands. Public project rates were not stated.

## Using it with agents

No MCP, API, CLI, `llms.txt` or agent guide was found. Open the home page and a case study directly, then describe the specific typographic or motion treatment to reference.

## Watch out for

- The project work is reference material; no reuse licence was stated on the pages checked.
- The portfolio is media-led. Allow project videos to load before judging a case study; the OpenAI DevDay25 animation appeared after its initial blank state during this review.
- Studio Dumbar is part of DEPT®, as described on its About page.

## Reusable ideas

- Let one kinetic typographic gesture introduce a portfolio while keeping the navigation plain and easy to scan.
- Use punctuation and glyphs as raw material for motion identities, then carry the same shapes into static compositions and event objects.
- Give project media a dark stage so bright identity elements remain legible.
