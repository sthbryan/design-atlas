# Dhruv Deora

## What it is

A designer and builder's portfolio with an editorial home page, colorful project gallery and playful pixel-art details.

## When to open it

Open it for a portfolio that gives project previews a strong visual role while keeping the introduction personal and readable.

## Most useful

The home page combines a large serif introduction with compact colored navigation labels and a pixel-art cat. Project links lead into oversized visual tiles with contrasting backgrounds and graphic treatments. The project gallery is useful for studying how to make a varied set of product work feel like one portfolio.

## Using it with agents

No published agent channel found. Use the live page as a visual reference.

## Watch out for

The Dotprolabs case-study page currently says the detailed case study is coming soon; the home page and project gallery still provide visual examples.

## Reusable ideas

- Give each project tile its own color and image treatment while keeping a consistent scale and rhythm.
- Pair a restrained editorial type system with a few playful pixel-art accents.
- Use short, clearly labeled navigation blocks to make a personal site feel informal without obscuring its sections.
