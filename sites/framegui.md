# Frame

## What it is

Frame is a native desktop app that converts video, audio and images in one workspace, powered by FFmpeg with files processed locally. It is free and open source, with an `llms.txt` describing every page in Markdown.

## When to open it

Open it when you need to batch-convert media assets for a product (video, audio, images) without uploading files to a website.

## Most useful

- **Every format, one workspace**: video, audio and images together, instead of three separate tools.
- **Local processing**: files never leave the machine, which matters for unreleased assets.
- **Markdown twins**: every page is available as Markdown, which is unusually agent-friendly for a desktop tool.

## Using it with agents

An `llms.txt` maps the site's Markdown pages for agents; the app itself is a desktop tool an agent cannot drive.

## Watch out for

- It is a desktop utility, not a design library; it earns its place for asset preparation only.
- No named licence was found at review despite the open-source claim.

## Reusable ideas

- Process media locally when the assets are unreleased or large.
- Publish Markdown twins of every page so agents can read the docs without a browser.
