# SEESAW

## What it is

SEESAW is a hand-picked gallery of websites, updated daily according to the site. It files whole sites, not individual sections: each entry is one live site with a short line about the product, the date it was added, the typefaces it uses and the categories it sits in. The maker isn't named on the site; it posts as @seesawsite on X. It is a Next.js front end whose records and images come from Airtable and Cloudinary.

## When to open it

- When you want to see how current startup, AI, fintech and developer-tool marketing sites look, since those dominate the recent additions.
- When you have picked a typeface and want to see real sites that set it, or the reverse.
- When you want a quick daily or weekly scan of new sites instead of a deep archive search.

## Most useful

- About 860 site entries in the sitemap, dated from June 2023 to September 2026.
- A font index with about 630 typeface pages; each one lists the sites that use it.
- About 260 category pages (3D, agents, banking, brand guidelines, portfolios and many more), with 14 shortcuts in the top bar.
- A ⌘K search that covers websites, fonts and categories together.
- Entry pages with "more like this" links to other recent picks.

## Using it with agents

No MCP, llms.txt, API or export. Use an entry as a written brief: note the site's typefaces from its SEESAW page, open the live site, then describe the hero, section order, density and palette to the agent and ask for the same structure with your own copy and brand.

## Watch out for

- Despite the name, you can't browse by page section (hero, pricing, footer); for that use [Sections.wtf](sections-wtf.md) or the section library on [Curated](curated-design.md).
- Not everything is a marketing site: events, reports, magazines and apps appear in the feed too.
- No licence or terms page is published, and entries show the site's own preview image rather than a full-page capture, so you still need to visit the live page.

## Reusable ideas

- Tagging every entry with the fonts it uses turns a site gallery into a type-pairing reference for free.
- One small record per site (name, one-line pitch, date, fonts, categories) is enough to power search, category pages and font pages from the same data.
- A shared ⌘K box across entities (sites, fonts, categories) beats separate filter panels for a catalogue this broad.
