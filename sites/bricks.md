# Bricks

## What it is

Bricks is a visual builder that ships as a WordPress theme rather than a plugin, and its selling page is organised around one idea: the design system should survive the editing. The features block is grouped accordingly — reusable classes, variables, palettes and Theme Styles first, then responsive controls with unlimited custom breakpoints and a stated desktop-and-mobile-first approach, then the structural tools (nestable elements, menu builder, query loop, conditions, interactions). There are 149 elements at review, and the hero opens on a video rather than a screenshot.

## When to open it

Open it when you are designing a WordPress build and need to know how far the theme lets you define tokens once and reuse them, or when you want a reference for how a builder presents a design system to people who are not developers. The free online playground at `try.bricksbuilder.io` is the honest way to judge the editing surface, since there is no downloadable trial.

## Most useful

- **The design-system framing**: classes, variables and palettes are documented as the primary workflow, not as an advanced panel, which is the right order for anyone maintaining a site after launch.
- **Breakpoint control on the canvas**, including changes made at each breakpoint without leaving the builder.
- **Free wireframes and design sets** included with every licence, which gives the builder a starting grid rather than a blank page.
- **Interactions and conditions** with click and hover triggers, enough for tabs, reveals and hover states without a second plugin.
- **A public playground as the demo**, which is a better sales device than a video of someone dragging boxes.

## Using it with agents

No `llms.txt`, MCP server or API was found at review. There is an experimental "AI Abilities" feature that lets a compatible external client create and update pages, elements, templates and design-system resources, but it works on a Bricks install and is not a documented agent channel for reading the design. Treat the site itself as a human reference.

## Watch out for

- The whole product is a theme for self-hosted WordPress. It is not a hosted builder, so the site's own marketing cannot be evaluated as a finished site service.
- Every plan claims the full feature set, so the tiers differ only on site count and billing; the comparison is not about capability.
- Design quality of the included wireframes is not shown in detail on the pricing page.
- The AI integration is labelled experimental at review.
- Video-led hero and feature sections are the standard builder template; there is no distinctive layout move to study beyond the design-system emphasis.

## Reusable ideas

- Sell a builder by showing the token layer — classes, variables, palette, theme styles — before the drag-and-drop.
- Put breakpoints on the canvas and let each edit be scoped to one width.
- Ship starter wireframes with the licence so the first screen is a grid, not a blank canvas.
- Use a live playground with an account as the trial instead of a downloadable demo.
