# Light Rails

## What it is

Light Rails is a browser pattern editor by Dinesh. It exposes adjustable rails, line and flare shapes, gradients, motion and timing, with templates that range from fans and grids to spirals and light trails. The editor includes an animated preview and an export action.

## When to open it

- When creating or studying a luminous line pattern for a graphic, background or motion piece.
- When comparing how one abstract pattern changes as its geometry, palette and timing are adjusted.

## Most useful

- **Shape and lines**: tune warp, base width, flare span, line count, core heat and edge behaviour.
- **Motion**: choose between a trail sequence, continuous colour loops and a pulse treatment.
- **Looks and templates**: save a named configuration or start from examples such as a fan, tile field, spiral, rays or sunburst.
- **Pattern preview**: view the animated pattern on its own or with a sample layout beneath it.
- **Export**: an export control is present in the editor; its format and reuse terms were not documented on the page at review.

## Using it with agents

No MCP, API, CLI, registry, `llms.txt` or agent guide was linked at review. The editor exposes visual controls and export, rather than a documented agent integration.

## Watch out for

- The editor loaded, but the same page also contains long, unrelated promotional sections and copy from other product concepts. Use the pattern editor itself as the reference and disregard those sections as evidence about this tool.
- The initial page opens with an extra follow prompt; dismiss it to see the controls and preview unobstructed.
- Price, export format and licence were not stated on the public editor page.

## Reusable ideas

- Group parameters by shape, lines, gradient, timing and look so a creator can reason about the output in stages.
- Offer named templates as working starting points, not finished assets.
- Make the animation visible beside its controls and allow the controls panel to be hidden for a clean preview.
