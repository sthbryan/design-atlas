# Compass Design System

## What it is

Compass is a shadcn-based design system shaped by UX research: components and blocks with semantic light and dark tokens, a brand and visual-language generator, and an AI layer that connects the system to coding agents through a skill and an MCP server. The site lists 120+ components and blocks; the public repository is more conservative about how many are shared primitives.

## When to open it

Open it when you want a shadcn-compatible system that ships with UX reasoning and agent wiring, rather than only component code.

## Most useful

- **Blocks as well as components**: page-level compositions, not just primitives.
- **Brand generator**: turn a brand into tokens and a visual language instead of hand-picking greys.
- **Agent wiring included**: a skill, an MCP server and registry installs, so the agent works from the same system.

## Using it with agents

An `llms.txt`, an agent skill, an MCP server and registry installs are documented. The free tier covers components; the Plus membership adds the AI connections.

## Watch out for

- Part of the system is a paid Plus membership; the free tier is the components.
- The site is Korean-first, so some documentation and defaults will need translating.

## Reusable ideas

- Pair a component system with UX write-ups, so decisions travel with the code.
- Generate brand tokens instead of hand-picking colours for each project.
