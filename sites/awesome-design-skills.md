# Awesome Design Skills

## What it is

Awesome Design Skills is a curated GitHub list of design skill files for agentic tools: about 67 entries at review, covering DESIGN.md one-pagers and SKILL.md agent skills aimed at tools like Claude Design, Google Stitch, Codex and Cursor. The list tracks the moving parts of the space (design systems, brand guides, review and audit skills) and is updated continuously, with a few thousand stars at review.

## When to open it

Open it when surveying what design skills exist before installing one, or when you need names to compare before adopting a workflow. It is the map, not the territory.

## Most useful

- **Curated breadth**: 67 skills in one index at review, with short summaries
- **Fresh**: commits land continuously, so it reflects the current state of the format
- **Zero install**: a bookmark and a README away

## Using it with agents

The list itself offers no MCP, API or installable skill; it points at repositories that do. An agent can fetch the README to enumerate the skills and their purposes, then follow the links to the skill folders themselves.

## Watch out for

- It is an index, not a review: linked skills keep their own licences, quality and maintenance
- Awesome lists rot; check the linked repository's last commit before adopting a skill

## Reusable ideas

- A living index of skills beats a static roundup, as long as entries carry a one-line summary
- Keep the index itself trivially clonable so the curation is the whole value
