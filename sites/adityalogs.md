# Aditya Logs

## What it is

Aditya Kumar Puri's portfolio combines a short biography, career highlights, recent GitHub activity, projects and writing.

## When to open it

Open it when exploring a compact portfolio that uses a coding-inspired type system and puts live activity alongside the introduction.

## Most useful

The desktop page divides into a broad biography column and a narrow activity sidebar, separated by a fine vertical rule. Monospaced text carries through the name, navigation, section labels and body. Most text is subdued gray; selected links and phrases turn bright white, making emphasis feel like inline annotation. A vivid blue contribution grid adds the main color accent.

## Using it with agents

No agent-facing integration was found. The portfolio links to its project list and writing, including a longer biography view.

## Watch out for

The two-column layout and compact mono text should be checked at smaller viewport sizes before reuse.

## Reusable ideas

- Give a portfolio sidebar a distinct job by filling it with timely activity rather than duplicate navigation.
- Use a single monospaced family and a few brightness levels to create hierarchy without many boxes.
- Reserve a saturated accent for data such as a contribution map.
