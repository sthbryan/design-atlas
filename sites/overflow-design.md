# Overflow Design

## What it is

Overflow Design is a one-person asset studio: isometric icons, isometric drawings, illustrations, 3D pieces and bot avatars, made for websites, apps, decks, docs and Notion pages. It counted 1,977 drawings at review, including 1,120 Notion icons and 400 isometric drawings, plus a scene builder.

## When to open it

Open it when a page or deck needs isometric or 3D-flavoured illustration that reads as one hand, not a stock mix.

## Most useful

- **One consistent hand**: the whole catalogue looks drawn by the same person, which is rare in asset packs.
- **Isometric coverage**: a deep set for that specific style.
- **Scene builder**: compose isometric scenes instead of hunting for a matching drawing.

## Using it with agents

An MCP server and `llms.txt` are published, so an agent can browse the catalogue.

## Watch out for

- The full catalogue needs the Pro licence; the free set is a subset.
- Isometric illustration is a strong style; it will not suit every brand.

## Reusable ideas

- Keep every asset from one hand so a catalogue reads as a system.
- Offer a scene builder for assets that are usually used in compositions.
