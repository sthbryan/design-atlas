# uberdesigner

## What it is

uberdesigner is a library of 200+ AI website templates and UI components: each entry is a prompt for Claude, Codex, Cursor or Kimi that rebuilds a finished design, with its Vite and React project and, for many, a Figma file. It covers complete sites, sections, cards, menus, dashboards and even browser games.

## When to open it

Open it when you want a finished design rebuilt in your stack by your agent, rather than a component to drop in.

## Most useful

- **Prompt plus project**: every template pairs a copyable prompt with a runnable Vite and React project.
- **Figma for many entries**: the design file travels with the prompt for handoff.
- **Whole sites, not only parts**: complete sites and ready sections, not just buttons.

## Using it with agents

An `llms.txt` and copyable prompts for Claude, Codex, Cursor and Kimi are the agent channels; the agent rebuilds the design from the prompt.

## Watch out for

- Paid plans gate part of the library; confirm what the free tier includes.
- Rebuilt designs still need a review pass for your brand and accessibility.

## Reusable ideas

- Ship every template as prompt plus project, so the agent and the human start from the same artefact.
- Include the Figma file where it exists so the rebuild stays faithful.
