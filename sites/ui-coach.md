# UI Coach

## What it is

UI Coach combines design practice resources with an award-winning website gallery. The reviewed gallery has sort and award filters and links to individual project pages. Each project page pairs a large captured design with its award, a short description, colour swatches and a link to the original listing or site.

## When to open it

Open the gallery when you want to browse recognized web projects and then study one reference more closely. Individual pages make it easy to move from a wall of examples to a larger capture with its award context and palette.

## Most useful

- The gallery starts with a brief explanation of what to study, then exposes sort and award filters before a three-column project grid.
- Project cards have a consistent dark title strip above large captures, so names remain legible while the artwork stays prominent.
- On the [Behind The Brutes gallery capture](https://www.uicoach.io/inspirations/award-winning/behind-the-brutes), the image takes most of the left column while a narrow information card on the right holds the title, Site of the Day label, source link, description, palette and original-site link.
- This archived 2013 example uses a dense, playful 3D scene with an intentionally staged composition; its detail page also shows three muted palette swatches. I reviewed the UI Coach capture, not the linked original site as it exists today.
- The gallery's footer connects inspiration to font pairings, colour palettes, UX laws and other learning resources.

## Using it with agents

No MCP, API, CLI, `llms.txt` or other agent channel was found during review. The award-winning gallery and its project captures are accessible in a browser without signing in.

## Watch out for

- A PRO membership is advertised at a promotional $9/month from a displayed $20/month price at review; confirm current terms before paying.
- Captures can represent older award entries. Check the original site before treating a reference as current.
- The gallery does not state a reuse licence for its featured designs. Take visual ideas only; keep their copy, imagery, logos and identity out of new work.
- A gallery capture is not proof of the current linked site's design. Open the original source separately when you need a live reference.

## Reusable ideas

- Show useful filter controls before the first row of a large visual gallery.
- Keep a consistent title band on image cards so project names remain readable over variable artwork.
- Use a split detail view to keep the reference large while making attribution, palette and follow-up links easy to scan.
