# Motificons

## What it is

Motificons is an icon search and restyling tool over open-source sets: 337,122 icons from 239 sets at review, with a style engine that normalises icons from different sets into one look, and native export for the platforms you need.

## When to open it

Open it when one project needs icons from several sets but must look like one family, or when an agent needs to find an icon across many libraries at once.

## Most useful

- **Style normalisation**: the reason to use it over a single set, since mixed sources usually clash.
- **Huge searchable corpus**: 239 sets in one index at review.
- **Agent access**: an MCP server, plus WebMCP, so agents can search and style in-session.

## Using it with agents

The MCP server is the agent channel; an account adds collections and an MCP key.

## Watch out for

- Licences belong to each upstream set; restyling does not change them.
- A normalised icon can lose the detailing that made it readable at small sizes, so check the result.

## Reusable ideas

- Normalise icons from different families into one style instead of forcing one library on a team.
- Show per-asset licence and attribution next to the export, not in an FAQ.
