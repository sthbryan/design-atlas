# HorizonX

## What it is

HorizonX is a premium UI component library for the vibecoding era: production-ready React and Tailwind components, Figma templates and UI kits, plus textures, shaders and mockups, aimed at builders using Cursor, Lovable and v0.

## When to open it

Open it when you want a kit that already speaks the vibecoding workflow (Figma source, React code, agent prompts) rather than a traditional design system.

## Most useful

- **Kits, not only components**: full UI kits for shipping a product surface quickly.
- **Beyond components**: textures, shaders and mockups in the same subscription.
- **Agent paths**: an MCP server, an `llms.txt` and prompts for Cursor, Lovable and v0.

## Using it with agents

The MCP server and `llms.txt` are the agent channels, alongside the Figma source and React code for humans.

## Watch out for

- It is a paid subscription; check what the licence allows before using kits in client work.
- Kit-heavy output can look templated if every surface comes from the same kit.

## Reusable ideas

- Bundle the kit, the Figma source and the agent prompts as one product.
- Add textures and shaders to a component library so surfaces are not flat by default.
