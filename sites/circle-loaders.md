# Circle Loaders

## What it is

Circle Loaders is a collection of 24 animated loading spinners designed as standalone SVG files. Each design offers a distinct visual approach to depicting loading states, with names like Latitude, Scanline, Waveform, Aperture, and Meridian.

## When to open it

Open this site when you need visual spinners or loaders for loading states. It's perfect for applications that want distinctive visual feedback without creating animations from scratch.

## Most useful

- **24 unique spinner designs** with varied technical approaches
- **Monochrome and adaptable**: each loader works on light or dark backgrounds
- **Zero dependencies**: pure SVG with embedded CSS animations
- **Copy-paste ready**: use directly in `<img>` tags, CSS background, or inline
- **Responsive controls**: adjust tempo (0.5×, 1×, 2×) and diameter (64, 96, 128px)
- **Accessible**: ARIA labels and support for `prefers-reduced-motion`

## Using it with agents

SVGs can be downloaded and edited by AI agents. Each loader includes detailed technical explanations that facilitate adaptations. You can ask agents to change colors, durations, or dimensions.

## Watch out for

- Loaders are designed to be simple; if you need something highly customized, be prepared to edit SVG
- Animation speed may require adjustments depending on your application context
- Some effects (wave, metaball) may use more GPU than others in older browsers

## Reusable ideas

- Geometric patterns (stripes, gratings, wedges) for modern loaders
- Wave and fluid effects for data applications
- Rotational (gimbals, gears, spirals) for machinery or engineering
- Path tracing and graph visualization for technical applications
- Particles and metaballs for organic aesthetics
