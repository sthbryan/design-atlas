# DesignEng

## What it is

DesignEng, at designeng.tools, is a directory of links for design engineers, shown as cards with a one-line description, a pricing badge and an "Open" button to the original site. It is grouped into Inspiration (websites, designs, discovery, OG images, logos, app icons, app screenshots), Resources (components, icons, tools, playbooks, design systems, fonts, skills, community, courses) and People (creators, founders, educators). Visitors can sign in to save resources, and saved lists show on public `@username` profile pages. The operator is not named on the site. Despite the similar domain, it is a separate project from [Design Engineer Tools](designengineer-tools.md).

## When to open it

- When you want a quick scan of React and Tailwind component kits, including small new ones, filtered to free or open-source options.
- When you want a short, pre-picked list of popular design agent skills with their install commands.
- When you are hunting for app icon, App Store screenshot or OG image galleries and don't remember their names.

## Most useful

- **Size**: 149 resources in the home listing and 204 resource pages in the sitemap at review, with 22 category pages.
- **Filters**: Animated, Free, Freemium, Paid, Open source and Free trial, plus a Newest sort and ⌘K search.
- **Tools** is split into subcategories: design and prototyping, website builders, motion, 3D, video capture, asset optimisation, sound, colour palettes and AI design tools.
- **Skills**: 10 agent skills at review, each linking to its skills.sh page, with a copy button for the install command and the install count shown there.
- Each resource page lists related entries from the same category.

## Using it with agents

No llms.txt, MCP or API. The Skills category is the part closest to agent use: it points to third-party skills and copies their install commands, and those skills are what your agent actually runs. For everything else, pick a library here and give the agent that library's own docs or registry URL.

## Watch out for

- Many entry descriptions appear to come from each site's own meta description, and a few are thin or inconsistent (a one-word blurb, a misspelt name, a pre-launch waitlist listed as a component library).
- The Submit link showed an empty page at review, so there's no clear way to suggest a resource.
- The mix is broad (whiteboards, favicon generators and paid icon bundles next to component kits), so "curated" here means a loose list rather than a strict one.
- No terms or privacy page, although it offers accounts.

## Reusable ideas

- Putting a pricing badge on every card and letting people filter by it answers the first question most visitors have.
- Letting visitors save resources to public profiles turns a directory into a set of shareable personal lists.
- Showing an install command next to each skill cuts the step from finding it to trying it.
