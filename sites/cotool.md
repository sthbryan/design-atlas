# Cotool

## What it is

Cotool sells AI agents for security operations. Its home page stands apart from a conventional enterprise dashboard aesthetic with a bright blue hero and a multicolor field of dots that rises from the lower edge.

## When to open it

When a technical product page needs a confident color-led identity, or when looking for an alternative to a screenshot-led hero.

## Most useful

- [Home](https://www.cotool.ai/) — inspect the saturated blue hero, highlighted phrase, dotted terrain and the Detect / Respond / Hunt selector.
- [Detect](https://www.cotool.ai/detect), [Respond](https://www.cotool.ai/respond) and [Hunt](https://www.cotool.ai/hunt) — compare how the same product family branches into focused feature pages.
- [Agreements](https://www.cotool.ai/license) — check current service terms before considering any reuse.

## Using it with agents

The public pages are browser-readable. I did not find a public `llms.txt`, API reference, CLI, MCP server or installable agent skill during this review.

## Watch out for

- The blue and dotted landscape are a strong brand device; check the live page for motion behavior and reduced-motion handling before borrowing the pattern.
- The homepage asks visitors to book a demo; it does not expose a public product sandbox.
- The terms include an enterprise subscription agreement, but no public price list was found.

## Reusable ideas

- Highlight one phrase within an oversized headline to make the core concept scan as a distinct unit.
- Carry a repeated dot motif into a broad lower-page landscape so the visual identity works at both headline and page scale.
- Use a small tab set to let a visitor switch between product jobs while keeping the surrounding layout stable.
