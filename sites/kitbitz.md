# Kitbitz

## What it is

Kitbitz is a collection of 2,000+ hand-drawn illustrations with a freehand style. Each illustration has an artisanal, non-digital quality, offering a refreshing contrast to generated or photographic assets.

## When to open it

Open Kitbitz when you need illustrations with character, visual authenticity, or a manual touch for your project. It's ideal for landing pages, blogs, applications with strong visual identity, or any project that wants that hand-drawn feel.

## Most useful

- **2,000+ unique illustrations**: enough variety for multiple projects
- **Consistent hand-drawn style**: all have artisanal coherence
- **Free to download**: access the repository and download what you need
- **Friction-free**: no registration or login required

## Using it with agents

Files can be downloaded and used as visual references. AI agents can adapt them using SVG or vectorization, or use them directly as embedded assets in projects.

## Watch out for

- Exact licence terms aren't completely clear on the site; verify before commercial use
- Hand-drawn style is very particular; some projects may find it too casual or unprofessional
- The variety of styles within the collection means you'll need to select carefully to maintain visual coherence

## Reusable ideas

- Characters for brand mascots
- Hand-drawn icons for interfaces
- Decorative elements with character for landing pages
- Context illustrations for tutorials or documentation
- Custom emojis with artisanal style
