# Inspiration Grid

## What it is

Inspiration Grid is an online magazine that has published daily picks of creative work since February 2011. It covers art, illustration, photography, graphic design, branding, typography, packaging, architecture, product and vehicle design, and more. Each post is a short written introduction to one artist, studio or project, with images and a link to the creator. The owners are not named beyond the brand; the about page credits the studio Avenue with designing and building the site. The sitemap listed roughly 8,400 URLs at review.

## When to open it

Open it for visual ideas from outside web design: an illustration style for a brand, a packaging system, a photography mood, a type-led poster. It suits moodboard research at the start of a brand or campaign. It is a weak source for interface or layout references.

## Most useful

- **Big archives in visual categories**: Art (4,487 posts), Illustration (3,256), Graphic Design (1,716), Photography (1,692), Typography (1,070) and Branding (728) at review
- **Typography and branding posts** that show whole identity systems and lettering work, not just logos
- **Credits and links** to each featured maker's own site or portfolio
- **Cross-discipline mix**, useful for finding a visual idea that no UI gallery would surface

## Using it with agents

There is no MCP, API or `llms.txt`; `/llms.txt` and `/robots.txt` both returned the site's 404 page at review. The site is a static Gatsby build, so each category has a public `page-data.json` with its post count. A sitemap and RSS feed are also available. For design work, pick posts by hand, describe the palette, type and composition to the agent, and link the original creator rather than passing on the images.

## Watch out for

- UX & UI Design is a small category (83 posts), and at review its newest entries were sponsored award-competition posts
- Sponsored editorial, product reviews and an Amazon affiliate "#want" block appear next to regular posts
- There is no licence for the featured images, so they are for reference only
- Browsing is by broad category and keyword search only, with no style, colour or format filters

## Reusable ideas

- Pair every image-led post with a short written note on what makes the work distinctive
- Keep broad visual categories (art, illustration, packaging) next to digital ones so moodboards can mix sources
- Credit and link the maker on every entry so readers go to the source, not a copy
- List audience figures on the partnerships page so sponsors can judge fit before asking for rates
