# Landing.Gallery

## What it is

Landing.Gallery is a regularly verified archive of landing pages. Its homepage showed more than 1,777 hand-picked examples at review and offers filters for page type, website builder and framework. Individual records include a desktop preview, a mobile view and an OG image view; the site also advertises an MCP for coding agents.

## When to open it

Open it when the brief names a page type such as pricing or careers, or when you want examples made with a specific builder or framework.

## Most useful

- Use the three homepage filters to narrow a broad screenshot grid by builder, framework or page type, then open a record for responsive and social-preview views.
- The [meli record](https://landing.gallery/websites/meli) links to [Meli's live store](https://drinkmeli.com/). Its current hero uses a looping product/lifestyle video under a handwritten headline, with a scalloped age-check panel centered above it.
- Records show when the site was last verified, which gives a useful cue to recheck the live page.

## Using it with agents

The site advertises an MCP for coding agents in its homepage and footer. No separate API or `llms.txt` was observed. Confirm MCP setup and available tools in its linked documentation before depending on it; the public browser filters and individual preview modes are available directly.

## Watch out for

- Verification dates are relative to each record and can age; inspect the linked live site before relying on its current state.
- The gallery says screenshots and logos belong to their respective owners. No general reuse licence was stated, so use examples as look-only references.
- Search and outbound links are public. The reviewed homepage did not indicate a paid gate for the archive.

## Reusable ideas

- Pair each screenshot with its last-verified date and a direct route to the current site.
- Expose desktop, mobile and OG image views together so a landing page can be studied across its presentation contexts.
- Make page type and implementation platform separate filters.
