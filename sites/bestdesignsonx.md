# Best Designs on X

## What it is

Best Designs on X is a hand-picked stream of design work posted on X, with separate tabs for Instagram, Dribbble, Behance, fonts, app icons and OG images. It is part of the Panda Network, the same group behind Collect UI and Curations Supply, and it runs the @bestdesignsonx account (about 15.7K followers at review). The main feed showed 9,411 items at review and says it updates hourly. It is a Svelte app on Supabase, and posts, including videos, are shown from the site's own CDN with the author's X handle and a link back to the original.

## When to open it

Open it to see what designers are posting this week: motion studies, landing-page shots, 3D and brand work, often as short videos. It is a quick scan for visual direction before a project, and a way to find designers worth following. For shipped products or complete flows, use a pattern library instead.

## Most useful

- **Hourly feed with search** across designs, creators and tags, and a "last updated" time
- **Credit on every post**, with the X handle and a link to the original, so you can reach the designer
- **Side tabs**: fonts filtered by classification (serif, sans-serif, script, monospace), app icons and OG images, each more focused than the main feed
- **Submit a post**: paste an X post URL to suggest it for curation
- **Daily newsletter** with the most-clicked items

## Using it with agents

There is no API, MCP server or llms.txt; the llms.txt path returns the app shell. Use posts as visual references you describe to an agent. The front-end code also defines Skills, Design Systems and DESIGN.md views with copy buttons for install commands and DESIGN.md files, but those views were not in the main menu at review, so do not count on them.

## Watch out for

- Media is copied from X to the site's CDN, and no licence or takedown process is published. Treat everything as reference only
- The feed mixes organic picks with paid placements: the designer showcase is ordered by bid, and sponsor cards promote network partners
- Many posts are concept shots and motion experiments, not shipped UI
- With no terms or privacy policy found, there is no stated basis for accounts or saved data

## Reusable ideas

- Curate from a social platform into a searchable archive, with the author credited on every item
- Split a broad feed into narrow tabs (fonts, app icons, OG images) for specific jobs
- Show a "last updated" time to prove the feed is alive
- Let visitors suggest items by pasting a post URL instead of filling in a long form
