# Illos

## What it is

Illos generates animated SVG illustrations for product sites that stay on-style: one consistent illustration language in your colours, without having to describe the style each time. It is packaged as skills for Claude Code, Cursor, Codex and other coding agents.

## When to open it

Open it when a product site needs animated illustration that matches the brand, and you would rather have an agent produce on-style SVGs than hand-brief an illustrator.

## Most useful

- **Style consistency**: the output stays in one illustration language across a whole site.
- **Your colours**: the style is applied in your palette, not a fixed house colour.
- **Skill packaging**: the agent workflow is the product, so illustration fits the build loop.

## Using it with agents

Agent skills for Claude Code, Cursor and Codex, plus an `llms.txt`, are the channels; the agent draws ready-to-ship illustrations in the session.

## Watch out for

- No pricing or reuse licence was published at review; confirm both before using output in a commercial product.
- Animated SVG needs a reduced-motion fallback for sensitive users.

## Reusable ideas

- Treat illustration style as a constraint the generator holds, not a prompt the user repeats.
- Deliver illustrations as code (SVG) so they theme and animate with the product.
