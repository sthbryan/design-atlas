# Sephiro

## What it is

Sephiro is a React and Preact UI toolkit with a public component and theme catalogue. The home page groups 71 components into seven sections and lets visitors preview the same interface in six built-in themes.

## When to open it

Open it to study how a component library can make theme changes legible across a whole product, or to compare related controls, forms, overlays, navigation, data feedback and agent UI patterns.

## Most useful

- The dark and light home variants show the same restrained layout with distinct surface and type contrast.
- The theme page offers directly selectable presets, making palette changes easy to compare without losing context.
- The component section pages expose controls and states alongside source examples.
- The Agent UI section collects citation, tool-call and plan-card patterns in one place.

## Using it with agents

The site has no advertised MCP, registry or CLI channel. Public section and component pages provide the visual examples; a GitHub link leads to the toolkit repository.

## Watch out for

- PolyForm Perimeter is source-available, not a permissive open-source licence; review its terms before reusing code.
- The `?ink=dark` query selects the dark presentation. Use the theme selector to compare the other presets.
- This is a young toolkit with a deliberately compact catalogue; treat its patterns as examples rather than a complete platform standard.

## Reusable ideas

- Make theme previews act on the catalogue itself so users can judge contrast in context.
- Group a component catalogue by the job a control performs, then reveal examples within each group.
- Keep the main installation action copyable and pair it with a short explanation of the design system.
- Give agent-facing components their own browsable family instead of scattering them among generic controls.
