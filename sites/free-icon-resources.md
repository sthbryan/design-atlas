# Free Icon Resources

## What it is

A GitHub catalog of icon sets and related tools, grouped into 14 categories across six groups. At review, it listed 157 resources, including open-source and freemium libraries, icon search engines, brand marks, animated and 3D icons, emoji, flags, SVG tools, Figma plugins, and iconography references. It is an index for finding a source, not a unified icon library or visual gallery.

## When to open it

Open it when you need to choose a concrete icon source or tool and want options grouped by use. The open-source sets section links directly to [Heroicons](https://heroicons.com/) and [Tabler Icons](https://tabler.io/icons); the search section links to Iconify and other aggregators. These official sites let you inspect each set's actual drawing style and rendering options; the catalog only discovers them.

## Most useful

- **Distinct categories** separate general sets from brand logos, animated icons, 3D icons, flags and niche subjects.
- **Direct links with short descriptions** help narrow the choice: [Heroicons](https://heroicons.com/) offers outline and solid styles, while [Tabler Icons](https://tabler.io/icons) lets you browse outline and filled variants and adjust stroke, size and color.
- **Search and production tools** such as Iconify, SVGOMG and SVGR Playground point to ways to browse or prepare icons after choosing a set.
- **CSV export** makes the same catalog available for a spreadsheet or Notion.

## Using it with agents

There is no MCP server, API, CLI or dedicated agent guide. The README and linked CSV can be read directly from GitHub. An agent can shortlist resources by category, then should check the chosen provider's own terms and license before proposing assets or code.

## Watch out for

- The word “free” in the repository name does not mean every linked resource is free of charge or unrestricted; the list includes premium and freemium offerings.
- Icon, brand and tool licences vary by provider. The repository's CC0 dedication covers its catalog, not the listed resources.
- Counts and summaries can go stale. The total of 157 resources is at review.

## Reusable ideas

- Group an asset directory by practical design tasks and visual variants, not just by provider.
- Include specialist sets alongside general-purpose libraries so a reader can narrow by context.
- Keep a portable CSV beside the human-readable catalog for reuse in other discovery workflows.
