# BRRRANDING

## What it is

BRRRANDING is a curated gallery of visual identity projects, with a project page for each feature and links to the original studio case study. At review it listed 216 projects and used human curation rather than an algorithmic feed.

## When to open it

Open it when a web or product brief needs a broader identity direction: wordmark, colour, type, packaging, motion and environmental applications. Its gallery is useful for finding a project; the original studio page is where to verify the work in context.

## Most useful

- **[Home gallery](https://www.brrranding.com/)**: a black canvas, enormous condensed masthead and three-column image grid. Search and pill-shaped filters let you narrow projects by industry, year, colour, elements, typography, type and sort order.
- **[Ytri Island Retreat](https://www.brrranding.com/blog/ytri/)**: the entry credits Bielke&Yang and tags the case for blue, red, serif, custom type, motion, website, print and environmental design.
- **[Original Ytri case study](https://bielkeyang.com/prosjekter/ytri-island-retreat)**: the live studio page pairs a compact capsule navigation with a broad project title and category tags, then opens into a large image. The identity mixes warm neutrals with deep red and pale blue; use the source page to inspect its applications rather than inferring them from the gallery card.

## Using it with agents

No public MCP, API or CLI surfaced. The footer links an `llms.txt`, but the browser blocked that file during this review, so its contents were not verified. An agent can still use the search and filter controls in a browser, then follow the project's credit link. Describe the visible design moves in your own words; don't feed the gallery imagery back as source assets.

## Watch out for

- The projects are identity case studies, not ready-made interface patterns. Follow the credit to check how the visual system behaves on its own site and across other media.
- Featured marks, photos, packaging and type belong to their respective creators; browsing does not grant reuse rights.
- Sponsor blocks appear within the gallery and are labelled. Sponsorship buys placement, not inclusion as a curated project.

## Reusable ideas

- Filter by colour and typography as well as industry, since a visual direction can matter more than the product category.
- Keep the project credit and source case study one click from every card.
- Place sponsorship in the same visual grid only when it is clearly labelled and visually distinct from editorial selections.
