# Ratnesh Chipre

## What it is

A design engineer's portfolio, writing site and shadcn-compatible component registry. The Components section currently lists four components, each with a live example and installation instructions.

## When to open it

Use it to study a compact personal portfolio or the presentation of small, copyable React components in a documentation page.

## Most useful

Open [Perspective Tilt](https://ratneshc.com/components/perspective-tilt) for a working 3D card interaction. Its page places a live preview before the usage and API sections, with the install command, composition tree, prop tables and code sample close to the example. The home page keeps the profile, project cards, experience and technology list in a narrow, lightly styled column.

## Using it with agents

The site publishes a shadcn-compatible registry. Its component pages show install commands and code; the registry can be addressed through the standard shadcn registry flow. No MCP, API or dedicated agent instructions were found.

## Watch out for

The registry is small, and the portfolio's restrained monochrome layout is a specific reference rather than a broad visual catalogue. The repository's MIT licence covers its project source; check any third-party assets separately before reuse.

## Reusable ideas

- Pair each interactive component preview with a short install command and copyable code.
- Keep the API reference and composition structure adjacent to the example so a reader can move from seeing to adapting it.
- Use a persistent, low-profile top navigation and a single narrow content column to make a personal site feel calm without hiding its sections.
