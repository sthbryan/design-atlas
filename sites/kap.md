# Kap

## What it is

Kap is an open-source macOS screen recorder. The homepage is a compact product-site reference: a single saturated blue-to-violet gradient hero introduces the app, then a capture-toolbar preview overlaps its curved lower edge.

## When to open it

Open it when a product needs a focused, single-screen landing page or when a screen-capture tool needs to show its main control without an extended feature tour. This is one live product site, not a gallery of interfaces.

## Most useful

- [Homepage](https://getkap.co/): inspect the gradient hero, curved transition into the white page, floating recorder controls and format summary.
- [Kap source repository](https://github.com/wulkano/kap): check the current project state, downloads, plugin ecosystem and source licence.
- [MIT licence](https://github.com/wulkano/kap/blob/main/LICENSE.md): the app source licence; it does not cover the site's visual assets by itself.

## Using it with agents

The site points to a public GitHub repository and its licence, but no MCP, API, CLI or dedicated agent guide was linked from the reviewed pages. An agent can open the landing page as a visual reference and read the repository, while treating the site's own art and copy as look-only.

## Watch out for

The homepage demonstrates the recorder's toolbar but does not provide a searchable collection of finished recordings or a detailed workflow tutorial. The GitHub MIT licence applies to the source repository; no separate reuse permission for the website's copy, screenshots or branding was stated.

## Reusable ideas

- Let one high-contrast hero carry the product promise, then place a recognisable product control at the edge of the next section to connect the promise to its interface.
- Use a restrained palette and a short format list when a tool's value is clear from its output types.
- A full-bleed gradient can provide visual identity while the rest of a short landing page returns to a quiet white background.
