# Ladybug

## What it is

Ladybug is a browser studio for wild visual effects: 60+ looks for images, video and type in one tab, including ASCII, dither and halftone, with no plugins and no AI. It is aimed at looks that would otherwise take days and twenty plugins.

## When to open it

Open it when you need an experimental effect (dithered imagery, ASCII type, glitch treatments) for a campaign, a launch or a texture, and want to export it from the browser.

## Most useful

- **Effect depth in one tab**: dozens of looks across image, video and type without a plugin chain.
- **Zero AI**: the effects are deterministic and controllable, which makes them repeatable.
- **Free to start**: no watermark on the free path.

## Using it with agents

No MCP, API or agent guide is published (the `llms.txt` address serves the HTML page at review); an agent can drive the studio in a browser.

## Watch out for

- Export terms for commercial work were not stated at review; check the pricing and licence pages before shipping.
- Heavy effects need performance and reduced-motion care on real pages.

## Reusable ideas

- Put many deterministic effects in one tab so experimentation is fast.
- Offer a no-watermark free path so the studio spreads as a tool, not a demo.
