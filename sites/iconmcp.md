# IconMCP

## What it is

IconMCP is a library of 6,248 original outline icons with an MCP server your coding agent can search by meaning: ask for the icon a concept needs instead of guessing a file name. It is free for anything under the MIT licence.

## When to open it

Open it when an agent needs to pick icons by meaning during a build, or when you need a large, permissively licensed outline set.

## Most useful

- **Semantic search over MCP**: the agent searches by meaning, so it gets usable icons without a filename guess.
- **Original set**: 6,248 outline icons drawn for the library, not a rename of an existing set.
- **MIT licensed**: ship the icons in commercial products.

## Using it with agents

The MCP server is the product; the site documents how to connect it in your agent. The library itself needs JavaScript to browse.

## Watch out for

- Outline-only coverage (6,248 icons at review); filled or duotone needs sit elsewhere.
- The set is large, so pick by meaning and style, not by scrolling.

## Reusable ideas

- Expose icon search by meaning over MCP so agents stop hallucinating icon names.
- Keep one consistent outline weight across a large set so mixed usage still looks coherent.
