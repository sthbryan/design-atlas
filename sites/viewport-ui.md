# Viewport UI

## What it is

Viewport UI is a visual reference gallery with filters for web, desktop, mobile, watch, iOS, Android, icons and motion. The grid mixes stills and media cards and links individual records to their original source.

## When to open it

Use it to browse interface directions across device formats, especially when you need a compact mobile composition or a motion example to investigate further.

## Most useful

- Start at the [home gallery](https://viewport-ui.design/) and narrow the collection with its category pills. Cards include a name or short description and creator attribution.
- **[Storyboard Component](https://viewport-ui.design/posts/591-storyboard-component/)** presents a sports story inside a phone frame: compact browser chrome, a concise headline, a strong subhead, paired photos and a score card. The centered phone capture makes the mobile hierarchy easy to scan.
- Follow the original-source link on a record to check its context and interaction. The gallery card is a visual record rather than a complete specification.

## Using it with agents

No MCP, API, `llms.txt` or agent export was visible at review. Use the browser to filter and open records, then follow the source link for the original work.

## Watch out for

- Pricing and a reuse licence were not stated at review. Treat the gallery and linked works as look-only.
- Some cards use media that may not play in every browser. Check the original source before drawing conclusions about motion.
- A single record may show only one viewport or static moment; verify responsive behavior and interaction on the source page.

## Reusable ideas

- Device categories make it easy to browse references by the shape of the target screen.
- A phone frame can preserve familiar browser context while keeping the actual content large enough to inspect.
- In a mobile story, combine a short headline, clear subhead, paired imagery and a compact data card to create a readable sequence without a long feed.
