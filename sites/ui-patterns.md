# UI-Patterns.com

## What it is

A reference library of common UI patterns and persuasive-design concepts. The pattern pages combine a short problem summary with an example, usage guidance, a proposed solution, rationale and discussion.

## When to open it

Open the [design-pattern index](https://ui-patterns.com/patterns) when naming a familiar interaction or comparing ways to handle a recurring interface task. Use the [screenshot browser](https://ui-patterns.com/explore) when you need real product examples to inspect by pattern, color, site or search term.

## Most useful

A detail page such as [Drag and drop](https://ui-patterns.com/patterns/drag-and-drop) puts the problem before its suggested solution, then shows an example from Stamps & Sons and notes that keyboard or other alternatives matter because dragging is not fully accessible. The screenshot browser connects examples back to named patterns and source domains. This is useful for finding a case to study, though the captures can be old and may not reflect the current site.

## Using it with agents

No MCP, API, CLI, `llms.txt` or other agent interface was found at review. The browser pages expose searchable pattern names and screenshot records, so an agent can open a named pattern or use the screenshot filters directly. Follow the source domain to check a current implementation before recommending it.

## Watch out for

The examples are a reference archive, not current implementation guidance. Check the original page before relying on an interaction, and look for accessible alternatives. Persuasive patterns need an ethical review in context. The written library is licensed for noncommercial sharing with attribution; the linked screenshots and products have separate rights.

## Reusable ideas

Describe an interface pattern with the user problem it solves, the conditions where it fits, one concrete example and its limits. Compare alternatives by user goal and context instead of treating a pattern name as a requirement.
