# Studio Yukiko

## What it is

Studio Yukiko is a Berlin creative studio whose homepage presents selected client work and a browsable project index. A custom, sharply condensed display face sets the large welcome line and project names against neutral sans-serif client labels. The [Urbane Künste Ruhr identity case](https://y-u-k-i-k-o.com/projects/urbane-kunste-ruhr/) opens as an image-led overlay, combining a vivid poster sequence with the identity rationale, links and credits.

## When to open it

Open it to study a strong typographic voice across an editorial studio portfolio, or to see a project archive organized with category filters and case-study overlays.

## Most useful

- **Display typography**: the narrow custom lettering gives headings and project labels a recognizable rhythm while lighter sans-serif text carries clients and supporting details.
- **Project index**: category buttons cover identity, editorial, campaign, music, culture and other project types; cards vary in size and include image crossfades.
- **Case-study overlay**: the UKR page alternates large visual sequences, explanatory text, links and a clear credit block.
- **Editorial depth**: updates, studio information and selected work appear in a long page, with Highlights, About and View All as persistent orientation points.

## Using it with agents

No published agent channel was found. Ask an agent to compare the home page, filtered project index and one case-study overlay for type scale, card rhythm and image-to-text pacing. The site's studio and client work are visual references; no reuse licence was stated.

## Watch out for

- The custom condensed face is distinctive but narrow; check small text and long labels at the actual viewport before adapting a similar treatment.
- Project imagery and motion are part of the clients' and studio's work, not reusable assets.
- No public pricing or reuse licence was found at review.

## Reusable ideas

- Pair one expressive display face with a quiet text face so the typographic contrast also clarifies hierarchy.
- Use category labels as a compact index into a large portfolio, and let card sizes reflect the changing image material.
- Arrange case-study media and rationale in alternating blocks so the visual system remains the focus while its context is available.
