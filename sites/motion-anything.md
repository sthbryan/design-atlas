# motion-anything

## What it is

motion-anything is an agentic motion layer: a local-first workbench and recipe library where you describe the feeling you want and a coding agent produces the animation, exported as CSS, React, Lottie, MP4 or GIF, plus portable skills. It runs on your own agent CLI or API key.

## When to open it

Open it when motion is the brief (springs, easing, transitions) and you want an agent to produce both a live implementation and a rendered file.

## Most useful

- **Both outputs**: code for the site and video for the launch, from one recipe.
- **Recipes as skills**: motion patterns travel between projects instead of being rewritten.
- **Local-first**: no render fees or watermark, but you pay for the model you use.

## Using it with agents

It integrates with Claude Code, Codex, Cursor, OpenCode and Gemini CLI, and its recipe skills are portable between them.

## Watch out for

- You bring the model, so cost and quality depend on the agent you connect.
- Agent-generated motion needs a reduced-motion path and a performance check on the real page.

## Reusable ideas

- Describe motion as a feeling and let the agent translate it, instead of hand-tuning curves.
- Export the same recipe to code and video so launch assets and the live site match.
