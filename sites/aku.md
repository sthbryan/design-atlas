# AKU

## What it is

AKU is a design studio based in Tallinn, Estonia. Its portfolio site moves from a short studio introduction into a long, typographic list of projects, with individual pages that present visual work across broad color fields.

## When to open it

Open it to study a minimal studio portfolio that gives project names room to act as its main visual navigation, or to see how a short text introduction can lead into a varied visual archive.

## Most useful

- **Home page** — the introductory statement occupies the top of the page; a compact INFO control opens contact, team and capability details.
- **Project archive** — project titles appear in a simple vertical sequence with generous gaps, so the index reads clearly without image cards.
- **Case pages** — an [example case page](https://aku.co/projects/music-estonia/) opens with a large title, a pale-blue text panel and full-width imagery further down. Use it to inspect the studio's layout and visual presentation.

## Using it with agents

No MCP, API, CLI or agent guide is published. The `/llms.txt` route opens a directory listing rather than an agent-readable text file. An agent can browse the portfolio and follow its project pages.

## Watch out for

- The portfolio showcases cross-media identity and editorial work; study its page composition and type hierarchy rather than treating the project imagery as reusable web assets.
- No public service prices or reuse licence were stated at review. Treat the work as look-only.

## Reusable ideas

- Use a short studio statement as a quiet lead-in to a text-first project index.
- Give project names enough scale and spacing to serve as both labels and navigation.
- Set case introductions on a solid color field, then let larger images carry the visual detail further down the page.
